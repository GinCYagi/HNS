### 1.2 条件（旧名称で競合しないか）の確認結果：**競合なし**

| 確かめたこと | 結果 |
|---|---|
| 正本4YAMLに「近江」「淡海」「おうみ」「丹波」「たにわ」「丹後」などが使われていないか | 使われていない（2026-10-02 時点、grep） |
| 東山道「権現道」の典拠への影響 | 9/30 の査読（`docs/reviews/2026-09-30_review_shichido_niigata.md` §2.2）は、東山道の権現の例に「日吉山王（近江）」を挙げている。ただし、採るときの条件 C1 で絞った典拠（出羽三山・日光・飯縄・御嶽）には近江は入っていない → **崩れない**。一次チェックで挙げた比叡山（近江）は、典拠から外す |
| 山陰道「神府道」への影響 | 典拠の中心は出雲。丹波が抜けても崩れない |

| 「七」を含むほかの名前 | 七国府日ノ本鐵道（七鐵）は同じ構想の一部で、そろう。五畿七道の「七道」とは数え方の対象が違う（区分の数と国の数） |

### 1.3 記録する内容

- A000：**七国府（なこう）**。旧称：国府内（くにうち／こうのうち）。
- 本世界の畿内は**七か国**とする：大和・山城・摂津・河内・和泉＋**近江・丹波**。
  - 七つの国の国府を抱えるので「七国府」と呼ぶ。
- 史実とのつながり（Wikipedia「畿内」本文で確認）：
  - 757年に和泉が河内から分かれるまでは、四か国で「四畿内」と呼ばれていた。
  - 大化の改新の詔では、北の境を「近江の狭狭波の合坂山（逢坂山）」としていた。
  - 794年に平安京へ遷都した後は、平安京から「山一つ越えただけの近江国や丹波国」へ出ることが禁じられた。
  - **本世界の設定（着想）**：遷都のとき、この「山一つ越えただけ」の2か国も畿内に組み入れた。
- **由来メモ（案）**：「そうだ、なこう、行こう」の標語を成り立たせるために、Gin が採った名前である。七つの国の国府を抱えることから七国府と呼ばれる、という設定を後から整えた。
  - 着想と断定の区別（PRE-007）として、標語が先にあったことを隠さずに書く。
  - 標語は、JR東海の「そうだ 京都、行こう。」をもじったもの（私の知識。元のページは未確認）。
- 本世界では「五畿七道」が「**七畿七道**」になる（記録。呼び方を決めるのは Gin）。

|---|---|

| 山陰道（神府道） | 丹波が畿内へ抜ける |

### 1.5 査読で確かめる点

- C-03：千葉の「那古（なこ）」「那古船形駅」と音が近い（引継ぎ書の一次チェック）。方面が離れているので、条件付きで通る見込み。
- C-07：「七国府」を「なこう」と読むのは字面から推しにくい → 台本はルビ必須。
- 畿内に入った近江・丹波の HNS 名は、まだない（あとで候補を出す）。

## 3. 野積（のづみ）

### 3.1 Gin の問い（原文）

> 3、野積はどこにあたるの？

### 3.2 どこか（元のページで確認）

- **新潟県長岡市寺泊野積。** 大河津分水（信濃川の分水路）の**河口付近**にあたる。
  - Wikipedia「大河津分水」：河口付近を「長岡市寺泊野積」と書いている。分水路は燕市（分水地区）と長岡市（寺泊地域）の境界付近を流れ、日本海に至る。
- 分水路の河口近くには、国道402号の**野積橋**が架かっている。
  - Wikipedia「野積橋」：「新潟県長岡市寺泊野積の大河津分水路に架かる国道402号」
- ALM の絵の基準表 §4「河口（野積側）」は、この**分水路の河口の、野積の側の岸**を指していると読める。
- 弥彦山（伊夜日子山）との位置関係は、今回は**未確認**（元のページに記述がなかった）。

### 3.3 扱い（HNS-Rev-local の推奨）

- **当面はカッコのまま「（野積）」でよい。** 絵の中で「河口のどちら側か」を示すだけで、台詞や看板に名前が出る場面はまだない。
- 名前を付けるなら、**分水路の名前が決まってから**にする（P-02：親から）。
  - 分水路の名前（「堰戸分水」など）は、まだ裁定前（NG の照合記録）。
  - 野積はその河口の地名なので、分水路の名前と一緒に考えると筋がそろう。
- 野積は長岡市（HNS ではまだ「（長岡）」とカッコ）に属する。名前が要る場面が出てきたら、長岡の名前とあわせて候補を出す。

## 4. 第2版：A000 は「五国府（ごこう）」に（Gin、2026-10-02）

> **［この節で §1 を置き換える］** §1（七国府・七か国）は記録として残すが、A000 の案は五国府に切り替わった。

### 4.1 Gin の発言（原文・時系列）

> ３、そうだ、ごこう、いこう
> でもきれいだと思うんだけど＋２なった原因ってなんだっけ
> 後光、信仰の地だからと理由づけられなくもない
> 後光の擦り切れのごこうだよね
> ごこうにしましょう

- 「+2」の原因は、HNS-Rev-local が次のように説明した。
  - 名前「七国府」が先にあった（7/7 の構想と 9/30 の Gin の発言）。
  - 畿内は五か国なので、「七」の説明として3案を出した。
  - Gin が案1（七か国にする）を選んだので、国を2つ足すことになった。

### 4.2 記録する内容

- A000：**五国府（ごこう）**。旧称：国府内（くにうち／こうのうち）。
- 畿内は**五か国のまま**（大和・山城・摂津・河内・和泉）。五つの国の国府を抱えるので「五国府」と呼ぶ。数が史実の五畿と合う。
- **§1 の「近江・丹波を畿内に加える」は取りやめる。**
  - 近江は東山道（権現道）、丹波は山陰道（神府道）にとどまる。
  - §1.4 の「権現道の典拠から比叡山（日吉山王）を外す」も取りやめる。ただし、9/30 の査読の条件 C1 で絞った典拠（出羽三山・日光・飯縄・御嶽）は、もともと近江を含まないので影響はない。
- 標語：「**そうだ、五国府（ごこう）、いこう。**」（「ごこう／いこう」で韻を踏む）
- **由来メモ（案）**：
  > 標語「そうだ、ごこう、いこう」を成り立たせるために、Gin が採った名前である。畿内の五つの国の国府を抱えることから五国府と呼ぶ。「ごこう」は「後光（仏・菩薩の背から差す光）」と同じ音で、寺社と古い都の集まる信仰の地にふさわしい**掛詞**として、意図して重ねている。
  - 着想と断定の区別（PRE-007）：標語が先にあったこと、後光との重ね合わせが意図したものであることを隠さずに書く。
  - 標語は、JR東海の「そうだ 京都、行こう。」をもじったもの（私の知識。元のページは未確認）。
- 「七畿七道」の呼び方の問いは消える（五畿七道のまま）。

### 4.3 五国府の一次チェック

| 検査 | 結果 |
|---|---|
| C-01 | 「五国府」という駅はない（国土地理院の住所検索で0件。全国駅名リストとの照合はしていない）。音が同じ「**五香駅**（ごこう）」が千葉県松戸市にある（京成電鉄松戸線。Wikipedia「五香駅」本文）。名前は一致しない＝記録 |
| C-02 | 国土地理院の住所検索で「五国府」は0件 |
| C-03 | 五香（ごこう、松戸）と音が同じ。方面は離れていて（下総＝東海道側）、全国に知られた地名でもない＝**記録のうえ条件付き**。査読で判断する |
| C-04 | 「後光（ごこう）」と同じ音で、「後光が差す」とよく使う言葉。ただし意味は良く、**意図した掛詞として由来メモに書く**（Gin「信仰の地だからと理由づけられなくもない」）。「御幸（ごこう＝上皇などの外出）」とも同じ音＝記録 |
| C-05 | なし |
| C-07 | 3モーラ。「五国府」を「ごこう」と読むのは字面から推しにくい → **ルビ必須** |
| C-08 | 兄弟の読みとの照合：こうぶ（神府道）と「こう」が重なる（記録）。ごくらく（極楽道・構想）と頭の「ご」が重なり、仏教の言葉どうしでもある（記録）。完全に一致するものはない |
| 短縮禁止 | 「国府」だけに略すのは引き続き不可（国府駅・国府津駅）。「五国」「国府」などの短縮は、使う場面が出たら C 系を掛け直す（RUL-009） |
| 連動 | 構想段階の「七国府日ノ本鐵道／七鐵」も「七」を含むので、名前を合わせる必要がある（構想段階なので記録だけ） |
