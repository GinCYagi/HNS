## 3. ユーラシア
- 現実の日本語は ユーラシア（カタカナ）がふつうで、漢字の 欧亜 はまれ。
- 外の名：Europe＋Asia → Eurasia と同じ作りで、Platopa＋Helia → **Plathelia**（プラトヘリア）。Plathelia という語は見つからない（近い語に 海藻の属 Platythalia、扁形動物 Plathelminthes）。
- 漢字は 望理（ぼうり）。暴利 と同じ音だが、まれな言葉なので受ける（大陸の提案書のとおり）。

## 6. 足し（2026-10-23、同じ日）：太平洋・大西洋の外の名と、世界の名の原理原則
### 6-1. 太平洋・大西洋（Gin「イ」「成り立ちからもじれればなと」）
| 現実 | 外の名（もじり） | 日ノ本の名 |
|---|---|---|
| Pacific（マゼランの Mar Pacífico、荒れた大西洋と比べて「平和な海」） | **Placid Ocean**（Mar Plácido。plácido＝穏やか。Pacific と音も意味も近い） | **太謐洋**（たいひつよう。天下太平 の 太＋天下静謐 の 謐。大西洋 と 太・大／たい で並ぶ） |
| Atlantic（アトラスの海。英語版 Wikipedia「Atlantic Ocean」） | **Telamonic Ocean**（建築の男像柱 atlantes の別名 telamones から。英語版 Wikipedia「Atlas (architecture)」） | **大西洋**（残す） |
- 太謐洋：地名 0、同じ音 大筆 のみ（weblio）。謐 は常用外。前の案 静穏洋・静謐洋・太寧洋 は下げる（Gin「静謐も由来はいいんだけどね」）。
- Placid Ocean・Telamonic という海の名は Web 検索で見つからない。Telamon はギリシャ神話の英雄の名でもある（Henrica と同じく、外の名では人の名も使う）。
- 大西洋 を残す理由（6-2 の原則による）：大＋西＋洋 は、方角（DIFF-026）と理に近い言葉（DIFF-028）だけでできていて、ずらすところがない。太平洋 の 太平 はマゼランの印象（人の思い）なのでずらす。中国の言葉かどうかは理由にしない。

### 6-2. 原理原則（Gin「それを一応原理原則にしたいなとは思います」2026-10-23）
G5 の言い方：**名が付いた瞬間を一歩ずらして、そこから歴史を流し直す。理はずらさない。**
1. ずらすのは、名の終わりの形ではなく、**名が付いた瞬間**（名の元の言葉・人・印象）。例：火ノ本→Hapan、eurús→platús（Platopa）、Amerigo→Henricus（Henrica）、Pacífico→Plácido（Placid）。
2. そのあとの訳・略・借用・当て字は、**現実と同じ道筋で自然に流れた**ことにする（例：Platopa→プラトッパ→望羅都巴→望州）。名の元と関わりなく作られた名は、それ自体の名が付いた瞬間で見る。
3. **理はずらさない**（方角・極・元号 など、DIFF-026・RUL-024）。
4. **日ノ本も世界も同じ物差し**で見る。
Gin のことば：「決まりをちゃんと決めてしまえば物語は後からこう自然と動くっていう考え方につながる」。
