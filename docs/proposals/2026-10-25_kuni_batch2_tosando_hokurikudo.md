## 気がかりのまとめ
- **#1 近江 と束1 の 遠江** は対で決める（邇湖・遥湖）。
- **#3 陸奥** は 律令 と 明治（束5）で同じ名。明治の 陸前・陸中 の 陸 との関係は束5 で見る（陸＝道 の意味なので、陸前＝路前 の形になりうる）。
- **#4 出羽** は 羽前・羽後（束5）の親。
- 由来が分からない #6 加賀・#7 能登 は、字の意味（加賀）と土地の姿（能登）で作った。ほかの道があれば C5 に。
- 読みにくい字（常用漢字表 2,136 字で照らした）：常用外は #1 邇湖 の 邇、#7 鉤江 の 鉤 の一字ずつ。ほかは常用の字だけ。ルビの要る読み：#1 湖＝うみ、#2 参＝み。#1 は 邇（常用外）と 湖＝うみ（読み）で、ルビの要る所が二つになる → DIFF-018 ④ の「読みにくい字」に読みも入るかを C5 に。
- 束1 も同じく照らした：常用外は 淵内（淵）・嘉湧（嘉）・領湊（湊）・多瀞（瀞）・連洲（洲）・遥湖（遥）の一字ずつ。二つのものはない。

## C5 の査読（docs/reviews/2026-10-25_review_kuni_batch2_C5.md）と G5
1. **DIFF-018 ④ に読みは入る**（正本の文「④読みにくい字(ルビの要る字。当て字・難読の字…)は、一つの名に一つまで」）。湖＝うみ は当て読み。なので **邇湖（邇＋うみ）は二つで当たる。束1 の 遥湖（遥＋うみ）も二つ**（G5・C5 とも束1 で見落とした）。湖＝こ にすると 遠江 は 5→3 拍で ±1 を外れる。→ **遠江・近江 を対のまま作り直す**：

   |---|---|---|---|---|---|

   - 隣湖（りんこ・3、0/3、照らし 0、weblio：臨戸・隣戸・凜乎）も近江 にだけなら作れるが、遠江 と対にならない。
2. 加賀＝益寿（字の意味）・能登＝鉤江（土地の姿）：受け入れ可。**同じ石川で作り方が分かれる** 点を Gin に。
3. 陸奥（律令・明治）を同じ名に：DIFF-045 どおり受け入れ可。果路 の はて は重い意味ではない（C5）。
- 参平 は 野→原 の次点 平 を使ったので、**元の字 野 を行に記録**（DIFF-050 の次点の決まり）。秀端・永稚 は受け入れ可。
