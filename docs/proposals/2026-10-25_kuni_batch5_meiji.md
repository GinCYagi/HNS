## 頭の字（G5 の記憶の手順：現実の頭の字が親の名のどの字かを先に書く）
- 陸前・陸中 の頭＝**陸奥 の一字目 陸**（陸＝道。道奥 の 道 を 陸 と書き換えた、ja.wikipedia「陸奥国」）。作中の 陸奥＝果路 では **陸（道）→路**。→ 頭は **路**。
- 羽前・羽後 の頭＝**出羽 の二字目 羽**（出羽＝出端、羽 は 端 の当て字、世界大百科事典・日本歴史地名大系）。作中の 出羽＝秀端 では **羽（端）→端**。→ 頭は **端**。

## 気がかり
- #1・2 は訓（みちさき・みちなか）、#3・4 は訓＋音（はぜん・はご）で、読み方の作りがそろわない。どれも拍は元と同じ。
- 陸前高田市（in_name）などの名は、市を決めるときに 路前〇〇 の形になる。

## C5 の査読（docs/reviews/2026-10-25_review_kuni_batch5_C5.md）
1. 頭の字：路（陸＝道 にあたる字。果路 の並びは逆でも、対応で取っている）・端（羽 にあたる字）とも正しい。束3・4 の取り違えとは違う。
2. 照らし：名まるごとの重なりは 0。路前・路中 の字の当たりは 横大路前川町・越路中沢 など切れ目をまたぐだけ。端後 の「中に含む」の多さは二拍で当たりやすいだけ。
3. 気がかり：前・中・後 の読みが、路前・路中（訓：さき・なか）と 端前・端後（音：ぜん・ご）で分かれる。前例は 渡前（どぜん）・渡中（どちゅう）・具前（ぐぜん）で音。→ **ろぜん・ろちゅう（音）にそろえるか、四つとも訓にそろえるかを Gin に**。G5 の付け足し：音にそろえると 路前＝ろぜん は 3 拍（元 4、±1 の内）、路中＝ろちゅう は 3 拍（元 4）で 路駐 と同じ音（悪い意味ではない、C5）。訓にそろえると 端前＝はさき・端後＝はしり などになり、照らしていない。

## Gin の言葉（2026-10-25、HNS-G5 のセッション）
- Gin「え、陸奥(みちのく)が果路になったんじゃないんだ」。G5 は二通りに読めるので問い返し中：①「みちのく」の呼び名が果路で、国の 陸奥（むつ）も果路か、の確かめ ②陸前・陸中 の頭は 果路 の一字目 果（果前・果中）と思っていた。答えが出るまで、M4 には送らない。

## 陸奥 の作り直し（Gin、2026-10-25、HNS-G5 のセッション）
- Gin の言葉：「え、陸奥(みちのく)が果路になったんじゃないんだ」「雪路みたいに」「だから最初は奥の細道から奥路になるのかと思ってたけど果路になってたからそうしたのかと」「現実はどういう関係性なの？」「さすがに被るのは誤読が増えるかと」「実際に『道』が国の名に入った例はあるの？」「もしくは五畿七道」「作り直してok」「アナウンス原稿もその語に差し替えます」。
- わけ：作中では 〜路 を七道の名（嶺路＝東山道・雪路＝北陸道）に使っている。国の名 果路 は七道と見分けにくい。現実でも、国の名から 道 は外れた：吉備道前国（藤原宮木簡）→備前、道奥→陸奥（道→陸）（ja.wikipedia「備前国」「陸奥国」）。七道（と 北海道）だけが 道 で終わる。

- 前の名 果路 は、正本 629・1230・1276 行（kyukokumei の律令・明治、と 陸奥(旧国名) の行）と tsunagari にある。ALM の GitHub（origin/main・claude/opus-external-generation-tools-y08f4a）に 果路 は見つけていない（G5 の PC で git grep）。アナウンス原稿は Gin が差し替える。
- **C5 の査読（束5 の査読の追記1）**：ア を受け入れ可。ただ前例（越前・苗後・具前・路前）は **字の対応** で頭を取っていて、果地 は 陸→地・奥→果 で並びが逆なので、位置で 果 を取ると、対応では 奥 の字を頭にすることになる。並びを 地果（ちはて、字・読み 0）にすれば位置も対応も 地 で合うが、地前 は つちさき＝土崎、ちぜん は 越前（えちぜん）の中に入る町域 22（C5 の照らし）、ちちゅう＝地中 で、どれも重なる。→ 行に「**頭は位置で取った。対応では 地。地前 は読みが重なるため**」と記録する（C5 の推し、G5 も受ける）。果地 の拍 3 は むつ 2・みちのく 4 のどちらにも ±1。照らし 0（中に含む 4 は ハテ の音だけ）。前・中・後 の読みが 果前・果中（訓：さき・なか）と 端前・端後（端＝は の訓に 前＝ぜん・後＝ご の音）で分かれる件は、Gin に一緒に。
- Gin「こうやって見てみると史実でもひでぇ扱いだな」「よー分からん土地扱いされてて」「まぁ統治者から見て、と言う名付けで見れば自然なことなんじゃないかな」（2026-10-25）。G5 の読み取り：都（統治者）から見た 奥・果て の名付けは史実として自然なので、果地 のまま（Gin に確かめ中）。
- Gin「地州仕置 になるわけか」（2026-10-25）。**陸奥 の別名 奥州 の作中の名**：現実の 奥州 は 陸奥 の **二字目 奥**＋州。頭を位置で取った（陸前＝果前）のと同じく、位置で取れば 果地 の **二字目 地**＋州＝**地州（ちしゅう）**。対応で取れば 果州（かしゅう）だが、weblio：**加州（加賀の別名）・河州（河内の別名）** と同じ音で、ほかの国の別名と紛れる。地州 は字・読み 0（町域・正本）、weblio：知州（古い役職名）。→ **地州** が筋。
  - 一緒に替わる名：奥州仕置＝**地州仕置**、奥州市（岩手、郵便番号データに 奥州市 の行 415）・奥州町、奥州街道、奥州藤原氏（藤原 は人の名で残る、奥州 は地州）。奥羽（陸奥＋出羽）は 地＋端 で **地端**（照らしていない）になる形。
  - 奥州仕置 は歴史の出来事の名。年は現実にそろえる（RUL-024）。名の中の地名は、作中の名（地州）で言う。
