## 1. 決まりの当て方
- **DIFF-048（同じ名の区はそろえる）**：旭・緑・泉・青葉・鶴見 の案は、そのまま 大阪（旭・鶴見）、さいたま・千葉・相模原・金之鯱（緑）、楼題（泉・青葉）にも当てる。各市の土地に合うかは、その市のときに見直す（例：仙台の 青葉 は 青葉山・青葉城 から、泉 は旧泉市 から。由来が横浜と違う）。
- **港**：港北・港南 と、名古屋・大阪の 港区 に同じ字を当てる。港→**埠**（ふ、船着き場の字）。
  - 外した字：泊（北海道 泊村 と同じ字。正本では 泊⇔帰 の前例〈寺泊→社帰〉もある）、浦（町域に 星が浦北 などが多い。浦 は字の表で 岸 に替わる字）、津（新潟県 津南町）、湊（読みが みなと で同じ）。
  - 気がかり：埠区（ふく）は1拍で短い（元 みなと 3拍。DIFF-043 の ±1 から外れる）。名古屋・大阪のときに 埠頭区 なども見る。
- **鶴（RUL-018、動物の字は残す）**：鶴見→鶴廻。見 を 廻（めぐり）に替えたのは、ツル＝水路・ミ＝めぐり の説から（鶴見川がうねって流れる）。読み つるわ（3拍、元と同じ長さ。同じ音は つる）。
- **旭→朝暉**：DIFF-028（日→暉、読みは理の言葉なので あさひ のまま）の前例どおり。旭市（千葉）・朝日町 と読みが同じになるのは前例と同じ扱い。
- **緑→萌**：緑 は理の言葉に近い（色）。同じ意味の字 翠 は、広島市南区に町域 翠（みどり）がある（DIFF-048 で鯉洲市にも区はないが、字が同じ）ので次点。萌（萌え出る緑）は町域 0。
- **青葉→碧葉**：青→碧 は 青森県＝碧林県 の前例。読みは へきよう（あおば は避ける、DIFF-043）。
- **栄→賑**：一字の瑞祥の名はどれも町域に当たる（昌・繁・盛・暁 なども当たる。盛 は 大船渡市 盛町・盛駅）。賑 は 町域 賑町 が3つ（町域どうしなら DIFF-045 で許すが、区の名と町域の重なりをどう見るかは Gin に）。二字の 隆盛 は 西郷隆盛 を思わせる（人の名、DIFF-035）ので外した。
  - 栄区 は 供苗町（公田町）の親。推しなら **おうはま市賑区供苗町**。
- **金沢→鉄渓**：石川の 金沢市 は 洗砂市（金洗いの沢の伝説）で、横浜の 金沢 は砂鉄の説から別に作る（DIFF-037）。金→鉄、沢→渓。
- **保土ケ谷→窪ヶ渓**：古語 ホト（くぼ地）の説から 窪、谷→渓。くぼがたに は5拍（元4拍、DIFF-043 の ±1 の内。ただし5拍は避けられないときだけ）。窪渓（くぼたに、4拍）は 高知県檮原町 久保谷 と読みが同じ。古い書き方 程ヶ谷・榛谷 は過去の名（DIFF-021）なので使わない。
- **磯子→汐子**：磯（いそ）を 汐（しお、塩→汐 の前例）に。外した：浜子（青森・千葉・富山に町域）、礁子（橿原市 小綱町 と読みが同じ）、岩子・巌子（那須烏山市 岩子）。
- **戸塚→扉丘**：戸→扉、塚（古墳・塚）→丘。門丘 は 戸→門。
- **瀬谷→狭渓**：狭谷（せや）の説から 狭、谷→渓。さけい（3拍、元2拍＋1）。細渓（ほそたに）は 京丹波町 細谷 と読みが同じ。瀬 は 仏名瀬・瀬端 に使っているので、ここでは使わない。
- **都筑→宮築**：都（みやこ）→宮、筑→築（きずく、「都を筑く」の願いから）。旧都筑郡 は過去の名（DIFF-021）。都築（つづき）は 都筑 の別の書き方なので外した。
- **神奈川→仏名瀬**：県名 仏名瀬 のもとが 神奈川宿・湊（この区）なので、県名と同じ名にする（現実と同じ形、DIFF-030 の筋）。

## 2. 気がかり（C5・Gin に）
1. 区の名と、ほかの市の町域が同じ字（賑・翠 など）になるのを許すか。
2. 埠区（1拍）を名古屋・大阪の 港区 にも当ててよいか。
3. DIFF-048 でそろえる名（萌・朝暉・清湧・碧葉・鶴廻）は、横浜の由来（公募・瑞祥）で作っている。仙台の 青葉・泉 のように由来が違う市があるので、Gin が「そろえる」を由来より先に置くか。
4. 鶴廻 の つるわ は、ほかの読み（つるまわり）もできる。ルビがいる。
