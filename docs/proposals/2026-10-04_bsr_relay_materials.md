## 2. テロップの形の案（ALM が決める材料）

テロップは「名前 17ch 497.143MHz」の形で、ch と中心周波数を添えて流れる（ALM 総監督）。

1. **局の名前だけ**：「軒結高田 18」でなく「○○ 18」。短い。ただ、どの市かは分からない。
2. **現実と同じ並び**：現実の局名がすでに「糸魚川大野」「柏崎鯖石」のように市＋地区の所だけ重ねる。ほかは局の名前だけ。現実のテロップに近い。
3. **すべて「（市の名前）○○」**：場所は一番分かりやすい。一行が長くなり、親の名前（13）を先に全部決める必要がある。

HNS-Orc の見方：2 が現実の手触りに近く、決める名前の数も少ない。ただ、2 でも「糸魚川」「津南」「柏崎」「小千谷」「関川」は親の名前が要る。

## 3. 決める名前の数（目安）

- 親の市町村：13（うち局名にも出るのは 村上・津南・湯沢・糸魚川・関川・小千谷 ほか）
- 局の地区・旧町村の名前：約40
- 同じ型で重なるもの：数＋日＋町（六日町＝什旭町の型）、黒川（墨河の前例）、越路（避けた経緯）、大和（国の名の広貴と字が同じ）

## 4. 段取りの案

1. 親の市町村13の候補（E5）→ NG の査読 → Gin の裁定（ALM 側）。
2. 局の地区名の候補（E5）→ NG → Gin。
3. 新津はりゅうと市の中なので Gin に直接。
4. 牛野尾谷・宮古木の場所を確かめる（未確認のまま推測で埋めない、RUL-020）。
