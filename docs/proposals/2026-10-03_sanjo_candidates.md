## 1. 三条の材料（元のページで確認）

- 古い呼び名：「越後三条庄」「三条七日市場」が中世前期の史料に見える。室町時代以降は三条長尾氏の城下町。江戸初期の廃城後は、信濃川の河港・宿場町・市場町として発達した（コトバンク「三条市」本文）。→ どれも「三条」を含むので、G-01 で採ると実在の名前のまま（RUL-017：却下）になる。対字置換（DIFF-016）で組み立てる。
- 「三条は『商人の町』、燕は『職人の町』とも称される」（Wikipedia「三条市」本文）。
- 17世紀初め、代官・大谷清兵衛が江戸から和釘の鍛冶職人を招いたのが三条鍛冶の始まり（同）。
- 寺：本成寺（法華宗陣門流総本山）、真宗大谷派三条別院（同）。
- 燕三条駅・三条燕インターチェンジは、名前をめぐって論争があった（同）。

## 2. 組み立ての考え方

- 「三」を他の数に替えると、京都の通り名（一条・二条・四条・五条…）と著名地名の衝突（C-03）が起きやすい。数を大きく・小さくする置き換えは、規模の対（C-06）にも近づく。→ **「三」は残し、「条」を替える。**
- 「条」と対になる字は「**坊**」。条坊制は「南北の大路（坊）と東西の大路（条）を碁盤の目状に組み合わせた」（Wikipedia「条坊制」本文）。東西と南北の対なので、格・規模の対ではない（C-06 に当たらない）。

## 3. 候補ごとの一次チェック

### S1 三坊（さんぼう）── 推奨

| 検査 | 結果 |
|---|---|
| C-01 | 「三坊」という駅は知らない。全国駅名リストとの機械照合はしていない＝未確認 |
| C-02 | 国土地理院の住所検索で「三坊」をそのまま含む地名は出てこなかった（町名を拾いきれないことがある＝未確認） |
| C-04 | 「**三宝**（さんぼう、さんぽう）」と同じ音。仏教でいう「仏・法・僧」の三つの宝（Wikipedia「三宝」本文）。意味は良い。三条には本成寺・三条別院があり、寺の町でもある。五国府と後光の前例のように、**掛詞として由来メモに書ける**＝記録（意図する場合は Gin の判断） |
| C-05 | なし。「坊」には「坊や」「坊主」の語感もあるが、侮る含意はない＝記録 |
| C-06 | 条⇔坊は東西と南北の対で、格・規模の対ではない＝合 |
| C-07 | 4モーラ。字面から読める |
| C-08 | 兄弟（柳都県の町）の読みとの重なりなし（すずめし・とおおか・じゅうくまちし・やしろぎ・りゅうと）。「坊」は寺の宿坊の意味も持ち、寺の町という実態と合う |

**派生（実態に即す：RUL-013）**：
- 燕三条駅 → **雀三坊駅**（すずめさんぼう、7モーラ）
- 三条燕インターチェンジ → 三坊雀インターチェンジ
- 現実の「名前の順番の論争」も、そのまま本世界に写せる。

**由来メモ（案）**：
> 三坊は、現実の地名「三条」の「条」を、条坊制で対になる「坊」に置き換えた名前である（DIFF-016）。坊は寺の宿坊にも通じ、本成寺・別院の寺町という土地柄に合う。

### S2 三筋（みすじ）── 否寄り

- C-02・C-03：**東京都台東区三筋**（ミスジ、〒111-0055、日本郵便で確認）と、字も音も同じ。自治体名ではない町名だが、実在の町名と完全に一致する＝否寄り。
- C-04：牛肉の部位「ミスジ」と同じ音（私の知識、未確認）＝記録。

### S3 三縄（みなわ）── 否

- C-01：**三縄駅**（みなわ）が実在する。徳島県三好市池田町中西、JR四国土讃線（Wikipedia「三縄駅」本文）。駅名と完全に一致する＝**否**。
