## 0. Gin の言葉から立てた三つのねらい
1. **一度したことを、すぐ引ける**（決めた名・外した名・決まり・前例・かごの中身）。
2. **分からないことは分からない、ない とは言い切らない**。
3. **積み重ねる**（同じ見落としを二度しない形で残る）。

## 1. たたき台
### 1-1. 引き口の道具（ねらい 1）
- `node scripts/lookup.js <字・名・読み>`：正本・pending_items・review_dictionary・kago・tsunagari・提案書・査読を **全部** 引き、当たった行を **切らずに** 出す。
- 出し方：もと（ファイルと行）ごとにまとめ、**決めた名／外した名（prev・外した案・review_dictionary）／決まり（DIFF・RUL）／かご／提案・査読** に分ける。
- 字の別の形も一緒に引く（沢・澤、旧字・異体字、ひらがな・カタカナの読み）。
- 出力の終わりに **「引いた範囲」**（どのファイルを、どの commit で）を必ず書く。
- 照らしの道具（郵便番号・地理院・Wikipedia・weblio。今は G5 の一時フォルダの lite・homo・muni）を scripts/ に移す。郵便番号データの場所は引数か環境変数で、中身は commit しない（M4 の足し 1）。拍の数えと「元と同じ拍 n/m」も出す（M4 の足し 5）。

### 1-2. 言い切りの決まり（ねらい 2）
三人の文（提案・査読・送る文）で、ある・ない を言うときは三つの言い方だけにする。
| 言い方 | 使うとき | 書き方の例 |
|---|---|---|
| **確かめた** | 出典を見た | 「正本 582 行の notes に〜とある」「ja.wikipedia『平安京』（2026-10-24）」 |
| **引いて 0** | 道具で引いて当たりがなかった | 「lookup で 0（正本・pending・review_dictionary・kago・提案・査読、commit abc1234）」 |
| **調べていない／見つけていない** | それ以外のすべて | 「調べていない」「G5 の知識、確かめていない」 |
- 「ない」「先例はない」「〜とは読まない」は、**引いて 0 の形でしか書かない**。範囲を書けないなら「見つけていない」。
- 先例として引く前に、**その行の rule・notes・prev を最後まで読み、元の名にその字があるかを確かめる**（今日の 京鹿 の件）。

### 1-3. 前例の索引（ねらい 1・3）
- 正本の行から「現実の字 → 作中の字、どの名で、どの行」を機械で拾った索引を、**char_defaults とは別に** 置く（M4 の足し 2。char_defaults は機械で当たる既定なので、上げる行は Gin が一つずつ決める）。
- 置き場所の案：`docs/precedent_index.md`（生成物。手で直さず、scripts で作り直す）。

### 1-4. 外した名の写し（ねらい 1）
- review_dictionary に、正本の prev・外した案 を写す。写しには **もとの行への道**（real と、どの行の prev か外した案か）と **写しの印** をつける。元は正本（M4 の足し 3）。

### 1-5. 積み重ね（ねらい 3）
- **見落としを試験にする**：今日の見落としを lookup の試験に入れ、出なければ失敗にする。
  - 京鹿 → 正本 582 行の notes「京→都の置き換えとは別」が出る
  - 上ノ道 → 正本 541〜543・588 行が出る（上ノ道市 の review_dictionary も別に出る）
  - 楊湊・参瀬・珠河 → 外した記録が出る
  - 渡前 → 郵便番号データの町域（鶴岡市・三条市）が出る
  - 潮澤 → 5拍・元と同じ拍 4/4 が出る（M4 の件）
- 新しい見落としが見つかったら、そのたびに試験を一つ足す。
- 始めの手順（かごを読む、名を出す前・先例を引く前に lookup を通す）は、**文の案まで**。各セッションの CLAUDE.md・hooks・設定への書き入れは Gin が決める（M4 の足し 4）。

## 2. 受け持ちの案
| 仕事 | 案 |
|---|---|
| lookup.js・照らしの道具を scripts/ に・試験 | G5 が作る |
| 査読（道具の出力が正しいか、試験が見落としを捕まえるか） | C5 |
| 置き場所（索引・写しの印）・正本との合わせ・登録 | M4 |
| 決める（始めの手順を各セッションに入れるか、索引から char_defaults に上げる行） | Gin |

## 3. 二人に聞きたいこと
1. ねらい三つの立て方は、Gin の言葉に合っているか。足すもの・削るもの。
2. 言い切りの決まり（1-2）の三つの言い方で足りるか。査読でこれを見る項目にできるか（C5）。
3. 前例の索引と写しの置き場所（1-3・1-4）（M4）。
4. 試験に入れる見落とし（1-5）で、二人の側に今日以外のものがあれば。
5. 受け持ち（§2）。
