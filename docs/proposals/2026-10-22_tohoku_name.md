## 2. 一つずつ
- **柵北**：
  - DIFF-019（元の名を使わずに場所が浮かぶか）：柵東（関東）が正本にあるので、「柵の東」と「柵の北」で二つの地方が並んで見える。
  - 4拍（元 とうほく 4拍）。元と同じ音 ほく（方角の 北 は残る字、DIFF-026）。
  - 気がかり：柵 は FTV の 東柵石 など局の名にも使っている（字が並ぶだけ）。柵東 の 柵 は 関 から、柵北 の 柵 も 関（白河の関）から、で筋はそろう。
- **日高見**：
  - 典拠がある（コトバンク・日本歴史地名大系の解説）。ただし **文献ごとに指す所が違う**：大祓詞では「大倭日高見国」で大和（日本ぜんたい）の美称、常陸国風土記では常陸の信太郡。常陸（＝永陸）の名の語源とする説もある。東北の名とするのは、景行紀と北上川下流域の説による。
  - 字の 日高 は 日高市（埼玉）・日高町・日高郡 などと同じ二字（日高見 としては 0）。
  - 4拍。元と同じ音なし。
- **奥路**：
  - 七道の型（雪路・嶺路）にそろう。東北はもと東山道（嶺路）の奥なので、嶺路 と並べても筋が通る。
  - 3拍（−1）。元と同じ音なし。
  - 気がかり：奥 は 奥州（奥州市）・奥羽 の 奥 と同じ字（字が一つ同じだけ。奥路 は 0）。
