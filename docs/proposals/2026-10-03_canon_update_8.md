## NG の査読（2026-10-03、HNS-NG §、全文は NG の PC の docs/reviews/2026-10-03_review_canon_update_8_NG.md）

判定：**受け入れ可**。条件：読み「ばんりゅう」をルビで固定。住所検索で「磐柳」「ばんりゅう」0件。旧国名の線（1 okです）の上。RUL-015 の「柳」で東柳新幹線と同じ組み方。略称「西線」「東線」も残る。
記録：
1. 「ばんりゅう」は蟠竜・盤竜（とぐろを巻く竜）と同じ音。よい連想。
2. 磐浜（いわ）と磐柳（ばん）で「磐」の読みが二つ。現実の磐城／磐越と同じ。
3. 磐柳東線は柳都県に入らない（現実の磐越東線も福島の中だけ）。由来メモに「一つの計画の東西の名残」と一行。
4. if（若松県）では、西線は三県をまたぐ（県境は現実と同じなので、禄嶋〈中通り・相津〉→柳都県の二県）。
5. 磐越自動車道は磐柳自動車道の見込み。

正本に入れるのは Gin の一言のあと。
