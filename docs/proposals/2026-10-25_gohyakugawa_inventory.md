## 2. 五百川の束（頼み 2）
### 2-1. 確かめたこと
- 五百川（ごひゃくがわ）：郡山市北西部の奥羽山脈東麓から東へ、磐梯熱海温泉を流れ下り、石筵川を合わせ、磐越自動車道の五百川 PA 付近から郡山市と本宮市の境になって阿武隈川へ（ja.wikipedia「五百川」）。

- 五百川原（会津美里町）：**読みは ごひゃくがわはら**（Mapion の住所の読み「…ひがしおまたごひゃくがわはら」。東尾岐 の中の小字。出どころはこの一件だけ）。郵便番号データにはない（小字）。
- 郵便番号データの 五百川：**三条市 北五百川・南五百川（きたいもがわ・みなみいもがわ）** の 2 町域。読みが いもがわ で別の土地。同じ字の名は一括（DIFF-045）なので、同じ字の束に入る。

## 6. 河東（Gin「2,河東は川東になるのかな、もうありそうだけど」2026-10-25）
- 伍百河 にして 川→河 を字の表に入れると、字の表の組はすべて入れ替え（DIFF-050）なので、逆の **河→川** も当たる。すると 河東 は **川東** になる。
- 郵便番号データ：**河東** を含む町域 25（会津若松市 河東町〇〇 の 16 ほか、周南市 河東町・宗像市 河東・白川町 河東・昭和町 上河東 など）、市町村 4（北海道 **河東郡** 上士幌町・士幌町・音更町・鹿追町）。**川東** そのものの町域が **すでに 8**（北見市・洞爺湖町・伊賀市・美作市・北広島町・まんのう町・東かがわ市・東串良町）。Gin の見立てどおり、川東 は現実にある。
- なので 伍百河 の道（川→河 を字の表に）を取ると、河東郡・河東町 が現実の 川東 と字が重なる。伍百川 の道（川 を残す、川→河 は名ごと）なら、河東 はこの件では動かない。

## 7. C5 の査読（docs/reviews/2026-10-25_review_gohyakugawa_rulecheck_C5.md）と G5
- 試験 5 通過・R1 5 名を C5 の PC で確かめた。
- 道具：R1 は「現実の X が X のまま」だけで、**逆向き（作中の Y の元が字の表の X 以外：磯瀬郡＝岩→磯、珠沢＝川→沢）を見ていない**。R5 として足すか、S3（前例の索引）でまとめるか → G5：S3 でまとめる（作中の字ごとに元を並べる索引の仕事）。単語の表の読み条件（温泉＝おんせん のときだけ）は rule-check では見ていない → 温泉津 の試験を N1 に入れる。R4 の芯：DIFF-043 は「町・村・市など」なので、通・駅・線 を芯から除くかを Gin に。「notes に例外 0」は、外れの理由が notes に無いからで、足していけば減る。
- 川・河：川 を残した 14 名は、前の字が替わって名全体が元から離れている。伍百川 は字も読みもほぼ元のままで状況が違うので、**伍百河 も同じ重さで Gin に並べる**（C5）。G5 も受ける。§6 の 河東→川東 の件は 伍百河 の側の重さ。
- 伍百川野（原→野）に C5 も賛成。北五百川・南五百川 は いも の **ルビ必須** を行に書く。
