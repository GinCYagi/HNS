## 決まっている型

- 旧国名は部品として使える。現役の路線名にはそのまま当てない（Gin「1 okです」）。
- 路線名の「都」は東都なので、柳都は「柳」（RUL-015。東柳新幹線・磐柳西線）。
- 磐越西線＝磐柳西線（磐＝磐浜の1字＋柳）の型。読みは「ばん（音）＋りゅう（音）」。

HNS-Rev の推し：
- **信越本線＝科柳本線**（ルビ必須）。
- **越後線＝柳越線**。
- **羽越本線は、出羽側（山形・秋田）の名前を先に**。いわきを先に決めたのと同じ順（Gin「だからいわきをどうするかを先に決めないと」）。

## NG の査読（2026-10-03。全文は NG の PC の docs/reviews/2026-10-03_review_zairaisen_NG.md）

- **科柳本線**：条件付き（ルビ必須）。完全一致なし。長野と新潟を結ぶ線そのものの名で、組み立ては良い。記録（新しく見つけたこと）：「かりゅう」と読まれると「花柳（かりゅう）」＝花柳界の語と同じ音（OpenPOI で「花柳」で始まる店24件）。下流・河流とも同音。ルビを固定すれば出ないが、読み違えたときの音が重い。
- **柳越線**：受け入れ可の見込み。完全一致なし。「越」は旧国名の部品の線の上（越路は今の地名だから外しただけで、「越」の字は外していない）。「やなぎごえ」とも読めるので初出ルビ。
- **羽柳**：否寄り（雨竜〈町・川・沼・道の駅〉、瓜生と同音）。出羽を先に決める判断は P-02 に合う。

## 科柳本線の読み（Gin、2026-10-03、原文）

「柳科にしたら長野の人おこるかな」（HNS-Rev：現実の上越・信越・磐越・羽越は越〈新潟〉が後ろ、東柳・磐柳も柳が後ろ。科柳のままがそろう）→「**やなぎ読みから 科柳本線 しなぎほんせん は？**」

- 組み立て：しな（科）＋やなぎ（柳）の重なる「な」をつなげて「しなぎ」。当て字・縮め読み（DIFF-018：ルビ必須、わけを記録）。
- よい点：「かりゅう」（花柳・下流）と読まれる心配がなくなる。「しなぎ」は、科坂の由来「科（しな）の木」＝シナノキの音にも近い。
- 一次チェック（Wikipedia 全文検索）：「しなぎ」9件（作品名・人名の中の音で、地名ではない）。記録：群馬の「品木ダム」（しなき、字は違う）、魚の「イシナギ」。
- NG に査読を頼む。

### NG の照らし直し（しなぎ、2026-10-03。全文は NG の PC の査読の文書 §6）

条件付き。
- 花柳の心配は消えた。住所検索で「しなぎ」完全一致なし。
- 記録（新しく見つけたこと）：「品木」の地名6件（品木・品木ダム〈しなき、群馬〉、品木島、**品木沢〈新潟＝柳都県の中、15225。読みは未確認〉**）。清濁違い・音の頭が同じ。
- 条件：「柳＝ぎ」は字面から推せないので、ルビ必須。わけ（しな＋やなぎを「な」でつなぐ）を記録。
- 記録：正本の路線名の「柳」は東柳（とうりゅう）・磐柳（ばんりゅう）と、どれも「りゅう」。科柳だけ「ぎ」になるので「しなりゅう／かりゅう」と読まれやすい。違反ではないが、ルビで補う。
- よい連想：しなぎは「しなの」に近い音。
- 柳越線は前のとおり、受け入れ可の見込み。

## 坂柳本線（Gin の案、2026-10-03、原文）

「坂柳本線　ばんりゅうほんせん」→ HNS-Rev：磐柳西線（ばんりゅうさいせん）と読みが同じ、坂の音読みはハン → Gin「坂下　とかいて　ばんげ　と言う地名が会津にあります」（会津坂下町。坂＝ばんの読みは実在、HNS-Rev の「はん」の指摘は取り下げ）「初見の人はまず読めませんが……さかしたとよみます」「**あー　丸かぶりはNGだね**」
→ **坂柳本線は採らない**（磐柳西線と読みが丸かぶり。C-08）。信越本線は科柳本線の読み（しなぎ／しなりゅう）を Gin が選ぶ。

## 越後線：ひらがなルート（Gin、2026-10-03、原文）

「標柳線　しりゅうせん　は？」（HNS-Rev：支流と同音、標＝し は当て字）→「(ほくほく線)ルートは？」「ひらがなルート、と言うことです」「地名由来ではなく全く新しい語呂の良い言葉にしてしまうルートです」
