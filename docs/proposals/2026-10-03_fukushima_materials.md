## 2. 地域の呼び分け「左・正・右」（新潟方式）

- **新潟方式**：越後国を「上方に近い南側から順に上越地方・中越地方・下越地方」と分けた（Wikipedia「上越市」本文）。上・中・下＋「越」（越後の一字）。
- **福島に当てる**：左・正・右＋（福島）の一字。
  - 「左」「右」は、京の左京・右京と同じく、南を向いたときの左右とする。「『左京』とは、天皇の在所すなわち御所から見て左側の意。天皇は南面して高御座に座っていたので左は東になる」（Wikipedia「左京区」本文）。

| 現実の地域 | 位置 | 本世界の呼び名（形） |
|---|---|---|
| 浜通り | 東（太平洋側） | **左**〇 |
| 中通り | 中 | **正**〇 |
| 会津 | 西 | **右**〇 |

- 〇は、（福島）の HNS 名の一字。だから **（福島）を先に決める**（P-02：親から。Gin「(福島)を決めないと使えないけど」）。
- 会津はすでに「相津」（正本で採用済み）。新潟で「上越」と「高田・直江津」が並ぶように、「右〇」（地方の呼び名）と「相津」（土地の名前）は並んで使える、と HNS-Rev-local は見ている。

## 3. （福島）の名前の材料

| 材料 | 内容（元のページの本文） | 使えるか（一次の見立て） |
|---|---|---|
| 福島の名の由来 | 安土桃山時代に、蒲生氏郷または木村吉清が「それまでの杉妻を縁起の良さそうな福島と改名した」という説が有力（Wikipedia「福島市」） | 「縁起の良い字」という由来は、対字置換（DIFF-016）の手がかりになる（例：福→同じ意味の字） |
| 杉妻（すぎのめ／すぎつま） | 福島と改める前の名前（同） | 福島市にいまも「杉妻町」がある（私の知識。未確認）。実在の町名と重なるなら使えない（RUL-017） |
| 岑越（みねこし） | 「古代には、福島市地域の代表的な地名は岑越（みねこし）と呼ばれており、現在の信夫山も岑越山と呼ばれていた」（同） | 古称（G-01）。ただし「越」が越後・越路の「越」と重なる。「岑」は読みにくい |
| 信夫（しのぶ） | 律令の信夫郡（同）。信夫山 | 古称（G-01）。いまも信夫山の名が残る |
| 岩代国 | 明治元年に陸奥国から分立。「会津の全域と中通りの北部」。別称は岩州（Wikipedia「岩代国」） | 旧国名。県の一部（西半分）だけ |
| 磐城国 | 同じとき分立。浜通りと中通り南部 | 旧国名。「磐」は（いわき）の磐浜で部品として使う方向 |

- 福島県は、岩代と磐城の二つの旧国にまたがる。旧国名だけでは県全体を一つの名で呼べない（DIFF-019 の物差し：元の名前を使わずに、どれだけその場所を想像できるか）。
