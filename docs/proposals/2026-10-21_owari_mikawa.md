|---|---|---|---|

## 1. 材料

- 尾張：7世紀後半の木簡に「尾張」と「尾治」の二つの書き方がある（Wikipedia「尾張国」）。→ 尾治 は昔に使われた書き方なので使わない（DIFF-021）。
- 三河：古事記に「三川」、7世紀の木簡も「三川国」、律令から平城京までは「参河」、長岡京のあとは「三河」。万葉集には「水河」とも。名の由来は不明（三つの大きな川の説ほか。Wikipedia「三河国」）。→ 三川・参河・水河 は昔の書き方なので使わない（DIFF-021）。参 を使うなら、河 は替える。

## 5. 二つの旧国名を合わせた名（DIFF-044）

- 「尾三（びさん）」のように 尾張＋三河 を合わせた名があれば、DIFF-044 で作る：尾展 の 尾 は元の 尾 と同じ字なので 展、参瀬 の 参 は元の 三 と同じ音なので 瀬 → **展瀬（てんせ）**。
- 記録：尾三 という名が今どこで使われているか（組合・地区の名など）は、G5 は確かめていない。【要照合】
- 三遠（三河＋遠江）・三遠南信 などは、遠江・信濃 の日ノ本名（信濃＝科坂は県の名）が要る。

## 6. 鮎潟県・金之鯱市とのつながり

- 鮎潟県（愛知県）＝ 尾展（西）＋ 参瀬（東）。国の層の二つの国が、県の中に並ぶ（現実の愛知県＝尾張＋三河と同じ）。
- 県名のもとの 年魚市潟 は、尾張の南東（今の熱田区から南区）にあった（Wikipedia「年魚市潟」）。→ 鮎潟 は 尾展 の中の干潟の名。
- 金之鯱市（名古屋市）は 尾展 の中。金の鯱 は 尾張 の名古屋城のもの。
- 県・市の名に、旧国名の字（尾・張・三・河）は入っていない。

## 7. 気がかり（C5 に見てほしいこと）

1. 尾展 は 美点、参瀬 は 賛成 に近い音。
2. 参瀬 の 河→瀬 は、理の字の置き換え（DIFF-028）として通るか。
3. §4 の地名の実在と、尾三 の今の使われ方は確かめていない。

→ HNS-C5 の査読（docs/reviews/2026-10-21_review_owari_mikawa_C5.md）：尾展・参瀬は見立てとして受け入れ可（推し）。河→瀬は近い字として許す。Gin に見てもらう点：(1) びてん は「美点」と同じ音の普通の語。(2) 参瀬 の 参 を さん と読むので、三河 の 三（み）の読みが残らない。DIFF-042「読みは元の数の読みのまま」に当たるか。
→ G5 の記録（(2) について）：正本の前例は二通りある。
- 読みを元のまま：弐本樅（にほんもみ）・参馨（みかおり、三春 の み のまま）。
- 読みが さん に替わった：**参洲町（さんすまち、三島町 みしま）**・参坊（さんぼう、三条市 さんじょう は元も さん）。参洲 は DIFF-042（2026-10-09）のあと、2026-10-11 にまとめて採用されている。
- DIFF-042 どおり み と読むと、参瀬＝**みせ**（「店」と同じ音）になる。G5 は、参洲 の前例に合わせて さんせ を推す。どちらにするかは Gin。
