- 三河：古事記に「三川」、7世紀の木簡も「三川国」、律令から平城京までは「参河」、長岡京のあとは「三河」。万葉集には「水河」とも。名の由来は不明（三つの大きな川の説ほか。Wikipedia「三河国」）。→ 三川・参河・水河 は昔の書き方なので使わない（DIFF-021）。参 を使うなら、河 は替える。

## 5. 二つの旧国名を合わせた名（DIFF-044）

- 「尾三（びさん）」のように 尾張＋三河 を合わせた名があれば、DIFF-044 で作る：尾展 の 尾 は元の 尾 と同じ字なので 展、参瀬 の 参 は元の 三 と同じ音なので 瀬 → **展瀬（てんせ）**。
- 記録：尾三 という名が今どこで使われているか（組合・地区の名など）は、G5 は確かめていない。【要照合】
- 三遠（三河＋遠江）・三遠南信 などは、遠江・信濃 の日ノ本名（信濃＝科坂は県の名）が要る。

## 6. 鮎潟県・金之鯱市とのつながり

- 鮎潟県（愛知県）＝ 尾展（西）＋ 参瀬（東）。国の層の二つの国が、県の中に並ぶ（現実の愛知県＝尾張＋三河と同じ）。
- 県名のもとの 年魚市潟 は、尾張の南東（今の熱田区から南区）にあった（Wikipedia「年魚市潟」）。→ 鮎潟 は 尾展 の中の干潟の名。
- 金之鯱市（名古屋市）は 尾展 の中。金の鯱 は 尾張 の名古屋城のもの。
- 県・市の名に、旧国名の字（尾・張・三・河）は入っていない。

## 7. 気がかり（C5 に見てほしいこと）

1. 尾展 は 美点、参瀬 は 賛成 に近い音。
2. 参瀬 の 河→瀬 は、理の字の置き換え（DIFF-028）として通るか。
3. §4 の地名の実在と、尾三 の今の使われ方は確かめていない。

→ HNS-C5 の査読（docs/reviews/2026-10-21_review_owari_mikawa_C5.md）：尾展・参瀬は見立てとして受け入れ可（推し）。河→瀬は近い字として許す。Gin に見てもらう点：(1) びてん は「美点」と同じ音の普通の語。(2) 参瀬 の 参 を さん と読むので、三河 の 三（み）の読みが残らない。DIFF-042「読みは元の数の読みのまま」に当たるか。
→ G5 の記録（(2) について）：正本の前例は二通りある。
- 読みを元のまま：弐本樅（にほんもみ）・参馨（みかおり、三春 の み のまま）。
- 読みが さん に替わった：**参洲町（さんすまち、三島町 みしま）**・参坊（さんぼう、三条市 さんじょう は元も さん）。参洲 は DIFF-042（2026-10-09）のあと、2026-10-11 にまとめて採用されている。
- DIFF-042 どおり み と読むと、参瀬＝**みせ**（「店」と同じ音）になる。G5 は、参洲 の前例に合わせて さんせ を推す。どちらにするかは Gin。

### 参 の読みのそろえ方（G5 の見立て）
- 正本の 参 は四つ：参馨（三春、みかおり）・参坊（三条、さんぼう）・参洲（三島、さんす）・参瀬（案）。
- DIFF-042 の決まりは「読みは元の数の読みのまま」。元が み なら み、さん なら さん：
  - 参馨（三春 みはる → み）：合っている。
  - 参坊（三条 さんじょう → さん）：合っている。
  - 参洲（三島 みしま → さん）：**合っていない**。みつす に直すと合う（みつ は 三つ の訓で、み の読みの側）。
- → 見立て：**「参 は、元の三の読みに合わせて読む。元が み なら み か みつ、元が さん なら さん」**。新しい決まりではなく、DIFF-042 の読みの決まりを、み と みつ の両方を許す形で書き足すもの。
- 三河 は元が み なので、参瀬 は みつせ（または み）。みせ（店）を避けるなら みつせ。ただ みつせ は白山市三ツ瀬町と同じ読みなので、Gin が許すか、参渓（みつたに）にするか。

## 9. 尾張＝尾伸（おのび）の検討（Gin「おのびからけんとう」2026-10-21、HNS-M4 の連絡）

経緯（Gin、HNS-M4 のセッション）：「尾伸市(おのびし)」→「尾伸旭市?」→「理には入らない？ 太陽」→「じゃあ尾伸日市？読めないけど」→「おのびからけんとう」。

### 1. 「おのび」の重なり（G5、2026-10-21）
- 郵便番号データ：町域の字（尾伸）・読み（オノビ）とも 0。市町村 0。国土地理院の住所検索 0。Wikipedia の記事 0。
- Web 検索：「おのび」の語・会社名は見つからなかった。近いものに、鬼火（おにび、1音違い）、のびのび（副詞）、株式会社おのの（ONONO）、株式会社のびのび（山形県東根市）。（Web 検索の要約による。会社の実在は、その先のページまでは開いていない）
- 聞き違え：「尾の火」「お伸び」と聞こえる余地はある（G5 の見立て）。
- 正本：尾伸・おのび とも 0。

### 2. 字の意味の筋
- 尾張 の 張（はる・ひろがる）→ 伸（のびる）。どちらも「長く・広く のびる」。DIFF-016 の近い字。尾 は残す（永陸 の 陸、磐汀 の 磐 と同じ一字残し）。
- 尾 も 張 も理の字ではないので、DIFF-028 は当たらない。RUL-023 は旧国名を含む今の地名の替え方の決まりで、旧国名そのものの作り方ではない。
- 読み：尾（お、訓）＋伸（のび、訓）の **訓訓**。湯桶読み・重箱読みではない。
- 拍：3（お・の・び）。元の おわり と同じ。元と同じ音は お。
- 記録：前の旧国名は音読み（ばんてい・えいりく・てんだ）。おのび は訓読みで、ここだけ型が違う。

### 3. 尾張旭市への当て方
- RUL-023 ②：尾張 の部分を 尾伸 に、旭 の部分を日ノ本名に。
- 旭 は「朝の日」で、正本には **朝日 → 朝暉（あさひ）** の前例がある（朝日中継局＝朝暉）。同じ意味の字で、読みは残す（DIFF-021 の追記：理の言葉で読みが同じになるものは、それだけを理由に替えない）。

| **尾伸朝暉市** | おのびあさひし（6、元の おわりあさひ と同じ） | 字 0。朝暉 の字の町域 0。読み あさひ は町域・市町村に多い（旭市・横浜市旭区・朝日町ほか） | **推し**。朝暉 は正本の前例の字 |
| 尾伸朝陽市 | おのびあさひし | **朝陽 の字は 坂井市丸岡町朝陽、常滑市大谷朝陽ケ丘（愛知の中）** | 否寄り |
| 尾伸日市 | おのびひし? | — | Gin「読めないけど」。読みが定まらない |
- 記録：朝暉 は柳都の中継局の名にもある（同じ字が二か所。尾伸朝暉 は組の名なので、紛れは小さいと見る）。

## 10. 三河＝参淵（みぶち）の検討（Gin「参淵(みぶち)は？」2026-10-21、HNS-M4 の連絡）

### 1. 「みぶち」の重なり（G5、2026-10-21）
- 郵便番号データ：参淵（ミブチ）は町域・市町村とも 0。ただし、町域の読みの一部に **広島県三次市 作木町岡三渕（さくぎちょうおかみぶち）** がある（字も 三渕）。字の 三渕 は ほかに 新潟県魚沼市 三渕沢（みふちさわ）。国土地理院の住所検索に「三淵山」1。
- **人名**：**三淵嘉子（みぶち よしこ、1914〜1984）**。国立国会図書館の典拠データで読み「ミブチ, ヨシコ」（https://id.ndl.go.jp/auth/ndlna/00043037 ）。名古屋市の資料に、ドラマ「虎に翼」の主人公のモデルで、1952年12月から1956年4月まで **名古屋地方裁判所の判事** を務めたとある（https://www.city.nagoya.jp/somu/cmsfiles/contents/0000176/176541/gonnnai.pdf ）。→ 同じ音の名の人が、ちょうど同じ土地（鮎潟県・金之鯱市）にゆかりがある。正本 docs/proposals/2026-10-01_ryuto_stations_lines.md:181 でも、三川の案 三淵（みぶち）を三淵嘉子と重なるとして記録している（同じ点）。
- 名字としての 三淵・三渕 の分布、会社名は、Web 検索では見つからなかった（調べ切れていない）。

### 2. 参 を み と読むのは DIFF-042 に合うか
- 合う。元の 三河 の 三 は み。正本の 参馨（三春、みかおり）と同じ読ませ方。§8 の見立て「元が み なら み か みつ」の み の側。参洲町＝みつすまち（みつ の側）とも矛盾しない。

### 3. 字・読みの筋
- 河→淵：正本の前例 郡山河内→郷岳淵内（河→淵）。淵 は正本で多い（楊淵・淵南・上淵・郷岳淵内）。
- 読み：参（み、訓）＋淵（ふち→ぶち、訓）の訓訓。尾伸（おのび）と型がそろう。
- 拍：3（み・ぶ・ち）。元の みかわ と同じ。元と同じ音は み。
- 照合の見立て：地名の重なりは小さい（作木町岡三渕 の後ろの一部だけ）。**人名 三淵嘉子 と、名古屋の地裁とのゆかりが重なる点が大きい**。
