## 2. 今ある決まりとぶつからないかの照らし
| 今ある決まり | ぶつかるか |
|---|---|
| HR（Hinomoto Railways）・HHS（Hinomoto Highway Service）・HF（Hinomoto Fisheries）・HOTATE（HinomotO…）・Hi-フォン ほか、英語の名に Hinomoto を使う 12 か所 | ぶつからない。⑥ の改名のあとにできた名として読める（JR の発足 1987 年より前に改名していれば、HR も筋が通る） |
| HI・.hnmt（national_codes） | ぶつからない。自分たちの名から取った符号 |
| 火守道（九州）の history_setting「火山災害と鎮火信仰・祈祷文化の定着を経て『火守道』が正式な行政区分名」 | ぶつからない。火ノ本 はこの信仰の土地の側の書き方として足せる |
| 正本の Japan の字 | 696 行の JF（Japan Fisheries）だけで、現実の名の説明。日ノ本の名には使っていない |
| 日本の型にすると心配した「Jachipan Railways＝JR」 | 起きない。Jachipan は昔の英語の名で、今の会社名は ⑥ のあとの Hinomoto から作る |
- **G5 の見立て：一本につながる（収束する）**。昔の名（ジチパング・Jachipan・Finomoto）は歴史の言葉として残り、今の名と符号は Hinomoto にそろう。日本の Nihon／Nippon／Japan のような「名が入り乱れる」性格も、字二通り・昔の外国名二系統（中国・マレー経由と九州で聞いた形）として持てる。

## 3. 決めること（Gin に）
1. ⑥ の改名の時期（JR の発足〈1987〉より前なら HR と合う。たとえば戦後の国際社会への復帰のころ、など）。
2. 火ノ本 の書き方が使われた時代と場面（火守道の古い書き方、今も九州で使う、など）。
3. ③ と ④ のどちらを Jachipan の元にするか（現実どおり マラッカ経由の Jachipão を英語の元にし、Finomoto は宣教師の辞書の中だけ、を推す）。
4. 3文字の符号 HNM でよいか。
5. 中国語・韓国語など、漢字の国での呼び名（現実の 日本〈リーベン〉にあたるもの。日之本 か 日本 と略すか）は、物語で要るときに。

## 4. 足し：マルコ・ポーロの名＝黄金原（こがねばら）（Gin「黄金の原(黄金原)にするとどう変わる？」「こがねばら」2026-10-23）
- 「黄金の国ジパング」の位置を、音から付いた ジチパング ではなく、意味から付いた **黄金原（こがねばら）** にする。この段だけ **ドイツの型**（外国の人が見た印象・言い伝えで名を付ける）。
- 変わらない所：自分たちの名（ひのもと、日ノ本／火ノ本）、今の英語の正式な名（Hinomoto）、符号（HI・HNM・.hnmt）、英語の会社名。
- 照らし：
  - 読み こがねばら：郵便番号データの町域・市町村に 0。weblio に見出しなし。
  - 字 黄金原：**秋田県湯沢市 黄金原（こがねはら）** の町域、Wikipedia の記事「黄金原駅」がある。読み こがねはら は 千葉県松戸市 小金原 とも同じ。読みを こがねばら（連濁）にしたので、読みは重ならない。字は重なるが、マルコ・ポーロの本の中の外国の呼び名（日ノ本の中の地名ではない）として扱う。
- まだ：ヨーロッパでの呼び名を、マレー語・ポルトガル語経由の音の名（Jachipan）のままにするか、黄金原を訳した名に寄せるか（Gin に）。

## 5. 足し：マルコ・ポーロの名＝フォパング（火本国）で整うかの試し（Gin「火本国だと？」「それで整うか見てみて」2026-10-23）
| 段 | 中身 | 照らし・出典 |
|---|---|---|
| ① 自分たちの名 | ひのもと（日ノ本／火ノ本）。略すと 日本 にあたる **火本**（ノを落とす） | 火本 は町域・住所・記事 0 |
| ② 南の中国の港で | 火守道（九州）の商人の言う 火本国 を、中国語で読む。火＝huǒ（標準）・hé／hóe（閩南語）（Wiktionary「火」） | — |
| ③ マルコ・ポーロ | **Fopangu（フォパング）**。日本国→Cipangu（ジ・パン・グ）と同じ作りで、日の位置に 火（fo） | 同じ名は見つからない。香港・九龍の地名 **Fo Pang（火棚）** と字の並びが近い（英語版 Wikipedia） |
| ④ 言い伝えの言葉 | 「黄金の国ジパング」→ **黄金原（こがねばら）のフォパング**（§4 の 黄金原 は言い伝えの呼び名として残す） | — |
| ⑤ マレー語・ポルトガル語・昔の英語 | 現実と同じ当てはめ方（閩南語 Ji̍t-pún → マレー語 Jepang／Jepun → ポルトガル語 Japão → 英語 Japan）で、閩南語 hé-pún → マレー語 Hepang → ポルトガル語 **Hapão** → 英語 **Hapan** | **気がかり**：タガログ語 **Hapón＝日本**（スペイン語 Japón から。Wiktionary「Hapon」）と一字違い |
| ⑥ 今の英語の正式な名 | **Hinomoto**（Türkiye 型の改名） | §2 のとおり |
| ⑦ 符号 | HI・HNM（案）・.hnmt | §2 のとおり |
- 整うか（G5 の見立て）：**整う**。
  - 火ノ本（①）→ 火本国（②）→ フォパング（③）が一本でつながり、ジパング と同じ4拍・同じ作り。
  - 外国の人が「火」の側の名で日ノ本を覚えた、という筋が、火守道（九州）の設定（火山と鎮火信仰）と、外国船が九州に来た歴史（G5 の知識、確かめていない）の両方に合う。
  - 昔の英語の名 Hapan は H で始まるので、J で始まる現実の名（JR など）ともぶつからない。今の名 Hinomoto・HI・HNM・.hnmt とも頭の H がそろう。
- 残る気がかり：Hapan は、タガログ語で日本を指す Hapón と一字違い。昔の英語の名を作中で使う場面がなければ、記録だけでよい。避けるなら、ポルトガル人が九州でじかに聞いた形 Finomoto（§1 ④）を昔の名に当てる。

## 6. 足し：昔の英語の名は Hapan（Gin「Haponに統一して齟齬が出ないか確認」→ G5 の照らし → Gin「Hapanか」2026-10-23）
- Hapon に統一すると：筋（ポルトガル語 Hapão → スペイン語 Hapón）は合い、今の名・符号・会社名ともぶつからない。ただ **Hapón は現実のタガログ語で「日本」そのもの**（スペイン語 Japón から、Wiktionary「Hapon」。アクセントなしの hapon は「午後」）で、現実の日本の名を日ノ本の名に使うことになり、例外を作らない考え（DIFF-051）とぶつかる。英語の形も、現実の Japão → Japan の道（ポルトガル語から）からずれる。
- → 昔の英語の名は **Hapan**（ポルトガル語 Hapão から。現実の Hapón とは一字違い）。スペイン語圏・タガログ語での昔の呼び名は、要る場面で作る（Hapón にはしない）。
