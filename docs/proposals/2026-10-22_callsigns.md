## 1. 共通の決まり（正本の前例から）
- 頭の JO（日本の国の頭）は落とす。いちばん後ろの部分に **HN** を付ける（後ろの印がないラジオは「-HN」を足す）。
- 実在の符号は、ハイフンと HN を持たないので、どれとも重ならない。

## 2. アマチュア無線（Gin「プリフィックスは現行の縛りを重し混んで／サフィックスは JA1XXXなら1AHN／JP0EZNなら0PHN／1〜0の数字がサフィックス頭にくるから放送系と被ることもないはず」）
- 形：**（個人の英字）-（地域の番号）（国際字列の2文字目）HN**。例 JA1XXX → **XXX-1AHN**、JP0EZN → **EZN-0PHN**。
- 7・8 で始まる局は国際字列を2文字とも残す（JN1ABC と 7N1ABC が同じにならないように）：7N1ABC → **ABC-17NHN**、8J7A33K → **A33K-78JHN**（後ろが5文字になるのは Gin「後ろが五文字はあり得るかなぁ」）。7K〜7N の数字は 1〜4 だけで、どれも関東（1エリア）。7N8 は発行されない。
- 現行の縛りをそのまま使う：
  - 地域の番号＝総合通信局の受け持ち：1 柵東総通・2 松並総通・3 近府総通・4 神光総通・5 二名総通・6 火守総通（沖縄 JR6・JS6 は阿児奈波総合通信事務所）・7 柵北総通・8 海北総通・9 雪路総通・0 科柳総通。
  - 後ろの英字に **QRA〜QTZ**（Q符号と重なる）と **SOS・OSO・TTT・XXX** は使わない。
  - 社団局（クラブ局）は **Y・Z 始まり**（YAA〜ZZZ）。
  - 7J は外国人、8J は特別記念局、JD は小笠原。
- 見分け：ハイフンの後ろが **数字** で始まる（放送は英字で始まる）。
- G5 の気づき：実在の局の英字をそのまま写すと、変換して実在の人に戻せる。作中の人物には新しく作るのがよい（Gin に）。

## 4. BS（Gin「MUSEの頃はHV／デジタルからBS-HDTV」）
| 時代 | 現実 | 日ノ本 |

| アナログ（テレビ） | JO21-BS-TV | **21-BS-TVHN** |
| アナログ（音声・データ） | JO23-BS-TAM1／JO23-BS-TDM1 | **23-BS-TAM1HN／23-BS-TDM1HN** |
| アナログのハイビジョン（MUSE） | JO243-BS-HDTV | **243-BS-HVTVHN**（HV＝ハイビジョン） |
| デジタル | （現実は局ごとの符号なし、B-SAT がまとめて持つ） | **番号-BS-HDTVHN** |
- 表から読んだこと（規則として書かれた出典はない）：JO＋2桁 は BS の局の番号（チャンネルの数字ではない：JO21＝7ch、JO22＝11ch、JO23＝5ch、JO24＝9ch）。3桁目は同じチャンネルを分け合う局の番号（JO241〜248＝9ch の8社）。TAM1・TDM1 の 1 は、同じ局番号の中の音声・データの1番と読める。TAM・TDM の意味は出典なし（Gin「音声多重放送」）。

## 6. BS の形の作り直し（Gin の形、2026-10-22、HNS-G5 のセッション。§4 の数字の前の部分と HVTVHN・HDTVHN は、これで置き換え）
Gin：
```
HHK1-BS-TVHN
HHK3-BS-HVHN
HHK2-BS-DTHN
HHKP-BS-HDHN (HHK Premium)
HSB1-BS-TVHN(Hinomoto Satellite Broadcasting)
```
- 形：**（放送局の略称＋番号・印）-BS-（種類2文字）HN**。前の部分は現実の数字（JO21 など）をやめ、地上の局と同じく会社の略称から作る。
- 種類の印は2文字にそろう（地上の TVHN・DTHN と同じ長さ）：
  | 印 | 意味（G5 の読み） |
  |---|---|
  | **TV**HN | アナログのテレビ |
  | **HV**HN | MUSE（アナログのハイビジョン） |
  | **DT**HN | デジタル |
  | **HD**HN | デジタルのハイビジョン |
- 略称：**HHK**（日ノ本放送協会、NHK にあたる。HHKP＝HHK Premium）、**HSB**（Hinomoto Satellite Broadcasting、日本衛星放送〈JSB、WOWOW〉にあたる）。正本に NHK・WOWOW の日ノ本名はまだない。
- 照らし（Web）：HHK・HSB という放送局は見つからない。HHK は **Happy Hacking Keyboard**（キーボードの名、英語版 Wikipedia の HHK の曖昧さ回避）と同じ並び。米国のラジオ KHHK がある（字が一つ多い）。HSB は インドネシアの衛星の計画（Hot Backup Satellite）の略として出るだけ。
- 気づき：TAM1・TDM1（音声・データ）を2文字の印にするなら、例えば **AM**HN・**DM**HN の形がありうる（G5 の案、Gin に）。地上の音声多重（§3 の TAMHN）も2文字にそろえるかは Gin に。

## 7. 足し：多重放送の印の意味を調べた（Gin「一応調べてみてもらえる?分からなくても倣う前提で」2026-10-23）
- 確かめた（dgba.ehoh.net「地上波放送局 コールサイン(呼出符号) 一覧」の頭の説明、Shift_JIS を直して画面で読んだ）：「呼出符号前４文字」の後に、デジタルテレビは **-DTV**、FM は **-FM**。AM は4文字だけ。終わったアナログテレビは **-TV**、**音声多重放送は -TAM**、**文字多重放送は -TCM**、**データ多重放送は -TDM** が付けられていた。
- **TAM1・TDM1 の「1」は、出典が見つからなかった**。審査基準の原文（総務省の新旧対照表 PDF）は、読む道具がなく読めなかった（PDF は読み取りの道具が自動で保存したので、読まずに消した）。審査基準を HTML で載せたページ（motobayashi.net）はアマチュア局の部分だけ。
- G5 の読み（推測）：同じ局番号（JO23）の中の、音声・データの何番目か。BS アナログの音声には Aモード・Bモード（Bモードは 48kHz16bit の PCM 2チャンネル、サテラビューの記事の注10）があり、独立した音声を何本か流せたので、その番号とも読める。マルチメディア放送の JOLZ-MM#（# は整数）と同じ考え。
- 日ノ本では倣う（Gin）：印も番号も現実の形を写す。地上 ○○○○-TAMHN／-TCMHN／-TDMHN、BS は 局の略称-BS-TAM1HN／TDM1HN（§6 の2文字の印にそろえるかは Gin に）。
