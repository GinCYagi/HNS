## 追記：黒川 → 墨河（Gin、2026-10-02、HNS-Rev に直接）

経緯：Gin 訂正「一点訂正、城は……の件は、地図的に実在すれば(HNS査読後)の名前で描画は構わない、という意味です」「実在名を許容ではないです」→ RUL-017 の例外は取り消し（4ebf028）。HNS-Rev の問い「相津を冠した形でも『黒川』は実名のままに当たるか」に、Gin の答え（原文）：

- 「**相津墨河城**」「**あいづすみかわじょう**」

組み立て：黒→墨（同じ黒の仲間）、川→河（同じ水の仲間）。DIFF-016（対字・近い字）。別名 **青鷺城（あおさぎじょう）** はそのまま。

一次チェック（元のページで確認）：

| 見る所 | 結果 |
|---|---|
| 「墨河城」「澄川城」 | Wikipedia 全文検索で0件 |
| 「墨河」 | 地名の実在は見当たらない。江戸の人の号（扇屋墨河、沢田東江など）に出てくる（記録） |
| 同音「すみかわ」 | **澄川駅**（札幌市営地下鉄南北線、札幌市南区澄川）。C-03（同音）：方面が遠いので記録・条件付きの見込み |
| C-07 | 「墨」を「すみ」と読むのは素直。「河」を「かわ」も素直。ルビはなくても読める見込み |
| つながり | 墨は黒の仲間なので、Gin の「黒は黒川城の黒」の由来がそのまま残る。墨と青鷺（灰青の鳥）で、色の取り合わせが落ち着く |

差分（NG の受け入れ判定のあと）：castles の fictional を「相津黒川城」→「**相津墨河城**」、yomi「あいづすみかわじょう」。open_question（黒川の扱い）を解消。rejection_log に「相津黒川城（実在の古名 黒川城そのもの。RUL-017）」。

Gin に聞きたいこと：駅名の案「相津黒川」（会津若松駅、未査読）も「**相津墨河**（あいづすみかわ）」にそろえますか。城と駅と町の名前がそろうと、読者が迷いません。

Gin の答え（2026-10-02、原文）：「1,そろえます」 → 駅名の案「相津黒川」（会津若松駅）は「**相津墨河（あいづすみかわ）**」にそろえる。駅名の第1稿（`docs/proposals/2026-10-01_ryuto_stations_lines.md`）は未査読なので、査読のときにこの名前で見る。
