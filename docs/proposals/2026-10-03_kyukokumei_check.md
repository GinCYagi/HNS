## 1. 旧国名を使っている前例（使ってよい根拠）

| 前例 | どう使っているか | 出どころ |
|---|---|---|
| **G-02「律令区分・旧国名採用」** | 仕様に生成規則として正式にある。「広域名称向き」 | specification G-02 |
| 陸奥（みちのく）＝東北 | 旧国名を**地方の名前**に。陸奥新幹線・都縦陸奥線にも | 正本 L160・L215 |
| 二名島＝四国 | 古事記の名（律令区分扱い） | 正本 L162 |
| **尾張府（蓬左市）＝愛知・名古屋** | 旧国名「尾張」を**そのまま県の名前**に（府を付けて） | 正本 cities |
| 越路＝北陸道（裁定待ち） | 越の国の古い呼び方 | shichido §15 |

→ Gin の見立てどおり、旧国名は前から使っている。**使うこと自体はぶつからない。**

## 2. ぶつかりそうな所（Gin に決めてほしい）

| # | ぶつかり | くわしく |
|---|---|---|
| A | **畿内の旧国名は、そのまま使っていない** | 大和→広貴、山城→谷背、河内→洲外、和泉→貴川（どれも条件付き・要修正）。越後・佐渡を実名のまま使うと、「畿内の国は名前を替え、それ以外はそのまま」になる。→ ①畿内だけは五国府の都の国として特別に替える、と書くか ②越後なども替えるか |
| B | **「陸奥」が二重になる** | 本世界では陸奥＝東北地方の名前。旧国名をそのまま使うと、律令の陸奥国（青森・岩手・宮城・福島）と、地方の陸奥が同じ字になる。磐越西線の「磐城」はもとは陸奥国から分かれた国。→ 東北の中の国名を使うときは、地方の「陸奥」と区別の書き方が要る |
| C | **佐渡は今の市の名前と同じ** | 旧国名の佐渡＝現実の佐渡市（佐渡島）。そのまま使うと、RUL-017（実名のまま却下）の「今ある市の名前そのまま」になる。尾張は「尾張府」として形を変えている。Gin の城の訂正「実在名を許容ではないです」とも向きが逆。→ 旧国名を使うのは「国・地方・路線名の部品」までにして、**今ある市町の名前にはそのまま当てない**、と線を引くか |
| D | 越後線・信越本線・羽越本線・磐越西線 | 旧国名を使うなら、路線名は実在のままになる（越後線＝現役の JR の路線名）。C-01（現役の路線名と同名）に当たる。上越新幹線は東柳新幹線にした前例がある。→ 路線名に使うなら、組み方を変える（例：越後〇〇線）か、実名のままを認めるか |
| E | 柳都平野 | 越後平野は柳都平野にした（Gin）。旧国名を使っても、平野の名前は柳都平野のまま（ぶつからない、記録） |

## 3. HNS-Rev のまとめ

- 旧国名を使うこと（G-02）は、既存の世界観と合う。
- ただし線引きが要る：**A 畿内との差**、**B 陸奥の二重**、**C 今ある市の名前（佐渡）**、**D 現役の路線名**。
- HNS-Rev の案（決めるのは Gin）：「旧国名は、**国・地方の呼び名と、名前の部品（上越の『越』など）**に使う。**今ある市町の名前と現役の路線名には、そのまま当てない**。畿内は五国府の国として別の名前」。この線なら、上越は越後を部品に組める、佐渡は島・国の呼び名としては佐渡、市の名前は別に、となる。
