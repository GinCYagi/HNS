【HNS】Proposal｜HNS-G5 より HNS-M4・HNS-C5・Gin への文（火ノ本 と 日ノ本：字を替えた時期・国書の対の言葉・今の使い分け）

作成：2026-10-23（HNS-G5）
もと：HNS-M4 の頼み。Gin「日出処の天子／火燃処の天子」「火伏せの考え方から／火山災害が続いたとかで」。M4 の読み取りに Gin「はい」：はじめは 火ノ本。607年の国書の位置で「火燃処の天子」と名乗り、外向きの名は 火本 → 火本国 → フォパング・Hapan（ア の筋）。のちに火山の災いが続き、火伏せの考え方から、都の側は 火 を避けて 日ノ本 と書くようになった（読みは ひのもと のまま）。火守道（九州）は火を鎮め守る土地なので 火ノ本 を残す（2026-10-23、HNS-M4 のセッション）。
照合（いずれも 2026-10-23 参照）：
- 中国語版ウィキソース『隋書』巻81 倭國
- 日本語版 Wikipedia「日本」「好字二字令」「遣唐使」「大坂」「富士山」
- 英語版 Wikipedia「Engishiki」（延喜式）
正本4YAMLは変更していない。
気をつけたこと：実在の災いを物語の道具にしない。ここで挙げるのは千年以上前の、記録の年だけ。災いの中身や被害は書かない。869年の貞観地震は、今の災いと結びつけて語られることが多いので、挙げない。

## 2. 頼み1：字を替えた時期（G5 の案）
| 年 | 作中 |
|---|---|
| 607 | 国書「**火燃處天子**致書**火盡處天子**無恙」（§3）。隋書の阿蘇山の記事は現実のまま |
| 701〜702ころ | 国の名 **火本**（ひのもと）が定まり、遣唐使が唐に「火本国」と名乗る（現実の 日本 の位置。**ずらしはここ一か所**） |
| 713・757 | 好字の決まり（現実のまま）。国の名には及ばない |
| 800〜802・864 | 富士山の噴火の記録（現実のまま。中身は書かない） |
| 894〜907 | 遣唐使が止まり、唐が滅ぶ。都と中国の公の行き来が絶える |
| **905〜927（延喜式）** | **都は、延喜式の「よい字で書く」定めを国の名にも当て、火 を避けて 日ノ本 と書くようにする。読みは ひのもと のまま** |
| 10〜12世紀 | 公の行き来がないので、中国には書き替えが伝わらない。博多の宋の商人は、火守道（九州）の人の言う 火本 を聞き続ける → 閩南語 hé-pún（ア の筋） |

- 延喜式に置く理由：
  1. 現実に「名をよい字で書く」定めがある本で、火の災いの記録（800〜802・864）より後。
  2. 唐との公の行き来が絶えた後なので、外の名 火本 → Hapan の筋が崩れない。
- 気がかり：室町時代の日明の公の交わり（勘合）では、都は 日ノ本 と書いて送ったはずなので、中国の役所の書き方は 日本 にあたる字に変わるかもしれない。閩南語の船乗りの言い方（hé-pún）は、それより前からマレー語に渡っていればよい。要る場面で決める。

## 3. 頼み2：国書の「火燃処」と対になる言葉（現実の「日沒處」の位置）
| 案 | 読み | 意味 | 見立て |
|---|---|---|---|
| **火盡處**（火尽処） | ひつくるところ | 火の尽きるところ | **推し**。没（沈む）と同じく「終わる側」で、煬帝が「無礼」と怒る筋も同じに立つ |
| 火滅處 | ひきゆるところ | 火の消えるところ | 滅 は強すぎる（滅亡を思わせる） |
| 火消處 | ひきゆるところ | 火の消えるところ | 今の「火消し（江戸の消防）」を思わせる |
| 燼處 | もえさしのところ | 燃えさしのところ | 一字で対にならない |
- 国書の作中の形：「**火燃處天子、書を火盡處天子に致す、恙無きや**」。
- 照らしはまだ（読みの同じ音、字の並びの地名）。

## 4. 頼み3：今の使い分け（G5 の案）
| 場面 | 字 | 理由 |
|---|---|---|
| 国の名・法律・役所・切手・国の会社 | **日ノ本** | 延喜式からの都の書き方 |
| 火守道（九州）の道の看板・道の役所の文書の題字 | 火ノ本 も使う（例：「火ノ本の道 火守道」） | 火を鎮め守る土地として残した |
| 祭り | 火守道の火の祭りの名に 火ノ本（例：火ノ本まつり） | 火伏せの祭りとして残る |
| 会社の名 | 火守道に本社のある古い会社に 火ノ本〇〇 が多い。全国の会社は 日ノ本〇〇 | 地元の誇りとして |
| 歴史の本・教科書 | 「古くは 火本・火ノ本 と書いた」と注を付ける | — |
| 外国の言葉 | Hapan（火本 から）・Hinomoto（ひのもと の音から） | ア の筋 |
- 祭りや会社の名は例。実在の祭り・会社と同じ名にならないよう、使う前に照らす。

## 5. 頼み4：縁起の悪い字を避けて地名の字を替えた現実の例（出典つき）
- **倭 → 日本**：『新唐書』「倭の名を悪み」（Wikipedia「日本」）。国の名そのもの。
- **大倭 → 大和（757）**、**好字二字令（713）**：よい字で書く決まり（Wikipedia「好字二字令」）。
- **延喜式 巻22**：郡の名は二字・よい字で、の定め。全国で地名が替わった（英語版 Wikipedia「Engishiki」）。
- **大坂 → 大阪**：「土に反る」を忌んだ説（『摂陽落穂集』1808年）と、「偶然」の説（『大阪市史』）が並ぶ。言い伝えとして扱う（Wikipedia「大坂」）。
- 「火」の字を避けて地名を替えた現実の例は、G5 は見つけていない。

## 6. 頼み5：DIFF-052 との合い方（G5 の見立て。C5 の査読に）
- ずらしは「国の名が定まった瞬間（701〜702ころ）に、日 でなく 火 の字だった」の一か所。
- 延喜式での書き替えは、二つ目のずらしではなく、現実の仕組み（字の意味を嫌って替える：倭→日本、好字令、延喜式 巻22）が、ずらした字（火）に自然に働いた結果。現実では 日 は忌む字でないので替わらなかった、というだけ。
- 外の名（Hapan）が 火 のまま残るのも、現実の「公の行き来が894年以降絶えた」と「博多の宋の商人」の流れから出る。

## 7. ついで：日ノ本エアシステム（Hapan Air System）の符号
- ICAO の候補 HSY は、スペインの Sky Helicopteros が使っている（airhex.com・sprinkle.com、M4 の照らし）。→ 見直しに入れる。IATA の2文字は H 以外の字も含めて、2026-10-23_iata_h_codes_survey.md と同じやり方で後で調べる。

## 8. C5 の査読（docs/reviews/2026-10-23_review_hinomoto_hi_kanji_C5.md、87ddb12）を受けた直し
1. **延喜式 巻22 の出典**：「凡諸国部内郡里等名 並用二字 必取嘉名」を、weblio「延喜式」とジャパンナレッジの解説で確かめた（§1 の表を直した）。定めは **郡・里の名** に向けたもの。**「都がこの定めを国の名にも当てた」ところが作りごと**（C5 の指摘のとおり書き添える）。
2. **ずらしの書き方**：「701〜702 に国の名が 火 だった」ではなく、**「ひ を 火 と書く考えが、はじめからあった」の一か所**と書き直す（C5 の案）。607 の国書「火燃處」も、701 の国の名 火本 も、そこから流れる。現実の 日出處（607）と 日本（701ころ）が同じ「日」の考えから出ているのと同じ型。隋書の阿蘇山の記事（現実のまま）が、「火 の側で自分たちを見る」考えの根になる。
3. **奝然（983〜984年、宋の太宗に日本の書物を献上）**：延喜式のあとにも、日本の書き物が中国の正史に渡っている。→ **C5 の案ア**を推す：中国の **書き物**（正史）は 984 年から 日ノ本 にあたる字になる。閩南語の **船乗りの話し言葉** は、博多・火守道の人の言う 火本 を聞き続け、hé-pún のまま16世紀にマレー語に渡る。現実の Japan も、中国の書き物ではなく船乗りの言葉（閩南語→マレー語）から出たので、筋に合う。§2 の気がかり（室町の勘合）も同じ答えで済む。§2 の「中国には書き替えが伝わらない」は、この形に改める。
4. **火盡處**：仏教の言葉「薪尽火滅」（薪が尽きて火が消える。釈迦の入滅のたとえ）と重ねて読まれうる（Web 検索で確かめた。ntireader.org の辞書ほか）。「火の尽きるところの天子」は「亡くなる天子」とも読める。現実の 日沒處 も強い言い方で、煬帝を怒らせる筋としてはかえって合う。外すかは Gin に。
5. **災いの書き方**：「貞観」「延暦」の噴火の名は出さず、年で書く（§1 を直した）。
6. 符号の調べの査読（docs/reviews/2026-10-23_review_iata_h_codes_C5.md）は、HL の過去の持ち主 Hellenic Airlines（1947〜1951）を足すだけで、順位は変わらない、HC に賛成。
