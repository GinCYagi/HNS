| 10〜12世紀 | 公の行き来がないので、中国には書き替えが伝わらない。博多の宋の商人は、火守道（九州）の人の言う 火本 を聞き続ける → 閩南語 hé-pún（ア の筋） |

- 延喜式に置く理由：
  1. 現実に「名をよい字で書く」定めがある本で、火の災いの記録（800〜802・864）より後。
  2. 唐との公の行き来が絶えた後なので、外の名 火本 → Hapan の筋が崩れない。
- 気がかり：室町時代の日明の公の交わり（勘合）では、都は 日ノ本 と書いて送ったはずなので、中国の役所の書き方は 日本 にあたる字に変わるかもしれない。閩南語の船乗りの言い方（hé-pún）は、それより前からマレー語に渡っていればよい。要る場面で決める。

## 3. 頼み2：国書の「火燃処」と対になる言葉（現実の「日沒處」の位置）
| 案 | 読み | 意味 | 見立て |
|---|---|---|---|
| **火盡處**（火尽処） | ひつくるところ | 火の尽きるところ | **推し**。没（沈む）と同じく「終わる側」で、煬帝が「無礼」と怒る筋も同じに立つ |
| 火滅處 | ひきゆるところ | 火の消えるところ | 滅 は強すぎる（滅亡を思わせる） |

| 燼處 | もえさしのところ | 燃えさしのところ | 一字で対にならない |

- 照らしはまだ（読みの同じ音、字の並びの地名）。

## 4. 頼み3：今の使い分け（G5 の案）
| 場面 | 字 | 理由 |
|---|---|---|
| 国の名・法律・役所・切手・国の会社 | **日ノ本** | 延喜式からの都の書き方 |
| 火守道（九州）の道の看板・道の役所の文書の題字 | 火ノ本 も使う（例：「火ノ本の道 火守道」） | 火を鎮め守る土地として残した |
| 祭り | 火守道の火の祭りの名に 火ノ本（例：火ノ本まつり） | 火伏せの祭りとして残る |
| 会社の名 | 火守道に本社のある古い会社に 火ノ本〇〇 が多い。全国の会社は 日ノ本〇〇 | 地元の誇りとして |
| 歴史の本・教科書 | 「古くは 火本・火ノ本 と書いた」と注を付ける | — |
| 外国の言葉 | Hapan（火本 から）・Hinomoto（ひのもと の音から） | ア の筋 |
- 祭りや会社の名は例。実在の祭り・会社と同じ名にならないよう、使う前に照らす。

## 5. 頼み4：縁起の悪い字を避けて地名の字を替えた現実の例（出典つき）
- **倭 → 日本**：『新唐書』「倭の名を悪み」（Wikipedia「日本」）。国の名そのもの。
- **大倭 → 大和（757）**、**好字二字令（713）**：よい字で書く決まり（Wikipedia「好字二字令」）。
- **延喜式 巻22**：郡の名は二字・よい字で、の定め。全国で地名が替わった（英語版 Wikipedia「Engishiki」）。
- **大坂 → 大阪**：「土に反る」を忌んだ説（『摂陽落穂集』1808年）と、「偶然」の説（『大阪市史』）が並ぶ。言い伝えとして扱う（Wikipedia「大坂」）。
- 「火」の字を避けて地名を替えた現実の例は、G5 は見つけていない。

## 6. 頼み5：DIFF-052 との合い方（G5 の見立て。C5 の査読に）
- ずらしは「国の名が定まった瞬間（701〜702ころ）に、日 でなく 火 の字だった」の一か所。
- 延喜式での書き替えは、二つ目のずらしではなく、現実の仕組み（字の意味を嫌って替える：倭→日本、好字令、延喜式 巻22）が、ずらした字（火）に自然に働いた結果。現実では 日 は忌む字でないので替わらなかった、というだけ。
- 外の名（Hapan）が 火 のまま残るのも、現実の「公の行き来が894年以降絶えた」と「博多の宋の商人」の流れから出る。

## 8. C5 の査読（docs/reviews/2026-10-23_review_hinomoto_hi_kanji_C5.md、87ddb12）を受けた直し
1. **延喜式 巻22 の出典**：「凡諸国部内郡里等名 並用二字 必取嘉名」を、weblio「延喜式」とジャパンナレッジの解説で確かめた（§1 の表を直した）。定めは **郡・里の名** に向けたもの。**「都がこの定めを国の名にも当てた」ところが作りごと**（C5 の指摘のとおり書き添える）。
2. **ずらしの書き方**：「701〜702 に国の名が 火 だった」ではなく、**「ひ を 火 と書く考えが、はじめからあった」の一か所**と書き直す（C5 の案）。607 の国書「火燃處」も、701 の国の名 火本 も、そこから流れる。現実の 日出處（607）と 日本（701ころ）が同じ「日」の考えから出ているのと同じ型。隋書の阿蘇山の記事（現実のまま）が、「火 の側で自分たちを見る」考えの根になる。
3. **奝然（983〜984年、宋の太宗に日本の書物を献上）**：延喜式のあとにも、日本の書き物が中国の正史に渡っている。→ **C5 の案ア**を推す：中国の **書き物**（正史）は 984 年から 日ノ本 にあたる字になる。閩南語の **船乗りの話し言葉** は、博多・火守道の人の言う 火本 を聞き続け、hé-pún のまま16世紀にマレー語に渡る。現実の Japan も、中国の書き物ではなく船乗りの言葉（閩南語→マレー語）から出たので、筋に合う。§2 の気がかり（室町の勘合）も同じ答えで済む。§2 の「中国には書き替えが伝わらない」は、この形に改める。
4. **火盡處**：仏教の言葉「薪尽火滅」（薪が尽きて火が消える。釈迦の入滅のたとえ）と重ねて読まれうる（Web 検索で確かめた。ntireader.org の辞書ほか）。「火の尽きるところの天子」は「亡くなる天子」とも読める。現実の 日沒處 も強い言い方で、煬帝を怒らせる筋としてはかえって合う。外すかは Gin に。
5. **災いの書き方**：「貞観」「延暦」の噴火の名は出さず、年で書く（§1 を直した）。
6. 符号の調べの査読（docs/reviews/2026-10-23_review_iata_h_codes_C5.md）は、HL の過去の持ち主 Hellenic Airlines（1947〜1951）を足すだけで、順位は変わらない、HC に賛成。

### 9-2. 確かめ（頼まれたもの）
1. **博多の宋の商人（博多綱首）**：謝国明（南宋の出の貿易商、博多の唐房に住む）が 1242年に承天寺を建てた（コトバンク「承天寺」、tabi-mag.jp）。唐坊・綱首は、遣唐使の記事で 10世紀後半〜12世紀の宋商人の居留地として出る（Wikipedia「遣唐使」）。11世紀後半〜12世紀前半の博多の大きな石積みの遺構もあるが、綱首との結びつきの資料はない（奈良文化財研究所 全国遺跡報告総覧）。→ **11〜13世紀**。作中の「九州の人が書いた 火本 が港に渡る」は、この時期に置ける。
2. **701年より前の火山の記録**（年だけ）：
   - 『隋書』巻81 の阿蘇山の記事（607年の国書と同じ巻、6世紀末〜7世紀初め の見聞）。
   - 684年：『日本書紀』の記事を、伊豆大島の噴火の記録の最初とする見方がある（地質調査所月報 35-10、gsj.jp）。同じ年の別の記録は挙げない。
   - 富士山の記録で最古は 781年（『続日本紀』）なので、701年より前には使えない。
3. **商人が書いた字が港で読まれる筋の無理のなさ**：**気がかりが一つ**。閩南語の 火 には二つの読みがある：話し言葉の **hé／hér／hóe** と、書き言葉（文読）の **hóⁿ**（Wiktionary「火」）。書いた字を読み上げると hóⁿ-pún になり、Hapan でなく **Hopan** の筋になりうる。
   - 答え（G5 の案）：地名は話し言葉の読みで呼ぶことが多い。台湾の 火燒島（緑島の古い名）は閩南語で **Hóe-sio-tó**（話し言葉の読み、Wiktionary「火燒島」、台湾教育部の辞書）。船乗りは 火本 を地名として話し言葉で呼び、hé-pún になった、とすれば流れる。
   - 現実の 日本 も、閩南語 Ji̍t-pún・Li̍t-pún と方言で分かれる（Wiktionary「日本」）。作中も、方言の差は残ってよい。
4. **火盡處**：仏教の「薪尽火滅」（釈迦の入滅のたとえ）と重なる（§8-4）。Gin はまだ決めていない。別の案（G5）：
   - **火冷處**（ひさゆるところ）：火の冷える側。没（沈む）より弱いが、「衰える側」で怒らせる筋は立つ。死の意味は薄い。
   - 火晦處（ひくらきところ）：火の暗くなる側。晦 は月の終わり（みそか）の字でもある。
   - 照らし（同じ音・字の並び）はどれもまだ。

### 9-3. DIFF-052
- ずらしは 607 の国書の一か所。701 の 日ノ本 は、現実の「倭の名を悪み」と同じ仕組みが流れた結果。火守道の 火ノ本、商いの書き物の 火本 は、そこから自然に分かれた。延喜式の作りごとがなくなり、§8 で C5 が言った「作りごとの部分」は消える。

### 9-4. C5 の査読 追記1（9392eee）を受けた直し
1. **684年は挙げない**（同じ年に大きな地震の記録がある、C5）。701年より前の火山の記録は『隋書』巻81 の阿蘇山の記事だけにし、あとは「火伏せの考え」で書く。
2. **港を一つに決める：泉州（Zaiton）**。泉州は 11〜14世紀に外国の商人にとって中国の第一の港で、マルコ・ポーロも1292年にここから帰りの船を出した（英語版 Wikipedia「Quanzhou」）。泉州の閩南語で 火 の話し言葉の読みは **hér**（Wiktionary「火」）。hér の母音 ə は、マレー語の e（ə と読む、Jepang の e と同じ）にそのまま入る → **Hepang**。フォパング（マルコ・ポーロ）と Hepang（マレー語）が同じ港から出る形になり、筋が一本になる。
   - 現実の Japan の元 Ji̍t-pún は 漳州・厦門 の側の読み（泉州は Li̍t-pún、Wiktionary「日本」）。作中は泉州の読み、という方言の差は残る（現実の型から外れるほどではない、と G5 は見る）。
3. **承天寺 1242年**：コトバンク（日本歴史地名大系）「仁治三年（一二四二）博多居住の宋商人（博多綱首）の謝国明…が開基となり」で確かめた。
4. **国書の対は 火冷處**（ひさゆるところ）を推す（C5 も 火冷處 を推す）。照らしはまだ。

## 10. 書き直し：Gin の決め（2026-10-23、HNS-M4 のセッション）
もと：M4 の問い「686年の宮の大火（難波宮の全焼）と火山の災いが重なったので、祈りとして 火 を 日 に替えた（朱鳥の改元と同じ型）という意味でよいか」「火盡處 に決める、という意味か」→ Gin「両方それで合ってます」「あの頃元号がコロコロ変わってるのはそんな意味合いが強く見受けられたので」「礼を尽くしたつもりがちがうところ「天子」で激怒された、なら／ウの火で揃えても問題ない気がします」。
**§9-1 の「701 に都は火山の災いを見て」と、§3・§8-4・§9-2-4・§9-4-4 の国書の対の言葉の理由は、この §10 で置き換える。泉州の筋（§9-4-2）はそのまま。**

### 10-1. 字を替えた理由

### 10-2. 国書の対の言葉：火盡處（決まり）
- **現実の手がかり**：煬帝が怒ったのは「天子」の語（中華の考えでは天子は一人なのに、辺境の首長が天子を名乗った）と、隋の皇帝が代わったのを知らなかったことで、「日出處」「日沒處」ではない。「日出處」「日沒處」は『大智度論』に「日出処是東方 日没処是西方」とある、東西を表すだけの仏教の言葉（東野治之の説、日本語版 Wikipedia「遣隋使」）。
- → **前の版の「没と同じ終わる側だから怒る」は現実と合わないので取り消す**（§3・§9-2-4 の見立て）。
- 作中の 火盡處：仏教の言葉「薪尽火滅」（薪が尽きて火が消える＝涅槃・釈迦の入滅）を踏まえた、仏教を重んじる **菩薩天子**（使いがそう呼んだ隋の天子）への **礼のつもりの言葉選び**。火燃處（東）・火盡處（西）で 火 にそろう。怒られたのは、現実と同じく「天子」の語。
- 火冷處・火晦處 の別案は下げる。
- 「菩薩天子」：『隋書』巻81 の使いの言葉「聞海西菩薩天子重興佛法，故遣朝拜，兼沙門數十人來學佛法」（中国語版ウィキソースで確かめた）。誰を指すか（文帝か煬帝か）は、遣隋使の記事の「皇帝が代わったのを知らなかった」と合わせて読む説がある、という程度にとどめる。

### 10-3. C5 の査読 追記2（0940114）を受けて
1. **薪尽火滅 の出典**：『妙法蓮華経』序品第一（鳩摩羅什 訳）の偈「佛此夜滅度，如薪盡火滅，分佈諸舍利」（中国語版ウィキソース「妙法蓮華經/01」で確かめた）。ほかに『雑阿含経』巻23 にも「如薪盡火滅」がある（同じくウィキソースの検索）。
2. **字の理由に、天皇の病・死は書かない**（C5）。理由は「宮の全焼と阿蘇の火」にとどめる（§10-1 の表を直した）。
3. **Gin に決めてほしいこと（C5 の案）**：
   - ア **替えた時を 686年、定まった時を 701年に分ける**。686年に宮の全焼と阿蘇の火の言い伝えを受けて 火 を 日 に改め、大宝律令（701）で定まり、702年の遣唐使が唐に 日ノ本 と名乗る。天武天皇は「日本を国号とした最初の天皇とも言われる」（Wikipedia「天武天皇」、C5）ので、現実の国号の説の幅（天武の代〜701）に入る。
   - イ 今のまま「701年ころ」。
   - G5 は **ア** を推す（朱鳥の改元と同じ年でつながり、現実の説の幅にも入る）。
4. **朱鳥 の 朱（火の色）をどう読むか**（Gin に）：朱 は赤、五行で南・火（朱雀）。読みは あかみとり（Wikipedia「朱鳥」、C5）。
   - (i) 火を鎮める側の祈り（火の鳥に火を収めてもらう）
   - (ii) 火の鳥に頼る祈り（火の力を借りる）
   - G5 の案は (i)：火 の字を国の名から退けて、火の力は朱い鳥（元号）にあずける、という読み。火守道（火を鎮め守る土地）とも同じ向き。

## 11. 答え（Gin、2026-10-23、HNS-M4 のセッション）と、決まった筋
- 問い1：字を替えたのは **686年**、定まったのは **701年** と分ける（ア）→ Gin「1,ok」。
- 問い2：朱鳥 の 朱 の読み → Gin「**朱雀が火を司るからこそ、火を治めて欲しいとの祈り**」「2,ok」。
