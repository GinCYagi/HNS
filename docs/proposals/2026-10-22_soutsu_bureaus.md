## 2. 作り方の分かれ目（Gin に）
- 電力会社は **会社の名の地方の名**（東京電力→東都、関西電力→柵西、中部電力→央嶺）から作った。総合通信局は **局の名の地方の名**（関東・近畿・東海）なので、同じ当て方をすると 柵東・近府・松並 になり、電力と違う名が並ぶ（現実でも 東京電力 と 関東総合通信局、関西電力 と 近畿総合通信局 は違う名）。
- 東海 の別案：**央嶺総合通信局**（中部＝央嶺。中部電力＝央嶺電力 とそろう）。ただし 央嶺（中部）は 北陸・信越 も含む広い地方の名で、東海の4県だけの局には広い。
- **柵東 の一音違い さくどう＝策動（悪巧み）** は、地方の名 柵東 そのものにかかる（局だけの話ではない）。記録として Gin に。

## 4. 足し（Gin、2026-10-22、HNS-G5 のセッション）
- 略し方：Gin「実際には関東総通、東北総通、のように使います／だから、柵東総通、柵北総通、海北総通で違和感はないです」→ 略称の形は **○○総通**。日ノ本では **柵東総通・柵北総通・海北総通**（北海道は 道 を落として 海北総通、Gin の書き方）・雪路総通・松並総通・近府総通・神光総通・二名島総通・火守総通・科柳総通。沖縄は 事務所 なので略し方は確かめていない。
- **柵東 の さくどう＝策動 は参考の記録に下げる**（名を外す理由にしない）。Gin「えんとうに点を足して遠藤にするみたいな話だね」。柵東総通・柵東総合通信局 と言うとき、とう が濁る場面がない。一音違いは、話し言葉で実際に起きる変化（っ・ー が落ちる、熟語の中の連濁）だけを見る。
- Gin「海北道総通(略称、海北総通)／二名島総通(略称、二名総通)／かな」（2026-10-22）→ 名の長い2局は二段にする案：**海北道総通（さらに略して 海北総通）**、**二名島総通（さらに略して 二名総通）**。ほかは ○○総通 だけ。G5 の見立て：合う（海北道電力・二名島電力 の 道・島 を落とすのと同じ縮め方）。二名 の読み ふたな は、俗語の話に出典がなかった（power_companies §6）ので、気にする理由はない。Gin の「かな」は確かめ中。
