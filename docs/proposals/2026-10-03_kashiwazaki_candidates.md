## 1. 柏崎の材料

- **地名の由来（伝承）**：「柏崎の地名には、往古沖を通る船が、河口部のモチカシワ樹の群生する丘を目印にしたことにちなむとの伝承がある」。文永11年（1274）、日蓮が佐渡から赦されて寺泊へ向かう途中、大風で「かしはざき」に流れ着いたと記される（コトバンク「柏崎市」本文）。
- 北国街道の宿駅。江戸中期から明治初めに、縮（ちぢみ）の行商で栄えた（同）。
- 山：刈羽黒姫山・米山・八石山。川：鯖石川・鵜川・谷根川（Wikipedia「柏崎市」本文）。
- カシワは「ブナ科コナラ属の落葉高木」で、「ミズナラとは近縁」（Wikipedia「カシワ」本文）。
- **ドラマの設定（ALM city_plan）**：柳都県の南西の海沿いの、発電所の町。発電所は廃炉になった原発（2026-09-30 Gin）。作品の中では、現実の発電所の名前や是非は扱わない（同）。

## 2. 本世界の設定：Gin の願い（2026-10-03）

> 廃炉先行実証実験かつ常温核融合実証実験の町になったら良いな

- （柏崎）を、**廃炉の先行実証実験**と**常温核融合の実証実験**の町とする、という世界設定の願い。ドラマの設定（発電所は廃炉）の続きにあたる。
- 世界設定そのものは ALM（city_plan）と Gin の領分。HNS は名前の材料として記録し、ALM と M4 に伝える。
- 注：常温核融合は、現実には実証が確立していない研究分野として扱われることが多い（私の知識。未確認）。作品の中の架空の実験として扱う分には問題ない。名前そのものには技術の名前を入れない（K3 は「目印・道しるべ」という抽象にとどめる）。

## 3. 組み立ての考え方

- 「柏」をそのまま残すと、千葉県の**柏市**を連想させる（C-03 の近似、私の知識）。実在の名前のまま（RUL-017）にも近づく。→ 「柏」を替える。
- 「崎」を「浦」にすると、出っ張りと入り込みの**地形の反転**（G-05 で禁止）になる。→ 替えるなら同じ仲間の「岬」にする。
- 「柏」の同じ仲間の木は「楢」。カシワとミズナラは同じコナラ属で近縁（§1）。

### K3 標崎（しるべざき）── 推奨（G-07）

| 項目 | 内容 |
|---|---|
| 典拠 | 伝承「沖を通る船が、河口の柏の丘を**目印**にした」（§1）。昔の船の目印を「標（しるべ）」として名に残す。本世界では、廃炉の先行実証と新しいエネルギーの実証の町として、**これからの道しるべ**にもなる（§2、Gin の願い） |
| 組み立て | 柏（目印になった木）→ 標（目印そのもの）。崎はそのまま。字の置き換えではなく典拠からの作り直しなので、**G-07（Gin の裁定が必須）** |
| C-01・C-02 | 国土地理院の住所検索は未実施（次の査読で機械照合を頼む）＝未確認 |
| C-04 | 「道しるべ」の「しるべ」。良い意味＝記録 |
| C-07 | 5モーラ。「標」を「しるべ」と読むのは訓読みだが、地名では「しめ」「ひょう」とも読まれうる → ルビ推奨 |
| 世界観 | 船の目印（過去）と、エネルギーの道しるべ（未来）を一つの字でつなぐ。社帰・参坊のように、字が土地のいわれを語る |

**由来メモ（案・K3）**：
> 標崎は、昔、沖を通る船が河口の柏の丘を目印にしたという伝承から、その「目印（しるべ）」を名に残したものである。本世界では、廃炉の先行実証と新しいエネルギーの実証の町として、次の時代の道しるべとも呼ばれる。

- 着想と断定の区別（PRE-007）：伝承は史料にある伝承（コトバンク）。名前と、本世界の町の役目は設定（着想）。
