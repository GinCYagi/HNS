## 3. 見立て
- 今の量（名 777・提案 128・査読 106）だと、**「全部を grep して、当たりを全部、行の最後まで読む」でやっと漏れない**。人もセッションも、どこかで切って読むと漏れる。構造に無理が出てきている、と G5 は見ます。
- いちばん効いているのは、**字の決まりが字の表に集まっていない**こと（16 行 対 341 通り）と、**外した名が三か所以上に分かれている**こと。
- 正本の作り（一行に全部）は、名が増えるほど grep の一行が長くなって読み落としやすい。ただ作り替えは大きな仕事で、ほかのセッションの読み書きにも響く。

## 4. 手当ての案（G5 から。どれも Gin と M4 の了解のあと）
| 案 | 中身 | 手間 | 効き目 |
|---|---|---|---|
| **1. 引き口の道具** | `node scripts/lookup.js <字または名>` で、正本・pending・review_dictionary・kago・tsunagari・提案書・査読を **全部引き、当たった行を切らずに出す**。外した名・prev・notes も同じ画面に出る。G5 の照らしの道具（lite・homo・muni）も scripts/ に移し、どのセッションでも使えるようにする | 小（G5 が作れる） | 大。今日の四件はどれもこれで出た |
| **2. 字の表を埋める** | 正本の rule から「X→Y」を拾った下書き（341 通り）を作り、決まったもの・案・外したものに仕分けて、決まったものを字の表に足す（京→都・川→河・山→岳 など）。仕分けは G5 が下書き、C5 査読、Gin が決める | 中 | 大。字の決まりを一か所で引ける |
| **3. 外した名を一か所に** | review_dictionary に、正本の「外した案」・prev を写して集める（正本は今のまま、写すだけ） | 中 | 中 |
| **4. 始めの手順** | セッションの始めに kago.md を読む、と各セッションの手順に書く。名を出す前・先例を引く前は 1 の道具を通す | 小 | 中 |
| 5. 正本の作りを分ける | 一行に全部の形をやめ、rule・ruling・notes を別の行に（ブロックの形）。ローダー（src/layer1）と scripts も合わせて直す | 大 | 中〜大。今すぐでなくてよい |

G5 の推し：**1 と 4 を今すぐ**、2 と 3 を次に、5 はあとで見直す。

## 5. M4 の見方（2026-10-24、HNS-M4 から）と G5 の受け
見立てと推しの順（1・4 が先）に M4 も賛成。足し五つ、G5 はどれも受けます。
1. **lookup.js と照らしの道具**：郵便番号データはリポジトリの外。場所は引数か環境変数で渡し、中身や写しを commit しない。weblio・地理院・Wikipedia は公開情報を読むだけ。→ そのとおり作る。
2. **字の表を埋める**：char_defaults は「これからの名に機械で当たる既定」。rule の X→Y の多くは名ごとの同意異字（川→瀬 の 瀬端 など）で、そのまま足すとこれからの名の替わり方が変わる。→ **案 2 を直す**：下書きは「前例の索引」として別の文書に置き、char_defaults へ上げる行は一つずつ Gin が決める。決まった名は例外として残す（沢⇄澤 の形）。
3. **外した名を一か所に**：写すときは正本の行への道（real・どの行の prev／外した案か）を残し、正本を元、review_dictionary は写しと分かる印をつける。→ そのとおり。
4. **始めの手順**：各セッションの CLAUDE.md・hooks・設定を書き換えるのは Gin の決め。→ 手順の文の **案まで** にとどめ、書き入れは Gin が決める。
5. M4 の側も、潮澤 を拍を数えずに推した（5拍、元の しおざわ がまるごと残る）。名を出す前に lookup と拍の数えを通す、を M4 の手順にも入れる。→ 拍の数えも lookup の出力に足す（元との同じ拍 n/m も）。

## 6. 12万件はできるか（Gin「これから12万何件分の町村とかの名前をやるのに、300ちょっとの文字でこんなになるの、これできんの？」2026-10-24）
郵便番号データの数え（G5、2026-10-24）：
| 項目 | 数 |
|---|---|
| 町域（府県・市区町村つきで重複なし） | 117,296 |
| 町域の名の種類（字が同じものをまとめる。同じ字の名は一括、DIFF-045） | 81,374 |
| 使われている漢字の種類 | **2,343** |
| 字の出てくる回数のうち、よく出る字 上位 100・300・500・1000 字で占める割合 | 65%・86%・93%・98% |
| 名の中の字が **すべて** 上位 N 字に入る名の割合（N＝300・500・1000・2000） | 57%・75%・**94%**・99.6% |
| よく出る字 上位 40 | 町田野西山川大東上中下南原新北小木島本谷寺津沢井高内三条屋松宮平台八吉岡前崎石和 |
- 見立て：**名ごとに決める今のやり方では、できない**（8万の名を一つずつ話すと何年もかかる）。**字ごとに決めて、機械で当て、人は外れだけ見るやり方なら、できる**。上位 1000 字の行き先が決まれば、名の 94% は機械で替わる。上位 40 字のうち 町・西・東・上・中・下・南・北・三・八・前 などは A（替えない）でもう決まっている。
- 今日つまずいたのは、字の決まりが一字ずつの長い話になっていて、決めた字が字の表に入らず notes に散っていたため（§2）。12万件に向けては、**字を 50 字ずつの束にして、行き先と機械で当てたときの当たり（現実の名との重なり・作中の名どうしの重なり）の数を並べ、Gin は束ごとに決め、引っかかる字だけ話す** 形が要る。
- 機械に任せない所は今の決まりのまま：旧国名（由来から、Gin「せめて旧律令だけはこの方式で」）・震災の土地（DIFF-040）・理（A）・県と県庁の市（DIFF-030）。
- 試しに、今の字の表（16 行）と A の字で一つの市を機械で替えて、どれだけ替わり、どれだけ重なるかを見せられる。
