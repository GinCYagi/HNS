## 3. 推定の考え方
1. **資料を先に**：『福島テレビ20年史』（マイクロ網・中継基地・親子・ルート変更）と 491mhz.net の地デジ期の受信アンテナの記述を先に当てた。送信所は民放・NHK で共用・近接が多いので、FTV の系統を TUF にも当てはめた（類推）。
2. **出力の段**：親局 30kW → 会津若松 5kW（準親局）・100〜200W（白河・田島・原町・富岡・いわき）→ 10〜30W → 0.1〜3W。子は原則として自分より出力が大きい（または同じ）局から受けたとした。
3. **近さと向き**：子に近く、子より笹森山に近い（親局の側の）局を候補にした。地域の上位は、会津＝会津若松（背炙山）、南会津東部＝田島、伊南川筋＝東只見、浜通り＝水石・いわき（湯ノ岳）、県南＝白河。
4. **開局の順（『福島テレビ20年史』）**：後から建った小さな局は、先に建っていた近くの局から受けたとした（例：天栄〈第3次〉← 長沼〈第2次〉、ミニサテ・極微小局 ← 近くの局）。富岡は、社史で「原町経由の孫局 → 昭和49年の滝根開局でルートが変わった」とあり、TUF 開局はその後なので滝根からとした。
5. **見通し（粗い確かめ）**：国土地理院の標高 API で、二局を結ぶ線の上の11点の標高を取り、両端に高さ30mのアンテナ、地球の丸み（等価地球半径 4/3）を入れて、線が地面より上かを見た（フレネル帯は見ていない）。住所の点しかない局は、その点のまわり約3km四方（0.8km おき25点）の一番高い所を送信所とみなした。迷う組み（会津・南会津・県南・浜通りの77組）だけ確かめ、結果は JSON の `los_check` に入れた。
   - さえぎられる結果でも、他に通る候補がない局は「ぎりぎり／未解決」と書いて近い上位局にした：東裏磐梯（どこからも通らず、未解決）、裏磐梯（-21m）、田島（-39m）、荒海（-14m）、古殿（白河から -18m）。
   - 資料（社史）と合わない結果：笹森山 → 原町は阿武隈の山で -267m（社史は「福島局の子」。マイクロ・反射板などがあったのかは不明）、東只見 → 只見は -14m、東金山 → 金山は -111m（東金山の位置が住所の点のため、とみられる）。資料を優先した。
