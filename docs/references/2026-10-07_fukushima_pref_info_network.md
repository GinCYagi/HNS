# 福島県総合情報通信ネットワーク（県の防災の通信網）の構成図の要約

出どころ：福島県の案内（「細密に広がる最新のネットワークが7つの生活圏を結びます。」の見開き、ファイル名 03_Fukushima_0215-2-2.pdf、2026-10-07 Gin が示した）。要約は HNS-M4。図は写さない。

- 7つの生活圏を、衛星回線・地上系無線・光回線で結ぶ。県庁・市町村・防災関係機関を結ぶ防災用の通信網。
- 無線局：県庁統制局1・中継局9・支部と準支部局9・県出先機関局39・市町村局59・消防本部局12・国と防災と生活関係機関局17・反射板4、計150局。ほかにヘリコプター全県移動無線3、衛星携帯電話（屋内73・可搬30・車載92）。
- 線の種類：多重無線（7.5GHz 帯 26M／6M）、FWA 無線（18GHz 帯 6M）。
- 中継局：**野地**・**笹森山**・**背炙**・**惣山**・**鬼丸**・**鎌房山**・**矢大臣**・**西楢葉**・**鶴石山**。反射板：**斎藤山**・**真名板倉山**・**上北高平**・**下野上**。
- 図から読める幹線（HNS-M4 の読み取り）：県庁統制局 → 野地中継局 → 背炙中継局（会津）→ 惣山中継局 → 鬼丸中継局 → 真名板倉山反射板（南会津の奥）。背炙 → 鎌房山 → 鶴石山 → 矢大臣 → 西楢葉（浜通り）。笹森山 → 矢大臣。
- TUF の木との関係（HNS-M4）：テレビの中継の木ではないが、**県の通信網も「福島 → 野地（土湯峠）→ 背炙山（会津）」の道**を通る。『福島テレビ20年史』の自営マイクロ網（本社 → 野地反射板 → 背あぶり山）と同じ。南会津の奥は「鬼丸」（南伊南の局のある見受山・鬼丸山の付近）。
- 昭和村の柱の箱の札「県総合情報用」（Gin の写真、ALM 総監督の読み取り）は、この通信網の市町村局の設備とみられる。
