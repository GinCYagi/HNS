## 4. 手順（HNS 管線 v0.1 凍結版どおり）

- **管線**：G系で候補を出す（規則 ID 付き） → D系 → C系の機械フィルタ（棄却理由は必ず記録） → Fable の査読 → Gin の裁定 → Master 登録。
- **凍結の規律**：v0.1 は凍結中。規則を直したくなったら、Ver.0.2 の差分候補として記録するだけにする。
- **正本との関係**：正本の4つの YAML は Manifest で照合されているので、直接は編集しない。成果は提案書（DocType: Proposal）として `docs/proposals/` などに出し、コミットしてから次に渡す。正本への反映は、Gin の裁定と Rev の受け入れ判定のあと。
- **C-01〜C-03 の照合**：実在の路線・駅名・自治体名と照合する。怪しいものは調べて、根拠を書く。一次チェックだけのものは、査読状態を「未査読（一次）」と明記する。
- **兄弟間の照合**：採用済みの読みとの照合（PRE-010、DIFF-008）を、毎回行う。
