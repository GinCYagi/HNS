## 2. 海北

| 検査 | NG の結果 |
|---|---|
| 典拠 | 1869年、松浦武四郎の建白書の6案「日高見道・北加伊道・海北道・海島道・東北道・千島道」の一つ（Wikipedia「北海道」、一次チェックで確認済み）。選ばれなかった名前を日ノ本で生かす、という筋は、DIFF-021（今は使われていない古称は許す）の線に合う |
| C-02（記録） | 宮崎県の字「海北」2件は、方面が遠く記録だけ。中国・青海省の海北（海北チベット族自治州、NG の知識）も記録。画家の**海北友松**（かいほう ゆうしょう、桃山時代）の名字も同じ字（読みは「かいほう」で違う） |
| C-04（記録） | 「かいほく」は「回復（かいふく）」と1モーラ近い（ほ／ふ）。高頻度語だが、完全同音ではない。記録 |
| C-07 | 字のとおり「かいほく」と読める。「うみきた」とも読めるので、初出のルビがあると安心 |
| 北加伊との関係 | 北加伊の由来「アイヌが自らをカイと呼ぶ」に金田一京助の異論がある、という一次チェックの新しい記録は大事。北加伊を外す理由の一つとして棄却履歴に残すとよい（アイヌの人々の呼び名に関わるので、確かでない由来を名に背負わせない） |

判定（案）：**海北は受け入れ可の見込み**（初出ルビ推奨）。

## 3. 北冥

- 典拠：荘子「北冥に魚有り、其の名を鯤と為す」（北の果ての大海、鯤が鵬になって飛ぶ）。壮大でよい。
- **C-05 第3層（記録）**：「冥」は冥土・冥福・冥界の字で、死の連想がある。極楽道・補陀落道で Gin が気にかけた種類。
- C-07：「冥」は日常で見ない字。ルビ必須。
- 判定（案）：条件付き。

## 4. 頼みごと

- HNS-Rev：海北に宮崎の字・海北友松・中国の海北・回復の音の記録。北冥に冥の字の記録。北加伊の金田一の異論を棄却履歴に。
- Gin：北海道を海北にするか。
