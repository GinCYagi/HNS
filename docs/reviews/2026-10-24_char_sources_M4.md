## 3. 今日のやり取りで出たもの（2026-10-24）
- 渡 ← 川（三渡・渡口）：国の名の 越→渡 とぶつかる。墨渡→墨河 は登録済み（12c01af）。三川・川口 は Gin に問い中。
- 口 ← 戸（漕口・弘口）と 口（渡口・標先岳口）：駅の出入り口の 口（よろずよ口）は普通のことばなので数えない（Gin「京都駅八条口みたいなものでは」）。標先岳口 の 山口 は地名か未確認。
- 淵 ← 津・沼・沢（＋郷岳淵内 の 河。字数が違うので表には出ない）：淵 は元が多い。
- 瀬 ← 川（瀬端）と 瀬（磯瀬）。川⇄瀬 は字の表にない。
- 三（そのまま）：三渡 だけ。ほかは 参（DIFF-042）。
- 郷岳淵内 の 内：残した理由の記録なし。河内 は国の名を決めるときに見直す（docs/reviews/2026-10-23_kuni_less_names_M4.md の2）。
