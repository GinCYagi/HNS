## 2. 滋賀＝鳰海県（条件付き）

- **DIFF-021**：「鳰の海」は琵琶湖の別名として本文にある古い呼び名。住所検索・OpenPOI では「鳰の海」も0件で、今の地名・施設名としては使われていない。また候補は「鳰海」（の を抜いた形）。DIFF-021 の線の上（許す側）。
- **C-03（条件）**：「におうみ」の後ろの「**おうみ**」は近江。近江は国の層の名（歴史の呼び名）だが、**近江八幡市・近江鉄道**など今の市名・路線名にも生きている。旧国名の線引き（今の市町名・現役の路線名と駅名には当てない）の、音の側の話。一音足しただけの形（山姿県・荊垣県と同じ型）でもある。
- C-05（記録）：「におう」は「匂う・臭う」と同じ音。「におうみ県」の頭に「臭う」が聞こえる人もいる。
- よい点：県の鳥カイツブリと琵琶湖の別名が一つになっていて、DIFF-019（場所が浮かぶか）は強い。
- 条件：Gin の判断（近江の音が残るのを許すか）。

## 3. 奈良＝鹿杉県（条件付き・弱い）

- 「しかすぎ」は「〜しか過ぎ（ない）」の言いかけに聞こえうる（E5 どおり）。
- 杉は秋田の杉穂県と同じ字（RUL-016 で許す範囲、記録）。
- 鹿（奈良公園）と杉（吉野杉）の典拠はよい。

## 4. ほかの府県

- 鴴江県：鴴（ちどり）はシロチドリの字だが、ふだんは「千鳥」と書くので見なれない。ルビ必須。ち・ど・り・え は言いやすい。
- 雅府：京都の雅。み・や・び で3拍。
- 梅詠県：梅（県の花）と和歌（和歌山の和歌）を詠む。う・め・よ・み、もつれない。
- 千橋府：浪華の八百八橋から。ち・は・し で3拍。千は千葉で消した字だが、ここでは別の県なので問題ない。
- 鉾倉県：兵（兵の武器）→鉾、庫→倉。地名の中の意味のまま対を取っている（2026-10-04 の知見どおり）。鉾は祇園祭の山鉾（京都）の字でもある（記録）。

## 5. 府の字の重なり（E5 の問い）

- 五国府（畿内）・近府（地方）は、名前の中に府がある。雅府・千橋府は、行政の「府」が付く名前。
- 「近府の雅府」「五国府の千橋府」と並べたとき、名前の府と行政の府が続く。読んで迷うほどではないが、台詞では「きんぷのみやびふ」と ぷ・ふ が続く。記録。
- 京都府・大阪府の府と市の組み方（Gin に聞く項目）は、E5 どおり Gin へ。

## 6. 頼みごと

- Gin：鴴江県・雅府・梅詠県・千橋府・鉾倉県にするか。鳰海県（近江の音）と鹿杉県（しか過ぎ）は条件付き。

## 7. 奈良＝京鹿県（きょうがけん）（Gin「京鹿県(きょうが、)」「平城京」、2026-10-05）

判定（案）：**受け入れ可**（記録3つ。Gin の裁定）。

| 検査 | NG の結果 |
|---|---|
| DIFF-024 | きょ・う・が＝3拍 |
| 典拠 | 京＝平城京（Gin）、鹿＝奈良公園の鹿。奈良の都と鹿で、場所が浮かぶ力は強い。鹿杉県の「しか過ぎ」・杉穂県との杉の重なりは消えた |
| 照合 | 京鹿：住所検索は「西ノ京鹿垣町」（京都市中京区、26104）の部分一致1件だけ。OpenPOI は「株式会社 京鹿の子」（京都の店）・「京鹿六せんべい」・「イン東京鹿沼店」の部分一致。きょうが：OpenPOI「阿賀野川きょうがせ防災ステーション」1件（NG） |
| C-03（記録） | 「京鹿の子（きょうがのこ）」は京都の鹿の子絞り・草花の名。字の頭が同じで、京都を思わせる面もある。また柳都県の中に**京ヶ瀬**（きょうがせ、阿賀野市。旧京ヶ瀬村）があり、読みの頭「きょうが」が同じ。どちらも一致はしない |
| 京の字（記録） | 本世界では東京＝東都で、京浜を使わない（棄却履歴：「京→都規則との不整合」）。また「京都相当都市の名称と『京』の字義」は保留の一覧に残っている。京鹿の京は都の名ではなく、平城京という歴史の都の字なので、京→都 の置き換えとは別の話と読める。京都（雅府）を決めるときに「京」の扱いを一緒に見るとよい |
| C-04 | 「恭賀」と同じ音（低頻度、よい意味）。「驚愕（きょうがく）」の頭とも同じ |
| DIFF-025 | きょ・う・が、もつれない |

NG の見方：典拠が強く、鹿杉の問題が解ける。京の字の扱いだけ、京都の名前と一緒に確かめるとよい。

### 7.1 奈良＝都鹿県（とがけん）（Gin「東京の京と京都の京は同じ意味なの？東の都？」→「じゃあ、都鹿(とが、)」）

判定（案）：**条件付き**。

| 検査 | NG の結果 |
|---|---|
| 照合 | 都鹿：住所0。OpenPOI は「京都鹿志館」「麗都鹿嶋店」の部分一致だけ（NG） |
| 京の字 | 京→都 に置き換えたので、東都と同じ置き換えの線にそろった |
| **C-04・C-05（条件）** | 「とが」は**咎**（とが。罪・あやまち、「お咎めなし」）と同じ音。「とがけん」は「咎県」と聞こえうる。よく使うほどではないが、意味が悪い |
| C-03（記録） | 「とが」は今の地名に同じ音がある：戸賀（秋田県男鹿市の戸賀湾、岡山県・滋賀県彦根市にも。住所検索22件）。どれも著名ではない |
| 都の字（記録） | 本世界では都は東都の字（RUL-015：路線名の「都」は東都）。都鹿の都は「昔の都」の意味で、東都の都と並ぶ。柳都県にも都がある（RUL-016 の範囲） |
| 長さ | と・が の2拍。Gin「二文字繋がり」：元の奈良（な・ら）も2拍で、長さがそろう。現実の県にも2拍は多い（奈良・滋賀・三重・岐阜）。短さは問題にしない（NG の最初の「まぎれやすい」は取り下げ） |

NG の見方：京→都 の筋は通ったが、「咎」の音が重い。京鹿（きょうが）のほうが音はよい。どちらにするかは Gin。

### 7.2 奈良＝鹿都県（かのとけん）（Gin「鹿都(かのと」）

判定（案）：**否寄り**。

| 検査 | NG の結果 |
|---|---|
| **C-02（否寄り）** | OpenPOI で「**鹿都**」の名の店が**奈良市**に2件（カフェ「鹿都」、「リバーサイドカフェ鹿都」）。字の並びがそのままで、しかも同じ奈良の中。否の線の 2（完全一致＝否）の側。蒼杜（施設「株式会社 蒼杜」で否寄り）と同じ型 |
| 照合 | 住所検索：鹿都0件、かのと は「道の駅 織姫の里なかのと」（石川県中能登町）の部分一致1件 |
| C-03・C-04（記録） | かのと は十干の「辛（かのと）」と同じ音（低頻度）。店名「かのと」（千葉県茂原市ほか）。中能登（なかのと）の部分一致 |
| よい点 | 3拍。「鹿の都」で奈良が浮かぶ。咎の音の問題は消えた |

NG の見方：名前の筋はいちばんよいが、奈良市の中に同じ名の店がある。物語で「鹿都県」が出たとき、奈良の人にはその店の名に聞こえる。
