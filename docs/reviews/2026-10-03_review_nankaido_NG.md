## 0. 結論

**南海道は、東海道（案：海つ道）と一緒に決めるのがよい**。どの案も、東海道の「海つ道（うみつみち）」と字か音が重なるため（§2）。

| 候補 | 判定（案） | 要点 |
|---|---|---|
| N1 海渡道（わたつみち） | **条件付き** | 完全一致なし。記録：「海渡」は実在の町名・店名・人の名前（かいと）、「わたつみ」から「きけ わだつみのこえ」（戦没学生）の連想。**海つ道と「海〜つみち」が重なる** |
| N2 南つ道（みなみつみち） | 条件付き | 完全一致なし。海つ道とそろえた形。ただ東海道の名に「東」がなく、南海道の名に「南」があるので、並べると向きがちぐはぐ |
| N3 補陀落道 | 否寄り（再考どおり） | C-05 第3層（補陀落渡海）。極楽道が外れて方位浄土の対もなくなった |

## 2. 東海道（海つ道）との重なり

- 東海道の案は「海つ道（うみつみち）」（9/30 査読で推奨、Gin の採否待ち）。
- N1 海渡道（わたつみち）：字の頭「海」と、音の後ろ「つみち」が海つ道と同じ。七道を並べて言うと、「うみつみち」「わたつみち」は聞き分けにくい。
- N2 南つ道（みなみつみち）：わざと海つ道と同じ「〜つみち」にそろえた形。ただ、「海つ道」は字だけ見ると「海の道」で、南の海（南海道）にも読める。東海道に「東」がなく、南海道に「南」がある並びは、読者には逆に見えるおそれがある。
- **NG の提案**：東海道と南海道は、どちらも「海」の道なので、二つを一緒に決める。たとえば、東海道を海つ道にするなら、南海道は「海」を使わない名にする。南海道を海渡道にするなら、東海道を別の名にする。

## 3. N1 海渡道（くわしく）

| 検査 | NG の結果 |
|---|---|
| 典拠（G-07） | 南海道は、加太→由良、福良→撫養と、海を二度渡る七道（一次チェックで確認）。二名島（四国）・淡路へ渡る旅の姿が浮かぶ（DIFF-019）。よい典拠 |
| C-02 | 「海渡」は実在の町名（広島の海渡町、長野の〇海渡）と店名。「海渡道」の三字では一致しない。記録 |
| **C-04（新しく見つけたこと）** | 「海渡」は男の子の名前（かいと）として多い字。字面で人の名前に見えやすい |
| **C-05 第3層（新しく見つけたこと）** | 「わたつみ（綿津見・海神）」の音は、『きけ わだつみのこえ』（戦没学生の遺稿集）で、戦で亡くなった若者を指す語としても広く知られる。極楽道・補陀落道で Gin が気にかけた「死の連想」と同じ種類なので、Gin に知らせる（主な意味は海の神で、害は小さい） |
| C-07 | 「海渡」を「わたつ」と読ませるのは当て字寄り（ふつうは「かいと」）。ルビ必須。7モーラ（わたつみち）は上限内 |

## 4. 頼みごと

- HNS-Rev：§2 を Gin への問いに。N1 に人名（かいと）・わだつみのこえ・海渡町などの記録。
- Gin：南海道と東海道を一緒に決めるか。海渡道の「わだつみ」の連想を承知で採るか。

## 5. 追加：海渡道の読み「うみとみち」の照らし直し

経緯：わだつみの記録を聞いた Gin「うみとみち では？」。海＝うみ、渡＝と（渡来・渡航の「と」）、道＝みち。

| 検査 | NG の結果 |
|---|---|
| C-01・C-02 | 住所検索・OpenPOI で「うみとみち」「海と道」とも0件 |
| C-05 | 「わたつみ」の音が消え、『きけ わだつみのこえ』の連想はなくなった |
| C-07 | 5モーラ。「渡＝と」は音読み（渡航・渡来）で、うみ・みち（訓）と混ざる読み。字面からは「かいと」「うみわたり」とも読まれるので、**ルビ必須**は引き継ぐ |
| C-04（記録） | 「うみとみち」は「海と道」（〜と〜）と聞こえる。台詞の中では、ふつうの言い回しと取れる場面がある（「海と道が続く」など）。初出は「うみとみちの国々」のように、名前と分かる言い方に。害はない |
| **C-08（記録、大事）** | 東海道のもとの案「**海つ道（うみつみち）**」とは**1モーラ違い**（と／つ）。東海道を日出路にすれば重ならない。海つ道を東海道の案に残すと、うみとみち／うみつみちで聞き分けにくい。**東海道＝日出路と組で決めるのが条件** |
| 日出路との並び | 字も音も重ならない。§5 の組（日出路＋海渡道）はそのまま成り立つ |
| 記録 | 字面の「海渡」は男の子の名前（かいと）に見える点は残る（ルビで補う） |

判定（案）：**海渡道（うみとみち）は条件付き**。条件：ルビ必須、東海道を日出路にして海つ道を外すこと。わたつみちより、死の連想がなくなった分、良い。
