## 2. 抜けている類（C5 が足すもの）
1. **左右（左京・右京・左近・右近）**：DIFF-026 の位置の字は「上中下」（と前後）で、**左右 が入っていない**。左右 も位置の物差し。郵便番号データで、市区町村に **京都市 左京区・右京区**、町域に 左京 4・右京 3・左近 8・右近 2。政令市の区の名なので、DIFF-026 に 左右 を足すかを Gin に（足せば 左京区・右京区 は替えない）。
2. **度量衡の単位（反・町・里・畝・尺・丈・坪）**：長さ・広さを測る言葉で、物差しそのもの。郵便番号データで 反田 93（五反田 40）、畝 34、丈 33（八丈町 も市町村名）、里塚 21（一里塚 など）、尺 17、千町 7。数の字（DIFF-026）と組んで 五反田・一里塚・八丈 のように物差しの意味で入っている名が多い。
   - **大事な食い違い**：字の表では **代→坪**（次点 **畝**）を使っている。坪・畝 は広さの単位なので、単位を A（替えない）にするなら、坪・畝 を 替える先の字 に使っていることとぶつかる（作中の 坪 が「元の 代」なのか「元の単位の 坪」なのか見分けがつかない）。単位を A に入れるかどうかと、代→坪 の行をどうするかを、一緒に Gin に。
   - 畝 は田の筋（うね）の意味の名も混じるので、名ごとに見る要がある。
3. **新・本・元・古（時の前後の位置）**：新温泉町（旧 温泉町）・本町・元町・古町 のような、時の前後を言う字。DIFF-026 の 前後 と近い。ただ数がとても多く、作中の名にもう替えたもの（古町→古湊 など）があるので、**C5 は A に入れない（今のまま字として見る）を推す**。論点として挙げるだけ。

## 3. まとめ
- G5 の区分けはおおむね妥当。北斗 は ウ、日の出・夕日 は B（朝暉 にそろえる）、月の名 は干支と同じく A、を推す。
- 抜け：**左右**（DIFF-026 に無い位置の字、左京区・右京区）と、**度量衡の単位**（坪・畝 が字の表の替える先に使われていて食い違う）。どちらも Gin に。

## 追記1（2026-10-24）：左京・右京 の 京（kotowari_placenames.md §10）
頼み：HNS-G5（M4 にも）。正本の京鹿市の行と、京都市の区の行（まだない）を見た。
- 左京 の作り（左右＋京〈都〉、分けられる言葉）は G5 の調べのとおりと読む。C5 は ja.wikipedia「左京区」「京職」を開いていない【要照合】。
- **エ（洛）の気がかり**：洛 は現実の京都の **古い呼び名そのもの**（洛中・洛外・上洛）。前に Gin は 上ノ道 を「古い呼び名そのものと取られる」懸念で外している（正本の 浜の筋 の notes）。洛 を使うと、作中の 雅 の都に現実の京都の呼び名がそのまま出て、同じ懸念に当たる。上洛区 が ふつうの言葉 上洛 とぶつかる点も G5 の書いたとおり。
- **ア（京を残す）を推す**：
  - 左京・上京 などの 京 は「都（みやこ）」という意味のふつうの言葉として入っていて、京都 という一つの名の 京 ではない。奈良＝京鹿 で 京 を残した先例とも合う。
  - 京→雅（京都）、京→都（東京）は、どちらも名の芯としての 京 を替えたもの。区の名の 京 は 都 の意味の言葉なので、別に扱ってよいと見る。
  - 左右 を DIFF-026 に足すかは前の査読の論点のまま（Gin に）。足せば 左京・右京 は字も残る。
- 外す寄りの 雅（左雅＝佐賀・嵯峨）・都（中都＝土浦市 中都町・中途）は、G5 の見立てに賛成。
- 見立て：**ア に賛成**。決めるのは Gin。

- 補い（2026-10-24、G5 の確かめを受けて）：C5 の引いた 上ノ道 は、上ノ道市（上越市の前の案。review_dictionary では 上山市 と音が近い〈C-03〉で外した）ではなく、**地方の名 上ノ道**（正本 541〜543 行 上越＝上柳 の ruling「上ノ道は古い呼び名そのものと取られる懸念」2026-10-09、588 行 浜の筋 の notes）。ただ、山陽道＝光面道（G-01、古い呼び名そのもの）を採った先例もあり、この懸念は一律の決まりではなく Gin がその都度見たもの。なので エ（洛）については「同じ懸念に当たりうる。採るかは Gin」に弱める。ア に賛成は変わらない。
