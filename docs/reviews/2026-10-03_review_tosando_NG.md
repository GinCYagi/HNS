## 0. 結論

| 名前 | 判定（案） | 要点 |
|---|---|---|
| 権現道（ごんげんのみち） | **否寄り**（HNS-Rev-local の見立てに同意） | 実在の「権現道」（江戸川区、OpenPOI で tourism の地点）。9/30 の行徳の権現道・東金御成街道の別名の記録と合わせ、今も使われる名前。越路→雪路の前例と同じ側 |
| 嶺路（みねじ） | **受け入れ可の見込み**（条件：ルビ） | 住所検索・施設名とも完全一致なし。雪路と同じ「〜路（じ）」の形で、七道の兄弟としてそろう |

## 1. 権現道

| 検査 | NG の結果 |
|---|---|
| C-02 | OpenPOI で「権現道」という名前そのものの地点1件（江戸川区、tourism）。部分一致ではなく名前の完全一致。住所検索は完全一致なし |
| 9/30 の記録 | 東金御成街道の別名・市川市行徳の権現道（どちらも下総＝東海道の側）。方面のずれ（C-08）で条件付き・Gin 回付だった |
| 今の物差し | Gin「基本的に今も人が居て使われる単語は除外したい」。越路（長岡市の越路〇〇、11件）を同じ理由で棄却し、雪路にした前例がある。権現道も、今も歩かれ、案内される道の名なので、同じ側に入る |
| 判定 | **否寄り**。棄却履歴に「権現道（ごんげんのみち）／東山道／C-02・C-08／江戸川区・市川市行徳の権現道、東金御成街道の別名。今も使われる名（Gin『今も人が居て使われる単語は除外したい』）」と写せる |

## 2. 嶺路

| 検査 | NG の結果 |
|---|---|
| C-01・C-02 | 国土地理院の住所検索で「嶺路」完全一致なし（total 3）、「みねじ」完全一致なし（total 42）。OpenPOI も0件。峰路も完全一致なし |
| 組み立て | 東山道の古訓「やまのみち」→ 山→嶺、道→路。雪路（北陸道）と同じ「〇路（〜じ）」の形。G-07 寄りの作り直し（古訓が典拠）。RUL-008 で Gin 裁定が必須 |
| C-07（条件） | 「嶺」は「みね」とも「れい」とも読む。「れいじ」と読まれると「零時・例示」と同じ音になる。**ルビ必須**（初出だけでなく、七道の名を並べる所でも） |
| C-08 兄弟 | 雪路（ゆきじ）と嶺路（みねじ）で「〜じ」が並ぶ。字面も音も分かれていて、まぎれない。雪＝北陸の雪国、嶺＝東山道の山国と、土地の姿に合う。よい並び |
| C-08（記録） | 七道の名の形がそろっていない：雪路・嶺路（〜じ）、火守道・神府道（〜のみち）、海つ道・補陀落道（案、〜みち）、五国府（畿内）。名前ごとに由来があるので問題ではないが、一覧にすると形が三つある。記録 |
| **C-08（層、記録）** | 現実の東山道は、近江・美濃・飛騨・信濃・上野・下野・**陸奥・出羽**まで含む。本世界では「陸奥」は東北地方の名前（G-02）。嶺路（道）の中に、陸奥（地方）が入る形になる。東山道の範囲と、陸奥（地方）がどの層にあるかを、つながりの地図に一行書く（現実の七道と地方区分は別の物差しで、重なるのは自然） |
| 子との関係 | 科坂（長野県）の親になる。嶺路が決まれば、科坂の親待ち（P-02）が解ける |

判定：**嶺路は受け入れ可の見込み**（条件：ルビ必須、Gin 裁定）。

## 3. 見送りについて

- 山路（65件）・雲路（出雲路）・岳路（長崎）の見送りは妥当。

## 4. 頼みごと

- HNS-Rev-local：権現道を否寄りとして棄却履歴に写せる形に。嶺路に「れいじ」の読まれ方と、陸奥との層の一行。
- Gin：東山道を嶺路にするか（権現道は下げる）。
