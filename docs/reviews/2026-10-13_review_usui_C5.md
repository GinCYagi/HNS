## 2. 由来（薄井家）

- 由来は、人の名（薄井家）。臼井ではない。
- 人の名から来た名は替える（DIFF-035）。由来で見分ける（DIFF-037）。替えること自体は必要。
- 前の査読で C5 が書いた「由来が確かめられるまで決めない」（DIFF-037）は、この出典で満たされる。C5 の保留は、ここで解ける。
- 出典は M4 の連絡。C5 は開いて確かめていない。【要照合】（Gin か M4 が、出典の 2 冊の記述を見てほしい）。

## 3. あわい（推し）

- **長さ（DIFF-043）**：うすい（3 拍）→あわい（3 拍）。同拍。○
- **元と同じ音**：元の音（う・す）を残さない。あわい は、い だけが同じ（うすい の最後の い）。元の読みを丸ごと入れていない。○
- **字（DIFF-016・DIFF-028）**：薄（うすい）→淡（あわい）。同じ「うすい」（色・密度が薄い）の意味。近い意味の字。○
- **字の簡単さ（DIFF-039）**：淡は、薄より画数が少なく、簡単な字。○（薄 は 16 画、淡 は 11 画。C5 の数え）
- **人の名の糸**：薄井家の名から来た薄を、意味の字（淡）に替えた。人の名の字は残していない。○
- **照合（郵便番号データ・町域）**：淡 は 町域に 25 件（字そのもの）。淡井 は 0 件。あわい（読み）の町域は、G5 の照合どおり、読みの一致は見ていない（【要照合】）。
- **照合（Web）**：同名の百貨店・会社は見つからなかった（G5）。睡眠の贈り物のブランド「awai」（T&E JAPAN）がある。読みは ローマ字の awai で、名の綴りは違うが、近い。商品の分野は別（睡眠ギフト）なので、ぶつかりは小さいと見る。【要照合】（J-PlatPat で商標を確かめる）。
- **気がかり（C5 の見立て）**：あわい は、普通の語（「間（あわい）」「淡い」）と同じ。店の名として、語が紛れる見方はある。オーカーのときと同じ型なので、Gin の判断で受け入れてよい。C5 は、この気がかりを記録するだけ。
- **旧かなの糸（あわゐ）**：1930 年の うすゐ を残す形。3 拍。元の音とは重ならない。○。看板の古い場面だけに使うなら、G5 の案のとおり。

## 4. かやい（次点）

- **長さ（DIFF-043）**：3 拍。同拍。○
- **元と同じ音**：う・す を残さない。○
- **字**：薄（すすき）→萱（かや）。読みの筋は「すすき」。字の意味（同じ屋根を葺く草）は近いが、薄（すすき）の読みは、元の「うす」とは違う読み。○（字の使い方は決まりに反しない）
- **由来との筋**：薄井家の 薄 は「うす」と読む人の名。かやい は、薄（すすき）の読みを使うので、由来からは一歩遠い。次点のままでよい。
- **照合**：町域の 萱 は 92 件（字そのもの）。萱井 は 0 件。茅乃舎（かやのや）が近い名として出た（G5）。同名ではない。【要照合】。

## 5. あつい（否寄り）

- **対の字（DIFF-016）**：薄↔厚 は対の字。○（決まりに反しない）
- **長さ**：3 拍。同拍。○
- **否寄りの理由**：あつい は、暑い・熱い と同じ音。店の名として、季節の語（暑い）に紛れやすい。C5 も、否寄りに賛成。
- **照合**：町域の 厚 は 86 件。厚井 は 0 件。

## 6. きねい を残すか（G5 の見立て）

- C5 も、**残さない**に賛成。
- きねい は「うすい＝臼＋い」と読んで、臼↔杵（対、DIFF-016）で作った名。由来が薄井家になった今、臼の読み替えの筋は切れている。
- 由来に合わせて決め直すのが、DIFF-037 の決まり。
- 「うす→きね」の連想は、音の遊びとしては耳に残る。Gin が音の遊びとして残すなら、由来の記録に「臼の読み替えによる遊び」と書いて残す形になる。これは Gin の裁定。
