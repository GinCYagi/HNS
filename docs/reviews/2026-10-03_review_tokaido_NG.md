## 2. T1 日出路

| 検査 | NG の結果 |
|---|---|
| 組み立て | 東＝日の出る方。一字＋路の型（雪路・嶺路）に並ぶ二字＋路。DIFF-020 の範囲。曙（Project AKEBONO）・朱島・光面道の夜明けの筋とつながる |
| 南海道との並び | 海渡道（わたつみち）と字・音とも重ならない。§2 の東海道・南海道の重なり（NG の南海道の査読）が解ける |
| C-02・C-03（記録） | 「日の出」は地名として非常に多い（247）。東京都日の出町（自治体）は、東海道（武蔵）の中にある。「日出路」の三字とは一致しないが、「ひので」の部分が重なる。条件付き |
| C-01（記録） | ゆりかもめ日の出駅（東京都港区）。「日出路」は駅名ではないので一致しない。記録 |
| **C-08（新しく見つけたこと）** | 本世界の名「**日ノ本**」は「日の出る本（もと）」の意。「日出路」も「日の出る方の道」。国の名と道の名が同じ意味を持つ。日ノ本の中で、東の道がとくに「日の出」を名乗る形。よい重なりとも、国全体の名と取り違えるとも読める。記録 |
| 記録 | 「日出（ひじ）」は大分県の日出町（ひじまち）。読みは違う。記録 |
| C-07 | 「日出」は「ひので」「ひいで」「ひじ」と読みが分かれる。ルビがあると安心（必須とまでは言わない） |

## 3. T2 富嶽路

- 「富嶽」は富士山の古い呼び名だが、富嶽三十六景、富岳（富嶽）の名の施設・学校・ゴルフ場・スーパーコンピュータ「富岳」など、**今も広く使われる名**。DIFF-021（今は使われていない古称は許す）の側ではなく、越路・潮待道と同じ「今も使われる」側。**否寄り**。

## 4. T3 宿継道

- 宿場で人馬を継いで旅を続けた東海道の姿（宿継ぎ）。一般語の「宿継ぎ」は低頻度で、C-04 は記録。7モーラ（しゅくつぎのみち）で上限ちょうど。衝突は少ないが、土地の姿（東・海・日の出）は浮かびにくい（DIFF-019）。条件付き。

## 5. 東海道と南海道の並び（NG）

| 組み合わせ | 見え方 |
|---|---|
| 日出路（東海道）＋海渡道（南海道） | 字・音とも重ならない。東は「日の出」、南は「海を渡る」で、方角の姿がそれぞれ立つ。**NG はこの組を推す** |
| 海つ道（東海道）＋海渡道（南海道） | 「海〜つみち」が重なる（NG の南海道の査読 §2） |

## 6. 頼みごと

- HNS-Rev：T1 に日の出（247、日の出町・日の出駅）、日ノ本との意味の重なり、日出（ひじ）の記録。T2 を否寄りに。
- Gin：東海道を日出路にするか（南海道の海渡道と組で）。

## 7. 追加：松並道・継路の査読（日出路の見直しのあと）

経緯：Gin「日出ずる国のメインストリート、という意味ではありかもしれないけど、西の人はイラッとしそう」で日出路を見直し（§2 の「日ノ本と意味が重なる」記録とも合う）。HNS-Rev の第2の候補。

### T4 松並道（まつなみのみち）

| 検査 | NG の結果 |
|---|---|
| 典拠（G-07） | 東海道の松並木（御油の松並木など）。街道の姿として名高く、東海道らしさがよく出る（DIFF-019） |
| C-02（記録・条件） | 「松並」は実在の地名31（東海道の国の中にも古河市・守谷市）。三字の「松並道」とは一致しないが、頭の二字が地名と同じ。名字の「松並」もある。条件付き |
| C-03（記録） | 「まつなみ」は松波・松浪（名字・地名）と同音。記録 |
| C-07 | 7モーラ（まつなみのみち）で上限ちょうど。字のとおり読める |
| 海渡道との並び | 松並道（まつなみのみち）と海渡道（うみとみち）は、字・音とも重ならない。**東＝松並木の陸の道、南＝海を渡る道**で、白砂青松（海辺の松）の取り合わせにもなる。よい並び |
| 西の人への受け取られ方 | 松並木は東海道に限らず、全国の街道にある姿。「東が上」と聞こえる響きはない（日出路の心配は解ける） |

判定（案）：**条件付き（推奨に同意）**。条件：「松並」の地名31件の記録。

### T5 継路（つぎじ）

- **否寄り**：築地（つきじ）と1モーラ違い（清濁だけ）。築地は全国152、とくに東京の築地は名高く、東海道（東都）の中にある。C-03「著名地名と近似、方面が同じ」に当たる。

## 8. まとめ（東海道と南海道の組）

**松並道（東海道）＋海渡道（うみとみち、南海道）**を NG は推す。日出路（見直し）・海つ道（うみとみちと1モーラ違い）・継路（築地）は外す。
