【HNS】点検｜HNS-G5 の受け持ちで「確かめずに使っている危ないもの／止めたが実は使えるもの」（ALM-M4 の同報、Gin の頼み、2026-10-27）

作成：2026-10-27（HNS-G5）
見た範囲：G5 が名の照らしに使っている外のもの四つ（郵便番号データ・常用漢字表・weblio・ja.wikipedia／コトバンク）。各サービスの規約の本文は 2026-10-27 に WebFetch で読んだ。

## (a) 確かめずに使っている危ないもの
1. **weblio を homo.py（プログラム）で引いている**（G5 のスクラッチパッドの道具、2026-10-22 から。記録の中に「weblio（homo.py）」の書きが多数）。
   - 根拠：weblio 利用規約 第10条「ユーザーはWeblioによってユーザーに提供されているインターフェイス以外の手段を用いてサービスにアクセスしてはならないものとします」。第5条は商業目的の利用（使用・複製など）を禁じる（https://www.weblio.jp/info/terms.jsp、2026-10-27 参照）。
   - G5 の見立て：homo.py（urllib で見出しを抜く）と WebFetch での weblio の取得は、第10条の「提供されているインターフェイス以外の手段」に当たりうる。使い始めるときに規約を確かめていなかった。
   - 対案：homo.py をやめる（G5 は今から使わない）。同じ音の言葉は ① 人がブラウザで weblio を引く（提供されている使い方）、② ウィクショナリー（CC BY-SA、MediaWiki の API がある）を道具で引く、③ 手元の辞書データで、使ってよいと書いてあるもの を探す。どれにするかは Gin に。記録に残っている「weblio：〇〇」の結果（照らしの事実）は、名の決めに使っただけで、weblio の本文は写していない。
   - M4・C5 も weblio を引いている（記録の書きから）。どう引いているかは確かめていない。

## 危なくないと確かめたもの
2. 郵便番号データ（utf_ken_all.csv、リポジトリの外）：日本郵便の readme「郵便番号データに限っては日本郵便株式会社は著作権を主張しません。自由に配布していただいて結構です。」（http://www.post.japanpost.jp/service/search/zipcode/download/readme.html、2026-10-27 参照）。取り込みは Gin の許し（前のセッション）。
3. 常用漢字表（ja.wikipedia から拾った 2,136 字、リポジトリの外）：表そのものは文化庁の告示（G5 の知識、告示の著作権の扱いは確かめていない）。ja.wikipedia の文は CC BY-SA で、字の並びだけを手元で照らしに使い、配っていない。取り込みは Gin の許し。
4. ja.wikipedia・コトバンクの由来の書き：提案に短く言い換えて書き、出典をつけている。長い写しはしていない（G5 の見立て）。

## (b) 止めたが実は使えるもの
- G5 の受け持ちでは見当たらない。見たもの：G5 が「使わない」と決めた外のものは、この点検の範囲では、なし。
