## 1. S1 三坊

### 1.1 照合（国土地理院の住所検索、NG）

| 検査 | 結果 |
|---|---|
| **C-02（新しく見つけたもの）** | 「三坊」を含む地名が10件。うち**京都市中京区（自治体コード 26104）に6つ**：三坊大宮町、三坊猪熊町南組・北組、三坊堀川町、西三坊堀川町、三坊西洞院町。平安京の条坊（左京三条三坊など）の名残の町名。ほかに「十三坊」（2件）、「三坊木」（岩手）、十三坊塚。**「三坊」だけの地名はない**ので完全一致ではない。記録・条件付き |
| C-08（京都との結び付き） | 一次チェックは「三を残すと京都の通り名との衝突を避けられる」としたが、「坊」の字そのものが平安京の条坊の言葉で、現実の京都の町名にも「三坊」が残っている。本世界の畿内は五国府（京都＝山城を含む）。越後にあたる柳都県の町が、都の条坊の言葉を名乗る形になる。害はないが、「なぜ越後の町が都の区画の名か」は、由来メモで説明できるとよい（三条も、もとは京の三条にちなむと言われる名なので、同じ筋で説明はつく。NG の知識、未確認） |
| C-01 | 「三坊」「さんぼう」の駅は、住所検索・NG の知識の範囲では見当たらない。全国駅名リストでの機械照合は HNS-Rev の手元で |
| C-03・C-04 | 「三宝（さんぼう）」＝仏・法・僧。寺の町（本成寺・三条別院）との掛詞は、一次チェックどおり Gin に。**記録を足す**：「三方（さんぼう／さんぽう）」＝神前に供え物をのせる台（神饌の台）。三宝と書くこともある。社寺どちらにも通じる語で、害はない。住所検索で「三宝」を含む地名は34件（三宝寺・三宝山・三宝荒神山、堺市堺区三宝町 ほか）。**堺市の三宝町（さんぼうちょう）は、市にしたときの「三坊市」とは字も形も違う**が、音の上で記録 |
| C-05 | 「坊」は坊や・坊主の語感があるが、侮る含意はない。むしろ寺の宿坊・僧坊の字で、寺の町に合う。一次チェックどおり合 |
| C-06 | 条⇔坊は東西と南北の区画の対で、格・規模の対ではない。合 |
| **C-07** | 三坊は4モーラで読める。**雀三坊駅（すずめさんぼう）は7モーラで、通称の上限（7モーラ。8以上は否）ちょうど**。これ以上何かを足す駅名（「〜口」など）は付けられない。記録 |

### 1.2 「三」を残す判断

- 妥当。十日町→什旭町で「十」を字の中に残したのと同じく、数は残して1字を替える型。数を替えると、京都の一条〜九条や、全国の「〇条」（北海道の条丁目など）と当たりやすい。
- ただし §1.1 のとおり、「坊」の側で京都の町名に当たる。どちらを替えても京都の条坊と縁が切れないのは、三条という名前のもとが京の三条にあるから。Gin に「京の言葉を名乗る町」として受け入れるかを聞く。

## 2. S2・S3

- 一次チェックどおり。三筋は台東区三筋と同名・同音（否寄り）、牛肉の部位「ミスジ」も記録。三縄は三縄駅と完全一致（否）。

## 3. 頼みごと

- HNS-Rev-local：S1 の照合に、京都市中京区の「三坊〜町」6つと、三方（神饌の台）・堺市三宝町を足す。雀三坊駅が7モーラちょうどであることを記録。
- Gin：三坊を、京都の条坊の名残の町名（三坊大宮町など）を承知のうえで採るか。三宝・三方との掛詞にするか。

## 4. 追加：参坊（さんぼう）の査読（第2版 6bd5980・1efffc4）

Gin のヒント（原文）：「一二三／壱貳参／で書き換えるならわしがある／書き足されないために」。三→参は、改竄を防ぐための大字。

| 検査 | NG の結果 |
|---|---|
| C-01・C-02 | 国土地理院の住所検索で「参坊」「雀参坊」とも0件。京都の「三坊〜町」6つとは字が重ならない（§1 の条件は、字の上では解けた） |
| 組み立て | 三→参（大字）、条→坊（条坊の対）。**十日町→什旭町の「十→什」も大字の置き換え**（什は十の大字）。これで同じ型が2つそろう。DIFF-016（対字・近い字）の一つとして扱うより、**「数の字を同じ数の大字に替える」**として DIFF-016 の中に一行明記するか、別の DIFF に分けると、あとの命名（一→壱、二→弐…）で迷わない。Gin のヒントの「書き足されないために」は、由来メモにそのまま使える |
| **C-04（NG が §1 で見落としていたもの）** | **「参謀（さんぼう）」と完全同音**。しかも頭の字「参」も同じ。参謀（作戦参謀・参謀本部）はよく使う一般語。**三坊（§1）も同じ「さんぼう」なので、§1 の判定にもこの記録を足す**（NG の見落とし。§1 では三宝・三方だけを挙げていた） |
| C-04 の重さ | 凍結版では、一般語との完全同音で日ノ中（火の中）を棄却し、2026-10-03 には什陽（重要）を否寄りにした。その物差しでは、さんぼう（参謀）も同じ側に入る。ただし、三宝（仏法僧）・三方（神饌の台）とも同じ音で、「さんぼう」という音そのものが複数の語に分かれている。什陽の「重要」のように一つの語に強く引かれる形ではない。**条件付き**（否寄りとまでは言わない）として Gin に回す |
| C-07 | 「参」はふつう「さん」と読むので、「さんぼう」と素直に読める。「まいりぼう」と読まれる余地は小さい。ルビは初出だけで足りる |
| C-07 駅名 | 雀参坊駅（すずめさんぼう）は7モーラ。上限ちょうど（§1 と同じ） |
| C-08 | 「参」は参詣に通じ、寺の町（宿坊）と合う。よい連想 |

判定（案）：**参坊は条件付き**。条件は C-04「参謀と同音（字の頭も同じ）」を Gin が承知すること。三坊と比べると、京都の町名との字の重なりがない分、参坊のほうが良い。

Gin に聞くこと：さんぼう＝参謀と同じ音・頭の字も同じことを、承知で採るか（作品は会社・戦略の話も多いので、台詞で「参謀」と並ぶ場面がありうる）。
