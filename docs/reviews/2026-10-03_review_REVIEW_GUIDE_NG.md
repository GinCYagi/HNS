## 0. 結論

大きな筋は正本と合っている。とくに「検索の要約を事実にしない」「住所検索の UTF-8」「Codex はリポジトリでやり取り」「受け入れ判定は NG が戻ってから」は、今日の経験から出た大事な注意で、よい。
直すとよい所が5つ（§1〜§5）。どれも新しい決まりではなく、正本にあるものを写すだけ。

## 1. 査読プロトコルの「否の線」を書く（いちばん大事）

§3.1 は順番だけで、**どこからが否か**が書かれていない。specification の review_protocol には、項目ごとに線がある。誰が査読しても同じ結論になるよう、写しておくとよい。

| 番号 | 正本の線（review_protocol の fail） |
|---|---|
| 1 実在の路線・駅名 | 現役名と完全一致＝否 |
| 2 実在の自治体・企業名 | 完全一致＝否、部分一致＝記録の上判断 |
| 3 同音・近似音の実在地名 | 著名地名と同音＝否、近似＝条件付き（方面が離れていれば可）。母音骨格の一致も近似とみなす |
| 4 一般名詞との同音 | **高頻度語と同音＝否、低頻度語＝記録** |
| 5 差別的・侮蔑的含意 | C-05 三層判定（常に行う） |
| 6 世界観整合 | 格降格＝否、方面矛盾＝Gin 裁定へ回付 |
| 7 モーラ・可聴性 | **通称8モーラ以上＝否**（7が上限）、難読＝条件付き |

- §3.2 の C-04 の行「一般名詞と完全に同じ音・字は否の側」は、正本では「**高頻度語**と同音＝否、低頻度語＝記録」。頻度の物差しを足す（例：什陽＝重要は高頻度、参坊＝参謀は三宝・三方と分かれるので条件付き、白嶺・川湊は低頻度で記録）。
- §3.1 の6は「C-06 格の反転・C-08」と書かれているが、正本の6「世界観整合」の方法は「格ランク比較・経路と名称の方面照合・由来メモと既採用名の歴史矛盾確認」。この言葉のまま写すとよい。

## 2. §3.2 の表の誤り（1か所）

- RUL-017 の例に「越路・上ノ道市は棄却履歴」とある。**上ノ道市は RUL-017 ではなく C-03**（上山市と近い音。review_dictionary の rejection_log でも checks は C-03）。越路は「RUL-017 寄り」で合っている。上ノ道市は C-03 の例に移す。
- C-04 の前例の「雁木市」は、NG の査読の判定（否寄り）で、正本の棄却履歴にはまだない（Gin が軒結市を採ったので候補に下げた扱い）。「前例」と書くなら、「NG の査読で否寄り」と添える。

## 3. §3.2 に足すとよい裁定

| 決まり | 要旨 | なぜ要るか |
|---|---|---|
| RUL-016 | 同字・同意の重なりは許す（「津」は全国に多数） | 字の一部が重なるたびに否にしないため |
| RUL-018 | 動物の字を含む地名は残す | DIFF-017（鳥の置き換え）とセットで読む |
| RUL-020 | HNS の役目：カッコをなくす。分からないときはカッコで聞く | 推測で埋めない根拠 |
| RUL-022 | りゅうとの命名規則は埼玉県さいたま市の応用 | 県は漢字・市はひらがなの型 |
| RUL-008 | G-07 は Gin 裁定を必ず通す | §3.2 の G-07 の行の根拠 |

## 4. §3.3 の層に「国」を足す

- Gin「1 okです」の線引きで「国の層は歴史の呼び名として残す」と決まった。層は、七道（雪路ほか）＞ **国（旧国名：越後・佐渡・磐城など、歴史の呼び名）** ＞ 都道府県 ＞ 県の中の地方名 ＞ 市町村 ＞ 地区・通り・施設。
- 島と市がずれる例も足すとよい：佐渡（島・国）と、その上の市（候補：朱島市）。

## 5. §6 の push の時期

- 「コミットして push する。push の時期に Gin の指示があればそれに従う」とある。今日までの運用は、**NG の査読文書は Gin の OK のあとで push**（9/30 の査読依頼の「査読結果は docs/reviews/ にコミットしてから Gin に返す」と、10/2 以降の「push は Gin の OK のあと」の両方がある）。HNS-Crd が迷わないよう、どちらで行くかを一行で決めておく（決めるのは Gin）。
