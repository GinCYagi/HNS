## 3. 青森＝碧林県

| 検査 | NG の結果 |
|---|---|
| DIFF-016 | 青→碧、森→林。どちらも近い字。よい |
| DIFF-019 | 「碧の林」から「青い森」が浮かぶ。よい |
| C-03・C-04（記録） | 「へきりん」は「**げきりん（逆鱗）**」と1音違い。意味は離れていて、方面も関係ない。記録 |
| C-07 | 音読み4字で少し硬い。ルビ推奨（一次チェックどおり） |
| 記録 | 「碧」は愛知県碧南市・静岡県の一碧湖など、地名の字として各地にある（住所検索56件）。並びは一致しない |
| 先のこと（記録） | 現役の鉄道「**青い森鉄道**」（旧東北本線、Wikipedia「青森県」本文）は、県名の「青森」とは別に、路線名として替える必要がある（旧国名の線引き：現役の路線名には実名を当てない） |

判定（案）：**受け入れ可**。

材料（Gin へ、急がない）：由来の「海上からの目印になる森」は、標先（柏崎、船の目印の丘）と同じ筋。碧林県の由来メモに「海から見える目印の森」を一言添えると、柳都県の中の標先と響き合う。

## 4. 宮城＝杜城県

| 検査 | NG の結果 |
|---|---|
| DIFF-016 | 宮→杜（社に縁のある字）。城はそのまま。よい |
| G-01 の型 | 仙台の雅称「杜の都」を県名に映す。柳都（新潟市の雅称）→柳都県と同じ型。よい |
| C-01・C-02（記録） | 日本の地名・施設とは一致しない。ただ、**字の並び「杜城県」が、中国・晋代の県名と同じ**（§1）。今は使われていない外国の古い県名なので、否の線（現役名）には当たらない。記録 |
| C-07（条件） | 「杜」を「もり」、「城」を「ぎ」と読むのは、字から出にくい（「城＝ぎ」は宮城の読みの借り）。初見では「とじょう」「もりしろ」と読まれる。**ルビ必須**（一次チェックどおり）。「とじょう」は「途上」と同じ音 |
| C-03（記録） | 森木（もりき）と1音違い（一次チェックどおり） |
| **親子のつながり（条件）** | 「杜」は仙台市の雅称の字。県に使うと、**仙台市の日ノ本名を作るとき、いちばん自然な材料（杜の都）が県とぶつかる**。柳都県とりゅうと市（RUL-022）と同じ組み方にするのか、仙台市は別の材料で作るのかを、**県と一緒に決める**のがよい |

判定（案）：**条件付き**。条件：①ルビ必須、②仙台市の名前の方針を一緒に決める、③「杜城県」＝晋代の県名の記録。

## 5. 岩手＝誓岩県

| 検査 | NG の結果 |
|---|---|
| G-07 | 伝説の「鬼の確約」を「誓い」で表す。よい。由来メモは「鬼が二度と荒らさないと確約し、その証の手形を岩に残した」と、本文の「確約」の語で書くのが確か |
| DIFF-019 | 「岩」が残り、手形の伝説を知る人には岩手が浮かぶ |
| C-04（条件） | 「せいがん」は、一次チェックの「誓願」（仏教の語、寺の名に多い）のほか、**ふつうの語「西岸」**（川の西岸、西岸海洋性気候）とも同じ音。「晴眼」「青眼」も同音。否の線の「高頻度語」とまでは言えないが、台詞で「せいがんけん」と言えば「西岸県」と聞こえうる。記録し、読み上げで確かめる |
| C-05（記録） | 誓願は意味のよい語。宗教の重さは軽い |

判定（案）：**条件付き**。条件：①読み上げで「西岸」と聞き分けられるか確かめる、②G-07 なので Gin の裁定。

## 6. 秋田＝杉穂県

| 検査 | NG の結果 |
|---|---|
| G-07 | 県の木の秋田杉（日本三大美林）と、あきたこまちの稲穂。どちらも本文で確かめた。よい |
| DIFF-019（記録） | 「杉」は吉野杉・屋久杉など各地にあるので、名前だけで秋田が浮かぶ力はやや弱い。由来メモで「秋田杉」を書けば足りる |

判定（案）：**受け入れ可**（G-07 なので Gin の裁定）。

## 9. 宮城の Gin 案「杜砦（とさい）」と採決

- Gin「見杜　砦　（」→「宮⇔杜　城⇔砦」→「tosai」（2026-10-03）。
- 杜砦・とさい：住所検索0件、OpenPOI 0件（「とさいち」など部分一致だけ）、Wikipedia 完全一致0件。
- DIFF-016：宮⇔杜、城⇔砦（どちらも近い字）。音読みで字のとおり読める（C-07、もりぎより楽）。とさいけん＝5モーラ。
- 記録（C-03・C-04）：頭の「とさ」は土佐（高知）を思わせうるが、方面は遠い。「都債」と同音（低頻度語）。「とりで」と読まないので、取手市との同音は避けられている。
- §4 の③（仙台市の名前の方針を県と一緒に決める）は、杜砦県でも残る。
- 採決：Gin「ここまでのものを採択、次に行きます」（2026-10-03）。対象は 碧林県・誓岩県・杜砦県・杉穂県。
