## 1. 瑞前・瑞中・瑞後 の作り方：**現実の作りと字の取り方がずれている**（いちばん大事）
- 現実：吉備国 が分かれて 備前・備中・備後。**頭の字は 吉備 の二字目 備**。
- 推し：吉備 の **一字目 吉** を 瑞 にして頭に置く。現実の 備前 には 吉 の字がないので、「吉→瑞」は現実の名の字の替えになっていない。
- 越→渡 の前例は、越前 の 越 が 越国 の名の字そのもので、合っている。苗後（丹後）も、丹波＝苗庭 の頭の字を受けていて、現実の 丹後＝丹波の 丹 と同じ作り。**瑞〇 だけが、現実と違う字を受けている**。
- 直す道（見立て）：
  - ア：先に 吉備 の名を決め（親が先）、その **二字目** を 前・中・後 の頭に置く（現実の作りと同じ）。
  - イ：備 を意味で替える（備＝そなえる）。例 具前（ぐぜん＝偶然 と同じ音）・整前 など、照らしていない。
  - どちらにするかは Gin に。今の 瑞〇 で行くなら「吉備 の吉 を取った」という作りの違いを記録に。

## 2. 呼母（よびも）の 母＝も
- 母 を も と読むのは、決まった読み（はは・ぼ）の外で、当て読み一つ（G5 の数えどおり）。DIFF-018 ④ の内。
- 気がかり（小さい）：G5 の言う 母屋 は ふつう おもや（母＝おも）と読み、も 単独の読みの例としては弱い。ルビ必須と、読みのわけ（DIFF-018 ②）を行に書く。
- 母を呼んだ話から、母来（古い名そのもの）を避けた作りは筋が通る。受け入れ可。

## 3. 湧雲（わくも）＝鶏蜱 の音
- 鶏蜱 は鳥につくダニで、悪い意味というより害虫の名。耳で聞いて取り違える場面は少ないと見る（見立て）。記録で受けられる。
- 気になるなら次の案（照らしていない）：八雲立つ の 立 を使う **立雲（たつくも・4）**。出→立（出る→立つ、近い意味）、雲 は理の字で残す。元 いずも 3 の ±1。

## 4. 巡香（周芳）
- 改めの前の名に戻す形は、潮来＝板久市・山城＝峰背 の前例どおり。周→巡・芳→香 は同じ意味。受け入れ可。

## 5. ほか
- 苗庭・苗後・唯馬・穂敷・磐洋・隔洲・御峠・悠戸：受け入れ可。
  - 穂敷：りゅうと市 穂敷兎町 とのつながりは、作中で 因幡の白兎 の連想を受け継ぐ形で筋が通る。
  - 隔洲＝隠す の音：元の 隠 の字の意味を音で残す形で、遊びとして受けられる。
- 拓間（たくま）：読みが 今治市 宅間・大牟田市 田隈 と同じ（字は違う、記録）。たくま は 琢磨 や人の名（拓真 など）にも多い、ふつうの音。
- 安芸 を後に回す、に賛成（DIFF-040、戦災の土地）。
