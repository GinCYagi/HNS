## 2. S1 朱島

| 検査 | NG の結果 |
|---|---|
| 典拠（G-07） | 朱鷺色の「朱」と、夜明けの「明け」。日本産トキの絶滅（2003）と佐渡での放鳥（2008）を、再生として表す（一次チェックで確認済み）。作品の「先代の想いを遺す」「消えて欲しくない」の筋と重なる |
| **C-08（よい連想、新しく見つけたこと）** | 「あけ」は、作品の**曙商会・Project AKEBONO（曙＝あけぼの）**と同じ音の頭。朱（あけ）の島が、夜明け・再生の筋で、曙の名とつながる |
| C-07（条件） | 「朱」はふつう「しゅ」「あか」と読む。「あけ」は古い読み（朱の玉垣など）。**ルビ必須**（字面から「しゅとう」「あかしま」と読まれうる） |
| C-04 | 「あけじま」に一般語はない。記録なし |
| **層（記録）** | 島の名は「佐渡」（旧国名の線引きどおり残す）、市の名は「朱島市」。市の名も「〜島」で終わるので、読者には「佐渡島とは別の、朱島という島がある」と見えるおそれがある。現実の佐渡市（佐渡島の上の市）と違い、島と市の名がずれる。つながりの地図に「朱島市は佐渡（島）の上の市。朱島という島はない」と一行書く。由来メモでも「島全体の市」と書く |
| C-08（記録） | 福島は禄嶋（嶋）、佐渡市は朱島（島）。字が「嶋」と「島」でずれるが、別の名前なので問題ではない。記録 |

## 3. S2 黄金島

- 典拠：佐渡金山。分かりやすい。
- 記録（C-04）：「黄金町（こがねちょう）」は全国に41件。中でも横浜市中区の黄金町は、かつての歓楽街として知られた町（NG の知識）。「こがね〜」の地名から、その連想を持つ人がいる。害は小さいが記録。
- 「島」の層の記録は S1 と同じ。
- 条件付き。

## 4. S3 朱鷺島

- 一次チェックどおり。「とき」は上越新幹線の現役の列車愛称。本世界の東柳新幹線の列車愛称（「とき」をどうするか）は、まだ pending にある。そこが決まれば、扱いが変わりうる。条件付き〜否寄り。

## 5. 見送りについて

- 金島（15件）、金北（金北山）、鷺を含む案（トキはサギではない）の見送りは、どれも妥当。トキ科とサギ科の違いを確かめて外したのは、よい（青鷺城の「鷺」とも混ざらない）。
