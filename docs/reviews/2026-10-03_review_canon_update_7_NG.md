## 1. A：遠岡

- Gin の言葉「遠岡で、十日町は什陽（じゅうよう）査読」は、HNS-Rev の問い「短山のままか、遠岡か」への答えとして引かれている。P-04 足りる。
- NG の §11（2026-10-02 の査読の文書）のとおり、C-06・G-05 合、住所検索0件。
- **条件**：遠岡の C-08（十日町＝とおかまちとの読みの近さ）は、十日町の HNS 名が決まって「とおか」の音が消えたときに解ける。B の什陽が否になっても、十日町に「とおか」を含まない名前を付ければ同じく解ける。pending に「十日町の名前は『とおか』の音を避ける（遠岡との C-08）」と1行残す。
- 短山を interim と rejection_log に残し、大祓詞の典拠を記録として残すのはよい。社帰原重の parent を遠岡に直すのも差分案どおり。
- 記録（§11 のとおり）：富岡（とみおか）と1モーラ違い。

## 2. B：什陽

| 検査 | NG の結果 |
|---|---|
| C-01・C-02 | 国土地理院の住所検索で「什陽」「じゅうよう」0件。実在の地名なし |
| **C-04（否寄り）** | 一般語「**重要**」と**完全同音**。とても使用頻度の高い語。さらに、市を付けた「什陽市（じゅうようし）」は「**重要視**」と**完全同音**になる。凍結版の C-04（一般名詞同音）では、**日ノ中（ひのなか＝火の中）を C-04 だけで棄却**し、小波（このは＝木の葉）も C-04 を理由の一つに棄却している（rejection_log）。什陽は同じ型で、しかも「重要」は「火の中」「木の葉」よりずっとよく使う語。台詞で「什陽に行く」「什陽市の…」が「重要に…」「重要視…」と聞こえる |
| C-04（よい連想） | 「重陽（ちょうよう）」＝菊の節句。字は似ているが読みが違う。記録 |
| C-07 | 「什」は日常で見ない字（什器・什物）。ルビ必須 |
| C-08 | 遠岡（とおおか）との重なりは消える（よい点） |
| 由来（記録） | 現実の十日町の名は、十日ごとに立った市（定期市）からと言われる（NG の知識。元のページでは未確認）。什陽の「十→什、日→陽」は字の置き換えで、由来の「市の日」とは別の筋 |

判定：**什陽は条件付き・否寄り**（C-04、日ノ中の判例）。

### 2.1 Gin に渡す材料（NG は候補を出さない。R-018）

- 字「什陽」を生かすなら、**読みを替える**のが一つの道。ただし「とお〜」で始まる読み（とおひ など）は、遠岡（とおおか）と重なりがもどるので避ける。
- 現実の名前の由来（十日ごとの市）を典拠にする道もある（G-07）。
- どちらにするか、別の字にするかは Gin。新しい候補は HNS-Rev か Gin が出し、NG が査読する。
