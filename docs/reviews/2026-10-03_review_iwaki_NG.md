## 1. 前提：旧国名の線引き（訂正）

- **訂正**：はじめ NG は「線引き案はまだ Gin の裁定前」と書いたが、誤りだった。`docs/proposals/2026-10-03_kyukokumei_check.md` §6 で、Gin が線引きに「1 okです」と答えている（旧国名は国・地方の呼び名と名前の部品に使い、今ある市町の名前と現役の路線名・駅名には当てない）。HNS-Rev-local の指摘で直した。
- 4案とも「磐」（旧国名「磐城」の一字）を部品として残すので、この線の上にある。
- 記録：Gin の言葉「旧国名が現在と被っている場所もあるはずなんです(磐城→いわき市)」のとおり、「磐城」をまるごと使うと、いわき市と同じ音になる。4案は「磐」の一字だけを使うので、まるごとの重なりは避けている。
- 磐越西線・東線の扱いは kyukokumei_check §9 のとおり。「磐柳」は住所検索で完全一致なし。
- そのあと（b14e180）、「浜」は Gin「はまなかあいづ ね」で、福島の三地域（浜・中・会津）の浜として解消した。磐浜は Gin の採否待ち。

## 2. I1 磐浜

| 検査 | NG の結果 |
|---|---|
| C-01・C-02 | 国土地理院の住所検索で「磐浜」「いわはま」とも完全一致なし。「岩浜」も完全一致なし |
| 典拠（G-07） | 浜通りで一番大きい町、小名浜港（一次チェックで確認済み）。現実の地域名「浜通り」とつながる |
| **C-08（浜の受け取られ方）** | 「浜」は、現実の**浜通り**（福島県の太平洋側）の名前そのものの字。浜通りは東日本大震災の津波と、福島第一・第二原発の事故の地域。名前に「浜」を置くことは、その土地の呼び名を正面から引き受けることになる。**侮る含意はなく、むしろ土地の実の名に沿う**。ただ、作品には廃炉と Gin の福島への思いがあるので、Gin が「浜」をどう受け取るかは本人に聞く（NG は否の理由にしない） |
| C-07 | 「磐」は「いわ」とも「ばん」（磐梯）とも読む。「いわはま」は磐城の読みに沿うので、福島の読者には読める。ルビは初出に付けるとよい |
| C-06 | 城→浜は格・規模の対ではない。合 |

## 3. I2 磐関

- **新しく見つけたこと**：国土地理院の住所検索で、「磐関」を含む地名として**常磐関船町**（いわき市、7204）が出る。I4「磐湯」が常磐湯本町の中に入るのと同じ形で、現実のいわき市の町名の中にそのまま入る。
- 「いわせき」は、岩瀬郡（いわせぐん、福島県）と近い音（一次チェックどおり）。住所検索では「字岩関」（3215）も出る。
- 典拠（勿来の関）は良いが、**否寄り**。

## 4. HNS-Rev-local の道具の訂正について

- 「そのまま含む」の数え方の不具合と、重原42件への訂正を確かめた。NG の照合は自前の住所検索（文字の比較は Node の文字列で、文字コードの崩れはない）で行っていたので、NG のこれまでの判定は影響を受けない。社帰原重の判定（字を逆にした重原は名前・音とも一致しないので記録だけ）も変わらない。
