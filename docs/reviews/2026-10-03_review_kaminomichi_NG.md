## 1. 上路・中路・下路（はじめの案）

| 名前 | 結果（国土地理院の住所検索、NG） |
|---|---|
| 上路 | 5件：**新潟県糸魚川市上路**（大字、15216）、上路川、栃木県（9206）の上路 |
| 中路 | 3件：栃木県・熊本県の中路、佐賀県の中路橋 |
| 下路 | 2件：岩手県の下路熊沢 |

- 前提は越路の裁定（越路は再査読で否寄り、2026-10-03_review_koshiji_NG.md）。
- C-04：**下路は音で「げろ」**、上路は「じょうろ」と読める。
- C-08：「〜のみち」が七道と同じ形で、層がまぎれる。
- **上越市＝上路市は否寄り**：同じ柳都県の糸魚川市に、大字上路（あげろ。謡曲「山姥」の舞台の里）。

## 2. 上ノ道・中ノ道・下ノ道（決めた書き方）

Gin の言葉（原文）：天気予報風の読み上げ「上の道の気温は21度…」、「競合無しを優先」。

| 検査 | NG の結果 |
|---|---|
| 解けたこと | 「げろ」と読めない。糸魚川の上路と字面が重ならない。越路の「路」に頼らない（越路の裁定と切り離せる）。日ノ本と同じ「ノ」で、本世界の書き方にそろう。§1 の問題はすべて解けた |
| C-01・C-02 | 国土地理院の住所検索で「上ノ道・中ノ道・下ノ道」「上の道・下の道」とも0件 |
| **C-03（記録）** | **奈良の上ツ道・中ツ道・下ツ道**（かみつみち…、古代の大和の三本の道。一次チェックどおり）と1モーラ違い。上・中・下の三つが組でそろう点まで同じ。しかも奈良は本世界の畿内（五国府）の中で、方面は遠い。字（ノ／ツ）も違う。記録。むしろ「古い道の名の並べ方」として由来にできる |
| **C-08（層、記録）** | 書くと「ノ」で七道の「〇〇道」と見分けられる。**ただし声では、七道の読み（神府道＝こうぶのみち、火守道＝ひもりのみち、権現道＝ごんげんのみち）と同じ「〜のみち」の形**。台詞では見分けにくい。天気予報の読み上げで自然だったのは、柳都県の中の話と前後で分かるから。つながりの地図に「柳都県の中の地方名（上ノ道…）は、七道（〇〇道）より一段下」と一行書く |
| C-04（記録） | 「上の道を通って」のように、ふつうの言い回し（上の方の道）と取れる場面がある。地名として出す初出では、「上ノ道の町」「上ノ道では」のように地名と分かる言い方にする。「かみのみち」＝神の道（神道の和語）の記録は前の版から引き継ぐ |
| C-07 | 「上ノ道＝かみのみち」は、字のとおり読める（熟字訓の問題は消えた）。ルビはなくてよい |

判定：**上ノ道・中ノ道・下ノ道は受け入れ可**（条件なし。記録3つ）。

## 3. 上越市の名前

- 地方名が上ノ道になっても、上越市の名前は別に決める（§1 のとおり、上路市は否寄り）。「上ノ道市」とするかは、上越市の候補のときに照合する。

- HNS-Rev-local：§2 の記録3つ（上ツ道、声での層、言い回し）を足す。
- HNS-Rev：正本に入れるとき、つながりの地図に層の一行。
