## 2. ヤンマー＝オーカー（決着の確認）

- Gin の案：「やまおか の おか からとって おーかー」（G5 の記録）。創業者・山岡孫吉の「おか」を取った形。C5 の前の査読は ギンマー を推していたが、オーカーに決まったので、この査読では ギンマー を取り下げる。
- **人の名の糸を外す**：山岡（人名）から取った名は替える（DIFF-035・DIFF-037）。オーカーは、人名の糸（山岡の「おか」）を残しているが、それは一字（おか）を取った形で、名字そのものではない。C5 は、Gin の判断を受け入れる。
- **長さ（DIFF-043）**：ヤンマー（4 拍）→オーカー（4 拍）。同拍。○
- **元と同じ音**：「やんまー」の「ま」「ー」が残るが、「やん」を「おー」に替えた。元の読みを丸ごと入れてはいない。○
- **語との重なり（M4 の試しの観点）**：オーカー（ochre、黄土色）は、よく使う語（色の名）と同じ。社名として、語が紛れる可能性がある。C5 はこれを気がかりとして記録する（Gin の判断）。
- **照合**：G5 の Web 検索では、同名の会社・商標は見つからなかった。J-PlatPat は未確認（【要照合】）。

## 3. クボタ＝ヒサボ（推し）

- **材料**：久保田権四郎（創業者）→ 株式会社クボタ。名は創業者の名字から（G5 の材料、有価証券報告書の沿革）。
- **人の名の糸**：人名（久保田）から取った名は替える（DIFF-035・DIFF-037）。○
- **長さ（DIFF-043）**：くぼた（3 拍）→ひさぼ（3 拍）。同拍。○
- **元と同じ音**：「ぼ」が残る（くぼ→ひさぼ の「ぼ」）。1 拍が同じ。元の読みを丸ごと入れてはいない。○（わずかな重なり）
- **久の読み替え**：久（ひさ）は、久保田の「く」の字の別の読み。「田」は落とす。DIFF-043 の 3 拍を保つ形。○
- **次点のボータ（ぼーた）**：元の「ぼた」が残る（「ぼ」「た」の 2 拍）。元と同じ音が多いので、C5 は次点のままでよいと見る。○
- **ヒサタ（否）**：株式会社ヒサタ（建設）が実在するので、外す。C5 も同じ。○
- **照合**：G5 の Web 検索では、同名の会社・商標は見つからなかった（近い名は ヒサノ・ヒサヤス）。【要照合】（J-PlatPat・法人番号）。

## 4. イセキ＝セキヰ（保留）

- **材料**：井関邦三郎（創業者）→ 株式会社井関製作所。今のブランドは「ヰセキ」（旧かなの ヰ）。名は創業者の名字からと読めるが、命名のわけを書いた資料は見つからなかった（G5）。
- **人の名の糸**：人名（井関）から取った名は替える（DIFF-035・DIFF-037）。替えること自体は○。
- **長さ**：いせき（3 拍）→せきい（3 拍）。同拍。○
- **元と同じ音（問題）**：元の読み「いせき」の 3 拍（い・せ・き）を、「せきい」（せ・き・い）に並べ替えた。**元の読みの音が、そのまま 3 拍とも残っている**。DIFF-043 は「元と同じ音はなるべく当てない」「元の読みを丸ごと入れない」。並べ替えはこの決まりに反する疑いが強い。G5 は「語順の入れ替え（手引き §3.2）」と書いたが、その型が「元の読みを丸ごと入れない」に当たるかを、C5 は確かめていない（【要照合】、手引きの §3.2 と DIFF-043 を並べて確かめてほしい）。
- **「ヰ」**：旧かなの ヰ を残す（ブランドの現実どおり）。画面で読めるかは、Gin の判断。○
- **次点はない**。セキヰを外すなら、元の読みと音を重ねない別の名字の糸（井→ほかの字など）を、G5 に出し直してもらう。
- **照合**：松山の「セキ株式会社」（印刷）が近い名として出た（G5）。同名ではないが、【要照合】。
