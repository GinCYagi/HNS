## 1. 浅途（あさと）＝沖縄の 安里 と同じ読み
- 字は違い、Gin の線（字が同じならダメ）には当たらない。DIFF-040 は「その土地の名をずらす」決まりで、ほかの土地の名と読みが重なることまでは言っていない（読み取り）。
- ただ、C5 の覚えでは、那覇の 安里 は沖縄戦の激戦地（安里五十二高地、シュガーローフ）の名として知られる【調べていない】。読みが同じ名を国の名に置くと、沖縄の読み手には戦地の名に聞こえうる。DIFF-040 が戦災に広がったのは「出来事を思わせない」ためなので、**避けられるなら避ける**のを推す（見立て）。
- 次の案（照らしていない）：淡→薄（うす）で 薄途（うすと）、道→途 はそのまま。拍 3 で同じ。

## 2. 筑前・筑後＝磐前・磐後：**瑞〇（束3）と同じ字の取り違えに見える**
- 現実の 筑前・筑後 の頭は 筑紫 の **一字目 筑**。築石 説では 筑≒築（きずく）・紫≒石 にあたる。
- 推しは 石→磐 を頭に置く。石 は 築石 の二字目（紫 にあたる側）で、現実の頭の字 筑 にあたる字ではない。束3 で 吉備 の 吉 を頭に置いて現実（備）とずれたのと逆向きの、同じ形の取り違え（見立て）。
- 直す道：筑（築＝きずく）の側を意味で替える（築→構・建 など、照らしていない）か、筑紫 の名を先に決めてその一字目を頭に置く（束3 で Gin が 具前 を選んだ形〈備→具〉にそろえるなら前者）。
- 磐前 と 伊達市 保原町磐前通：町域の名の一部が重なるだけ（DIFF-046 は 町域の名 を見るが、名まるごとではない）。こちらは記録で受けられる。

## 3. 土佐＝地輔・薩摩＝救磨（字の意味だけ）
- 由来が分からないときに字の意味で替えるのは DIFF-037 の道で、加賀＝益寿 と同じ。弱いが決まりの上では通る。
- 土佐 は記事に 遠狭・門狭 の説がある（G5 の書き）。説の一つから土地の姿で作る道もある（那須＝臼嶺・伊賀＝籠里 の形）。字の意味と土地の姿のどちらにするかは Gin に。

## 4. 臨 の重なり（日向＝陽臨・対馬＝臨馬）
- 国の名どうしで同じ字が二つ並ぶと、作中で取り違えやすい。どちらかを替えるのを推す。G5 の次の案 陽面（ようめん、日向）は、元の 向 の意味（日の出の方を直に向く）に合う（照らしていない）。

## 5. 壱岐＝壱枝 の 壱
- 足しの見立て：壱岐 は 魏志倭人伝 の 一大国・一支国 と G5 の書いたとおり、**壱 はもともと数の 一 の大字**として入った字。なので、作中の 壱 の元を 一 とする決まり（DIFF-026 の大字、一→壱）と、筋として合う。現実の 壱 の行き先（未決）を、この名では「一の大字として残す」と書けば足りる（見立て）。

## 6. ほか
- 好黍・良黍（同じ読みで字が違う）：現実の 阿波・安房 と同じ形で、よい作り。黍 は常用外一つ。
- 深樹＝三木市 と読みが同じ、細幅・湧井・裕前・裕後・沃後・広隈：受け入れ可。拍が同じもの 9 つ、±1 のもの 8 つ（G5 の数え）。
- 肥前 を後に回す、に賛成（DIFF-040、長崎）。
