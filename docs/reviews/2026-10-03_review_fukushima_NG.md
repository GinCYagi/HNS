## 2. B1 禄島

- 典拠：福禄寿（福・禄・寿の三つの徳。一次チェックで確認済み）。福の次の字を取る組み方は、福と禄が並ぶ言葉なので筋が通る。
- C-04（記録）：
  - 「禄」は俸禄（給金）、「禄を食む」の字。財・恵みの意で、悪くはない。
  - **「ろく」は「碌でもない（ろくでもない）」と同じ音**。字は違う（碌）が、「禄でもない」と書かれることもある。台詞で「ろくしま」と言うと、耳で連想する人はいる。害は小さい。
  - 数の「六（ろく）」とも同じ音。六島（§1）。
- C-07：「禄」は字面から「ろく」と読める。ルビは初出だけで足りる。
- 地域名：左禄（さろく）・正禄（しょうろく）・右禄（うろく）。人の名前には見えにくい。読みは決めておく。

## 3. B2 祥島

- 典拠：吉祥・瑞祥（めでたいしるし）。福→祥は近い意味。
- **条件（C-07）**：読みが「しょうじま」と「さちしま」の二つ。どちらかに決める（ルビで固定）。
- C-04（記録）：
  - **「正祥」は男性の名前（まさよし・まさあき など）としてよくある字**。中通り＝正祥が、人の名前に見えやすい（依頼の問いの答え）。左祥・右祥は見えにくい。
  - 「祥」は不祥事（ふしょうじ）の字でもある。音は違うので、記録だけ。
  - 「しょうじま」は小豆島（しょうどしま）と近い音。方面は遠い（香川）。記録。
- 祥は「さち」とも読み、幸せの意で、福島の「福」にいちばん近い。意味の上では B1 より近い。

## 4. 地域の呼び分け（新潟方式）について

- 浜通り＝左〇・中通り＝正〇・会津＝右〇（南を向いて左は東）。上・中・下（新潟の上越・中越・下越）にならう形で、Gin の案。
- 記録：会津は、すでに**相津**（裁定済み）。右〇（右禄・右祥）を会津の地域名に使うと、会津に「相津」と「右〇」の二つの名前ができる。相津＝土地の名・右〇＝県の中の地域の呼び分け、と役割を分けて記録しておくと迷わない。
- 浜通りは、いわきの磐浜の「浜」（Gin「はまなかあいづ ね」）とも重なる。左〇（浜通り）と磐浜の「浜」の関係も、同じく役割を分けて記録する。

## 6. 追加：禄嶋（ろくしま）の査読（Gin の選択、f84bb1e）

Gin の言葉（原文）：「嶋もあるね」「禄がまんたん、禄の嶋」

| 検査 | NG の結果 |
|---|---|
| C-01・C-02 | 国土地理院の住所検索で「禄嶋」0件。左禄・正禄・右禄も0件。「福嶋」は秋田県に4件（5203・5212）あるが、使わないので関係ない |
| C-03 六島 | §1 の六島16件のうち、岡山県笠岡市（33205）と長崎県（42383）の六島は、どちらも読みは「**むしま**」（NG の知識）。「ろくしま」と読む六島は、NG の知る範囲ではない。字も違う（六／禄）ので、記録だけ |
| 組み立て | 福→禄（福禄寿の隣の字。DIFF-016 の近い字）、島→嶋（同じ字の異体字）。**島→嶋は、十→什・三→参（数の大字）と同じく「字だけを替え、読みと意味は変えない」型**。DIFF-016 に「数の大字」と並べて「**同じ字の別の書き方（異体字・大字）**」とまとめて一行にすると、あとで迷わない |
| C-04 | §2 のとおり、「ろく」は「碌でもない」と同じ音（害は小さい）。Gin の「禄がまんたん」で、意味（恵み・財が満ちる）ははっきりしている |
| C-04 正禄 | 「正禄」は人の名前としてはまれ（正祥のような、よくある名前ではない）。人の名前には見えにくい。**記録を足す**：左禄・正禄・右禄の「〇禄」は、元禄・嘉禄のような**元号の形**にも見える。害はなく、むしろ古風な響き |
| C-07 | 「嶋」は「島」の異体字で、読める。読みは「ろくしま」と清音で決める（「ろくじま」と濁る余地があるので、ルビで固定） |

判定（案）：**禄嶋は受け入れ可**（条件：読み「ろくしま」をルビで固定）。地域名 左禄・正禄・右禄も受け入れ可。§4 の役割の書き分け（相津＝土地の名、右禄＝県の中の地域の呼び分け。浜通り＝左禄と磐浜の「浜」）は、そのまま引き継ぐ。
