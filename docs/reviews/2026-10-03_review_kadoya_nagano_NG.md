## 1. 門家・門家分水

Gin の言葉（原文）：「門家分水」「かどや」「字が違えば許容したい」「1 揃えたい」

| 検査 | NG の結果 |
|---|---|
| C-01・C-02 | 国土地理院の住所検索で「門家」の完全一致0件（total 2）、「かどや」は total 56 でも完全一致0件（かなの地名はない）。施設名（OpenPOI）は「門家」で50件出るが、どれも「専門家」の中の文字の並び（例：「…の専門家…」）で、「門家」という名の施設ではない |
| 組み立て | 関→門（関所＝門）、屋→家。DIFF-016（近い字）。りゅうと市の中（RUL-019、Gin の裁量）。地名・駅・分水路を門家にそろえる（Gin「1 揃えたい」）のは、関屋分水・関屋駅・関屋の地名が同じ名を持つ現実と同じ形（RUL-013） |
| C-03・C-04 | かどや製油（ごま油）、京都の角屋（揚屋）と同音。Gin「字が違えば許容したい」で許容。記録 |
| C-07（条件） | 「門家」は「もんか」「もんけ」とも読める。**初出にルビ** |
| 記録 | 字面の「門家」が「専門家」の後ろ2字と同じ。看板・字幕で単独に出れば問題はない |
| 駅名の案「堰戸」 | Gin「1 揃えたい」で下げる。棄却履歴ではなく「候補に下げた」記録（関戸と同音 19か所の条件もあった） |

判定：**受け入れ可**（条件：初出ルビ）。

## 2. 長野県

### N1 信州

- 一次チェックどおり否寄り。住所検索60件：長野市の大字「信州新町〇〇」が多数、ほかに信州峠（20304）・信州谷（19205）。越路と同じ「今ある地名」の型。
- 「信」を部品に使う道（信柳本線など）は、旧国名の線引きの「部品」に入るので、妥当。

### N2 科坂（しなさか）

| 検査 | NG の結果 |
|---|---|
| C-01・C-02 | 住所検索で「科坂」0件、「しなさか」完全一致0件。施設名（OpenPOI）は1件出るが「内科坂口医院」の中の文字の並びで、名前としての一致ではない |
| 典拠（G-07） | 信濃の名の由来の二説、科の木と、賀茂真淵の級坂（しなさか）を合わせる（一次チェックで Wikipedia「信濃国」本文を確認済み）。**記録（よい点）**：信濃は古くは「科野（しなの）」とも書いた（NG の知識）。「科＝しな」は信濃そのものの古い字で、典拠がさらに固い |
| C-07（条件） | 「科」はふつう「か」と読む。字面からは「かさか」と読まれる。**ルビ必須** |
| C-03 | 「しなさか」に近い実在地名は、NG の知る範囲ではない |
| **親（P-02）** | 長野県は東山道。東山道の HNS 名「権現道」は、まだ Gin の採否前。P-02 では、親が決まらないと「親待ち」で登録。柳都県が越路待ちだったのと同じ。記録 |
| DIFF-019 | 「元の名前を使わずに、どれだけ場所を想像できるか」：ルビで「しなさか」と読めば、信濃（しなの）の音が浮かぶ。合 |

判定：**条件付き**（ルビ必須、親待ち）。推奨に同意。

## 3. OpenPOI API の使い方について（手引きへの提案）

- 施設名の検索は**部分一致**で返る。「門家」で「専門家」、「科坂」で「内科坂口」が出たように、**長い語の中の文字の並びも数に入る**。件数だけを見ると、実在の衝突と取り違える。
- 照合では、返ってきた名前の中で、候補が**語として**使われているか（前後が別の語に続いていないか）を目で確かめる。REVIEW_GUIDE.md §5.1 に一行足すとよい。

## 4. 頼みごと

- HNS-Rev：門家・門家分水を正本に（初出ルビ、かどや製油・角屋の記録、堰戸は候補に下げた記録）。
- HNS-Rev-local：科坂に「科野」の記録と親待ちの一行。手引き §5.1 に部分一致の注意。
- Gin：科坂（しなさか）を長野県の名にするか。
