## 1. 五国府（ごこう）

### 1.1 根拠

- Gin「３、そうだ、ごこう、いこう」「でもきれいだと思うんだけど＋２なった原因ってなんだっけ」「後光、信仰の地だからと理由づけられなくもない」「ごこうにしましょう」。P-04 足りる。
- 畿内を五か国のままに戻すのは、現実の五畿（大和・山城・摂津・河内・和泉）と同じで、「五畿七道」の呼び方もそのまま使える（C-08 合）。近江・丹波を動かさないので、東山道・山陰道への影響もなくなる。七国府のときの「兄弟区分への影響」の記録（2e57027 の判定 §5.1）はいらなくなる。

### 1.2 C 系（NG の知識と正本の grep）

| 検査 | 結果 |
|---|---|
| C-03 五香 | 差分案どおり。五香駅（ごこう、千葉県松戸市、京成松戸線）と同音。方面が遠いので記録 |
| C-03 **御幸町通**（記録を足す） | 京都市の「御幸町通（ごこまちどおり）」。読みは「ごこ」で、五国府の「ごこう」と1モーラ違い。京都は本世界の畿内そのもの（山城）なので、方面が同じ。完全一致ではないので記録だけ |
| C-04 **御幸**（記録を足す） | 「御幸（ごこう）」は、上皇・法皇のお出かけを言う語（天皇は「行幸」）。畿内・都の名と重なるので、後光と並ぶ二つ目の掛詞として読める。害はない |
| C-04 五更（記録を足す） | 「五更（ごこう）」は、夜を五つに分けた時刻の呼び名（漢詩の言葉）。低頻度。記録だけ |
| C-04 後光 | Gin の掛詞（信仰の地）。差分案どおり |
| C-07 | 3モーラ。「国府」を「こう」と読むのは、国府津（こうづ）・国府台（こうのだい）と同じ読み方で、地名として自然。ただし字面から「ごこくふ」と読まれやすいので、**ルビ必須**は差分案どおり |
| C-08 兄弟 | 正本の七道の読み（こうぶのみち・ひもりのみち ほか）と重なる読みはない。「こうぶ（神府）」とは「こう」の2モーラだけが同じ。記録しなくてよい程度 |
| 短縮 | 「国府」単独の短縮禁止は五国府にも効く。差分案どおり。「五国（ごこく）」と略すと、別の読みになるので、略さないほうがよい（記録） |
| 標語 | 「そうだ、ごこう、いこう」も、現実の旅の標語のもじり。字幕・看板で元の文字の並びを写さない注意は、そのまま残る |
