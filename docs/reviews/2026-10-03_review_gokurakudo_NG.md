## 0. 結論

## 2. 組み立てと型

- 構想名「山陽道→極楽道」（2026-07-07）と、方位浄土案（西＝阿弥陀の極楽浄土＝山陽道、南＝観音の補陀落＝南海道）。G-07（典拠からの作り直し）。RUL-008 で Gin 裁定が必須。
- 二字＋道。DIFF-020（字数に縛らない）の範囲。
- 神府道（山陰道、条件付き採用）とセットで決める条件（pending）は、神府道が先に入っているので、極楽道を決めれば満たせる見込み。山陰（神の府）と山陽（極楽）で、神と仏が並ぶ。神仏習合の世界設定（pending の世界設定）と合う。
- **読み「きら」は当て字**（DIFF-018）。ルビ必須、わけを記録。一次チェックの読み（極＝きわみの「き」＋楽＝「ら」、綺羅、山の陽のきらめき）のどれか、Gin の言葉で確かめる。

## 3. C-05 第3層（死の連想）：Gin に必ず見てほしい所

- 凍結版の C-05 第3層は「死など。禁止ではないが、採用前に読み・意味・音声上の印象を確認」。
- 「極楽」は、極楽往生・「極楽へ行く」＝亡くなる、の意でも使う語。9/30 の査読で、補陀落道（補陀落渡海）にも同じ「死の連想」を記録している。極楽道が採られると、**七道のうち二つ（山陽・南海）が「死後の浄土」の名**になる。方位浄土案としてはきれいにそろうが、読者が「死の国の道」と受け取る余地がある。
- **山陽道は、現実の安芸（広島）を含む**。広島は原爆の地。そこを含む道の名が「極楽（死後の浄土）」になることを、Gin がどう受け取るか。慰霊の意を込めた名と読む人もいれば、軽く見ていると受け取る人もいるかもしれない。NG は否の理由にはしないが、作品が廃炉と福島への思いを抱えていること（ALM city_plan、Gin）と同じ重さの話なので、Gin 本人の判断を仰ぐ。
- 読みを「ごくらく」ではなく「きら」にするのは、この連想を和らげる効果がある（字は極楽、音はきら）。記録。

経緯：NG の条件②（死の連想・広島）を聞いた Gin「だとあれだね」「再考」。HNS-Rev が推した煌道に、Gin「煌道 査読」。候補を出したのは HNS-Rev。

| 検査 | NG の結果 |

| C-05 | 極楽道の死の連想は消えた。神府道（山陰、神）との対は「神の府」と「煌めく道」になり、神仏の対ではなくなるが、陰と陽（山陰・山陽）の光の対として読める |
| **C-04・C-05（音読みの記録、新しく見つけたこと）** | 字面から「こうどう」と読まれると、行動・講堂（一次チェックどおり）のほかに、**皇道（こうどう）**と同じ音。皇道は、戦前の陸軍の「皇道派」（二・二六事件）の語として知られる。音読みしたときだけの重なりで、ルビ「きら」を固定すれば出ない。記録。**よい連想**：黄道（こうどう、太陽の通り道）とも同じ音で、山陽（陽）と合う |
| C-07（条件） | 「煌」を「きら」と読ませるのは当て字寄り。**ルビ必須**。七道を並べる所でも付ける |
| C-08（記録、重さは小） | 煌＝きらめく光。山陽道は広島を含む。原爆の光を「ピカ」と呼んだ記憶と、「きらめき」の字が重なると受け取る人がいるかもしれない。NG は重い連想ではないと見る（「煌」は明るさ・晴れやかさの字）。Gin が極楽道で広島を気にかけたので、念のため書く |

判定（案）：**煌道は受け入れ可の見込み**（条件：ルビ「きら」固定、当て字のわけを記録、Gin 裁定）。極楽道より、死の連想の問題が解けている。
