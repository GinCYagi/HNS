### 7.2 紅県

経緯：紅花県は Gin「わるくないとおもうんだけど、禄島に比べると安直に感じるかも」で保留。Gin「山形 再度候補」に HNS-Rev の推し「紅県」。

- Wikipedia「紅色」本文：「**『くれない』の語源は『呉の藍』（くれのあい）、呉の国の染料のこと**で、5～6世紀頃に高句麗の僧から伝えられたとみられている」。
- → 一次チェックの「呉藍→くれない の縮みは HNS-Rev の知識で未確認」は、**確認済み**にできる。

| 検査 | NG の結果 |
|---|---|
| C-01・C-02 | 住所検索・OpenPOI で「紅県」0件。「くれない」は OpenPOI で「くれない」で始まる店15件（京都市・堺市・松山市・神戸市 ほか）。県名としての一致はない |
| **C-04（大事）** | 「紅（くれない）」は**色の名前の一般名詞**（紅色）。紅花県の「一般名詞をそのまま県名に」の問い（pending）と同じ型が残る。字が一字で、紅花より抽象的な分、「安直」さは薄れる。ただ、雁木市（一般名詞で否寄り）との並びは同じ問いになる |
| C-04（記録） | 「紅（くれない）」は、X JAPAN の代表曲の名としてとても有名。台詞で「くれない」と言うと、曲を思い出す人がいる。害はない |
| C-03（記録） | 語源の「呉（くれ）」は、広島県の呉市（くれし）と同じ字。紅県の字面には出ないので、記録だけ |

判定（案）：**紅県は条件付き**。条件：①一般名詞（色の名）をそのまま県名に使ってよいかを Gin に（紅花県と同じ問い）、②ルビ推奨。

## 8. 追加：山形県＝山姿県（やますがたけん）の査読

経緯：紅県のあと、Gin と HNS-Rev が「形と姿の違い」を話し、Gin「山姿いいね　雄々しい峰々が想像される(個人の感想です）から悪いイメージはないと思う」。形→姿、山はそのまま。

| 検査 | NG の結果 |
|---|---|
| C-01・C-02 | 国土地理院の住所検索・OpenPOI で「山姿」「やますがた」「山姿県」とも完全一致なし |
| C-04（一般名詞の問い） | 「山姿」は「山の姿」の意の言い回しで、辞書に立つほどの一般名詞ではない（低頻度）。**紅花・紅のような「一般名詞をそのまま県名に」の問いには当たらない**。記録 |
| 組み立て | 形→姿は近い意味の字（DIFF-016）。「山」はそのまま。一字だけ替える型は、遠岡（長→遠、岡はそのまま）・什旭町（十→什）と同じ。実名のまま（RUL-017）には当たらない |
| **C-03（記録・大事）** | 読み「やますがた」は、現実の「やまがた」に「す」が一つ入っただけ（5モーラと4モーラ）。耳ではほぼ「山形」に聞こえる。別の土地とぶつかるのではなく、**元の名前に近すぎる**という問い。DIFF-019（元の名前を使わずに、どれだけ場所を想像できるか）の物差しでは、「元の名前に頼って浮かぶ」側に寄る。遠岡（とおおか／ながおか）よりずっと近い。Gin が「現実と頭が同じ」を承知で採るかを、一言で |
| C-07 | 「山姿」は「さんし」とも読める。山紫（山紫水明）・蚕糸（さんし）と同音。ルビがあると安心（必須とまでは言わない） |
| よい点 | 「雄々しい峰々」（Gin）。山形は出羽三山・蔵王・月山・鳥海山の国で、山の姿という名は土地に合う |

判定（案）：**山姿県は条件付き**。条件：元の名前「やまがた」に音が近すぎる点を、Gin が承知すること（DIFF-019 との関係）。それ以外の衝突はない。

## 9. 追加：山形県＝嶺姿県（れいしけん）の査読

経緯：山姿県（やまがたに近すぎる）のあと、Gin の新しい案「嶺姿県　れいしけん」（山→嶺〈親の嶺路〉、形→姿、音読みで山形から離れる）。

| 検査 | NG の結果 |
|---|---|
| C-01・C-02 | 国土地理院の住所検索・OpenPOI で「嶺姿」完全一致なし。「れいし」は「くれいし」（徳島県、36383）の中の並びだけ |
| 組み立て | 山→嶺は、親の東山道＝嶺路の字を受ける。形→姿は近い意味（DIFF-016）。親の字を子に受ける形は、柳都県→りゅうと市、磐浜→磐柳線と同じ筋で、層がつながる。よい |
| C-03（解けた） | 「れいし」は「やまがた」と音がまったく離れた。山姿県の「元の名前に近すぎる」問いは解けた |
| C-04（記録） | 「れいし」は、霊芝（きのこ、健康食品）・茘枝（ライチ）・麗姿（うるわしい姿）・令旨と同じ音。どれも一つの語に強く引かれるほどの高頻度語ではない（什陽の「重要」とは違う）。麗姿は名前の意味（嶺のうるわしい姿）とも重なり、よい連想。記録 |
| C-03（記録） | 中国の温嶺市・公主嶺市は、一次チェックどおり記録だけ（方面が遠い） |
| C-08（記録） | 「嶺」の読みが、親の嶺路では「みね」、嶺姿県では「れい」と分かれる。磐浜（いわ）と磐柳線（ばん）、現実の磐城・磐越と同じ型で、問題ではない |
| C-07 | 字面からは「みねすがた」とも読める。**ルビ推奨**（初出） |
| DIFF-019 | 嶺＝山、姿＝形で、由来を一言添えれば山形が浮かぶ。山姿県より一段遠いが、元の名前に頼らない分、HNS の物差しに合う |

判定（案）：**嶺姿県は受け入れ可の見込み**（条件：初出ルビ推奨。記録：霊芝・茘枝・麗姿・令旨）。
