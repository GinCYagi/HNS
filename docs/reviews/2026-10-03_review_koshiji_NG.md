## 0. 結論

**条件付き・否寄り（Gin に回す）**。9/30 の「推奨」は、その後の二つの決まり（黒川城の却下、旧国名の線引き）に照らすと、そのままでは保てない。

- 越路は「北陸道（越の国）の実在の古い呼び名」で、G-01（古称）の型。G-01 の古称は、これまで柳都・伊夜日子・相津・陸奥で使ってきた。**型だけなら通る**。
- ただし越路は、ほかの古称と違って、**同じ柳都県の中で、いまも生きている地名**（長岡市の旧越路町の地域名）。この点で、柳都・伊夜日子より、却下された黒川城に近い。

## 1. 照合（国土地理院の住所検索、NG）

- 「越路」を含む地名・施設：全国 **52件**。うち**新潟県が11件**：越路原、越路中島、越路中沢（大字）、市立越路小学校・越路西小学校・越路中学校、越路橋、長岡警察署越路交番、長岡消防署越路出張所、北陸地方整備局 信濃川河川事務所 越路出張所 ほか。
- 旧越路町は 2006年に長岡市へ編入。いまも地域の名前として、学校・交番・橋・国の出張所に使われている（住所検索で確認）。
- ほかに北海道（10件）・千葉・神奈川・富山など。仙台の越路（こえじ）、鳥取の越路（こいじ）は 9/30 の記録どおり。
- 「こしじ」のかなは、特養「こしじの里」（新潟）など3件。

## 2. 見てほしい点への答え

### 2.1 RUL-017（実名のままは却下）と黒川城

- 黒川城（会津若松城の実在の古名）は、Gin「実在名を許容ではないです」で却下され、相津墨河城になった（10/2）。
- 越路も「北陸道の実在の別名」なので、**同じ物の実在の別名を名乗る**という点では黒川城と同じ型。
- 一方、柳都（新潟の雅称）・伊夜日子（弥彦の古称）・相津（古事記の表記）・陸奥も、同じく「実在の別名」を G-01 で採ってきた。これらとの違いは：

| 名前 | 実在の別名か | いまの地名・自治体名として生きているか |
|---|---|---|
| 柳都 | ○（雅称） | 自治体・町名にはない（柳都大橋・新潟柳都中学校など施設名に部分一致。記録済み） |
| 伊夜日子 | ○（古称） | 地名にはない |
| 相津 | ○（古事記の表記） | 地名にはない |
| 黒川城 | ○（古名） | 城の名として文献で通る。**却下（Gin）** |
| **越路** | ○（古称・別名） | **長岡市の地域名・町名（越路中沢・越路中島・越路原）として生きている。2006年まで町の名（越路町）** |

- NG の読み：Gin の線は「今ある名前をそのまま使わない」にある（黒川城、旧国名の線引き「今ある市町の名前にはそのまま当てない」）。越路は、**今ある地名としての重み**が、柳都・伊夜日子よりはっきり大きい。黒川城の側に入る見込み。

### 2.2 旧国名の線引きと DIFF-019

- 越路は旧国名ではなく、道の古い呼び名。ただ、線引きの趣旨「今ある市町の名前にはそのまま当てない」は、越路にもかかる。旧越路町の地域名（越路〇〇）がいまも使われているので、北陸道の名前としてそのまま当てると、この趣旨とぶつかる。
- DIFF-019「元の名前を使わずに、どれだけその場所を想像できるか」には、越路はよく合う（北陸がすぐ浮かぶ）。ただ、それは実在の呼び名だから浮かぶので、黒川城と同じ理由で浮かぶとも言える。

### 2.3 越路中沢・越路中島の重さ（今）

- 9/30 は「記録」だった。いまは、§1 のとおり、同じ柳都県（新潟県）の中で、学校・交番・橋・国の出張所の名として11件。北陸道の名前が、県の中のひとつの地域の名と同じになる。**否寄りの重さ**と見る。
- 列車愛称「越路」は、9/30 どおり未確認（記録）。越路吹雪も記録どおり。

## 3. 上路・中路・下路への響き

- 越路が作り直しになると、「路」の由来が動く。ただ、「路」の字そのものは、北陸道の新しい名前に「路」が残れば、上路・中路・下路は生かせる。北陸道の作り直しのときに、「路」を残す組み方を候補の一つにすると、県の中の地方名を守れる。
- 上越市＝上路市は、前の査読（2026-10-03_review_kaminomichi_NG.md §3）のとおり、糸魚川市の大字上路と字面が同じで否寄り（越路の扱いと別に）。

## 4. 頼みごと

- Gin：越路を、黒川城と同じく「今ある地名なのでそのまま使わない」側に置くか、柳都・伊夜日子と同じ「古称なので使う」側に置くか。
- HNS-Rev-local：作り直しになる場合は、北陸道の新しい名前に「路」を残す組み方を、候補の一つに。
