## 2. 近畿＝近府

| 検査 | NG の結果 |
|---|---|
| DIFF-016 | 畿→府（五国府の府）。畿内＝五国府とつながる。よい |
| C-03（条件） | 「きんぷ」は**金峯（きんぷ）**と同じ音。金峯山寺（奈良・吉野、紀伊山地の霊場）は近畿の中の著名な寺。字は違い、「金峯山（きんぷせん）」の頭だけが同じ音なので、否の線（著名地名と同音）とまでは言えないが、**近似**として条件付き |
| C-04 | 高頻度語との同音はない |
| 記録 | 「府」は現実の大阪府・京都府の府でもある。本世界の府の扱い（大阪府・京都府の名）を決めるときに、近府とまぎれないか一緒に見る |

判定（案）：**条件付き**。条件：①金峯との近い音の記録、②大阪府・京都府の名と一緒に見る。

## 3. 中国＝影外

| 検査 | NG の結果 |
|---|---|
| C-05・C-06（否寄り） | 「そと」は背面（そとも）から取った音。背面道は、NG が「裏日本を思わせる」として否寄りにし、Gin が神在道を選んだ（review_dictionary の棄却履歴）。**同じ根を地方名に戻すことになる**。字の「外」は、山陰を「外」に置く読み方をいっそう強める |
| 本世界との食い違い | 山陽道は本世界では**光面道**（字は「光」）。影外の「影」は、本世界で替えた字ではなく、現実の古い書き方「影面」の字。本世界の人からは、由来がたどりにくい |
| 字面 | 「影の外」と読める（一次チェックどおり） |

判定（案）：**否寄り**。

材料（E5 へ）：二つの道を合わせる型を残すなら、本世界の名（光面道・神在道）から取るのが筋。たとえば「光」と「神在」の字を使う形。どれも照合はまだ。

## 4. 中部＝央嶺

| 検査 | NG の結果 |
|---|---|
| C-03・C-04（条件） | 「おうれい」は「**お礼（おれい）**」と、のばす音一つの違い。お礼はとても多く使われる語。台詞で聞き分けられるか、読み上げで確かめる |
| DIFF-019（記録） | 中部は北陸（雪路）・中央高地（嶺路）・東海（松並道）の三つ。「嶺」は真ん中の山国だけを表すので、北陸・東海の人には自分の地方の名に聞こえにくい。現実の「中部」も同じ弱さがあるので否ではない |
| RUL-016（記録） | 嶺は嶺路・嶺姿県に続いて三つ目（一次チェックどおり） |
| 下位区分で呼ぶ案 | 筋が通る。現実でも「中部」はまとまりが弱い。Gin の判断 |

判定（案）：**条件付き**。条件：読み上げで「お礼」と聞き分けられるか確かめる。

## 5. 関東＝柵東

| 検査 | NG の結果 |
|---|---|
| DIFF-016（記録） | 関→柵。どちらも守りの字だが、柵は古代の北の城柵（多賀城・秋田城など）の字で、関所の東を表す関東とは意味がずれる（一次チェックどおり） |
| C-05（記録） | 城柵は、朝廷が北へ領地を広げたときの拠点の字。東北の束（杜砦県・碧林県）と並べると、関東に北の拠点の字を当てるのは、少しちぐはぐ |
| C-04（記録） | 「さくとう」は作刀・作陶と同じ音（低頻度語） |
| 外した案 | 関左（監査）・関陽（慣用ほか）・嶺東（冷凍）・坂左・松嶺の判定に同意 |

判定（案）：**条件付き**（弱い）。関東は Gin の着想を待つのがよい（一次チェックどおり）。

## 6. 頼みごと

- HNS-E5：影外に替わる中国の案（§3 の材料）。関東の案。
- Gin：近府・央嶺（または下位区分で呼ぶ）・柵東にするか。中国は影外をやめるか。
