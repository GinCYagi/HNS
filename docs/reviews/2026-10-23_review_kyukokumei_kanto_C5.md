1. **DIFF-044 と 磐渡 の食い違い（いちばん大事）**：正本の DIFF-044 は「元の名と字・音が重なる字は避け、その日ノ本名のもう一方の字を取る」。磐越 の 磐 は元の名 磐越 と同じ字なので、決まりの文のとおりなら 磐 は取れず、**汀渡（ていど）** になる。G5 の指摘は正しい。
   - 汀渡：町域の字 0、読み テイド の町域 0（C5 も確かめた）。同じ音 程度（ふつうの言葉。悪い意味はない）。
   - **磐渡 は今まさに登録中**なので、登録の前に Gin に一言要る：(a) DIFF-044 のとおり 汀渡 にする、(b) 磐渡 を DIFF-044 の外れとして記録する。
   - 同じ目で見ると、叢渡線（上越線＝上野＋越後）は 上叢 の 上 が元の 上越 と重なるので 叢 を取っていて、**DIFF-044 に合う**。科渡本線（信越）も 科・渡 とも元の 信越 と重ならず、合う。
2. **下野＝下叢（しもくさ）**：町域の字・読み 0。上叢 と同じく DIFF-050（野→原 の一対一）の外れで、野→原 なら 下原（町域 32 か所）で外れる。**上叢 と同じ理由を単語の表に足す**こと。受け入れ可。
3. **武蔵＝勇倉（いさくら）**：町域の字・読み 0。武→勇・蔵→倉 は意味の近い字（DIFF-016）。むさし（3拍）→いさくら（4拍）で ±1 の内。由来に定説がないので字替え、の筋は通る。受け入れ可。
4. **相模＝冷洋（れいよう）**：町域の字・読み 0。海→洋 は正本の DIFF-028 の例（「海→洋」）にあり、合う。寒→冷 は意味の近い字。さがみ（3拍）→れいよう（4拍）で ±1 の内。寒海 説は ja.wikipedia「相模国」によると G5 は書いており、C5 は記事を開いていない【要照合】。受け入れ可。
5. **常磐線＝永汀線**：町域 0。地名の 常磐＝永汀（DIFF-044）と同じ名で、筋どおり。受け入れ可。
6. **上総・下総・安房 の保留**：安房 は親（阿波）が先（P-02 の 親が先）、総 は字が決めきれない、のどちらも筋が通る。両叢線 が 両総（りょうそう）と同じ音になる点も、総 を決めるときに一緒に見る、でよい。
- まとめ：下叢・勇倉・冷洋・永汀線 は受け入れ可。**磐渡 は DIFF-044 の文と合わないので、登録の前に Gin に（汀渡 か、外れとして記録か）**。
