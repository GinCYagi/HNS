## 1. 山城＝峰背（改めより前の名に戻す形）
- 前例を確かめた：正本の real「潮来市」＝**板久市**（光圀の改めの前の名 板久 に戻した形）が採用されている。山城（794 の改め）→ 山背 に戻す形は、この前例と同じ。受け入れ可。
- DIFF-021（古称は、今の地名・施設・解説・観光で通っていなければ許す）について：峰背 は 山背 の 山 を替えているので、古称そのものではない。気がかりは小さい（見立て）。ただ 山背 は「山背古道」（京都の観光の道の名、と C5 は覚えている【調べていない】）や、東北の冷たい風 やませ（山背）など、今も通る言葉。峰背 にすれば重ならない。
- 山→峰：山背 の 山 は 奈良山 を指すが、名は 山 そのものの名ではない（地域の名）。DIFF-028 の「山体を地理的に呼ぶ名」ではないので 峰 に替える筋、新潟の〇〇山＝〇〇峰 と同じ。受け入れ可。
- 拍：やましろ 4 → みねせ 3、0/4。

## 2. 伊賀＝籠里（意義変換）
- 由来が見つからないので土地の姿（山に囲まれた盆地）から、は 那須＝臼嶺 の前例どおり。受け入れ可。
- 読み こもり は 小森（町域 11）と読みだけ同じ・子守 と同じ音：どちらも悪い意味ではなく、Gin の線（字が同じならダメ）に当たらない。記録で受けられる。
- 足しの見立て：伊賀 は 忍び の里として知られ、籠もる（隠れる）の意味は作中で話を作りやすい（見立て、由来の出典ではない）。

## 3. 音の重なり
- **領湊（りょうそう）＝両総**：両総 は 上総・下総 をまとめた現実の呼び名で、今も 両総用水 などで使われる（C5 の覚え【調べていない】）。作中では 上総・下総＝上束・下束 なので、作中の 両総 にあたる言葉は 両束。現実の言葉と読みだけ同じ、で字は違う。受けられるが、**作中で 摂津 と 両束 の地域が並んで出る場面がなければ** 困りは小さい。記録に。
- **嘉湧（わき）＝脇・腋**：腋（わきの下）は少しおかしみのある聞こえ。地名の形（嘉湧国）なら紛れは小さい。読まない佳字 嘉 を頭に置く作りまで元と同じ（和泉 の 和）、の筋は通るが、**嘉 を読まないことは見ただけでは分からない**ので、ルビ必須を行に書く。

## 4. ほかに気づいたこと
- **伊豆＝湯湧 と 石川＝湧湯**：正本に real「石川」「石川町」「石川郡」＝**湧湯・湧湯町・湧湯郡** がある（確かめた）。湯湧 は 湧湯 の字を逆に並べた形で、字面がとても近い。lookup の字の当たりは 0 だが、読み手が取り違えやすい（見立て）。表の読みの欄も「いでゆ・3」のままで、湯湧 の読みが書かれていない。**湯湧 の読みを書き、湧湯 との近さを気がかりに足す**のを推す。別の形が要るなら 湯涌（ゆわく）など（照らしていない）。
- 河内＝淵内：DIFF-045 で 郡山の 河内＝淵内 にそろえる、は筋が通る。
- 遠江＝遥湖：湖 を うみ と読むのはルビ必須。近江 と対で決める、に賛成。
- 上束・下束：下束 の 元と同じ拍 2/4 は しも（DIFF-026 の 下）を数えなければ 0/2 という G5 の見方に賛成。
- DIFF-040（戦災の土地、安芸・肥前）はこの束にはない。
