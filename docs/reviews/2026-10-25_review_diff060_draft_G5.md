## 1. ③「広く分かれてしまう」の線
- 「ほかの多くの名とつながる」を **数や広さ** で引くと、どこまでも広がる（M4 の気がかりのとおり）。つながる先の **種類** で引くのを推す。
- 案：**③ に当たるのは、つながる先に「時代・元号・歴史の出来事」の名があるときだけ**。これらは RUL-024（元号と歴史の出来事は現実にそろえる、時の流れを感じられるように）と DIFF-052（理と歴史の流れ）で、もう現実にそろえると決まっている。そこに名が入っているので、名だけ替えると、そろえた側と字が分かれる。
- **物産・会社・施設・駅 の名は ③ に入れない**。これらは親の地名に合わせて一緒に替わる（DIFF-032 の親子）ので、つながっていても歪みにならない。
- 例に当てると：
  | 名 | つながる先 | ③ か |
  |---|---|---|
  | 平安京 の 平安 | 平安時代（時代の名） | **当たる** |
  | 東山区 の 東山 | 東山文化・東山殿（文化・時代の名） | **当たる**（ほかに ① 山体の名でも残る） |
  | 室町 | 室町時代・室町幕府（時代の名） | **当たる** |
  | 元号の名（昭和村 ほか） | 元号そのもの | **当たる**（DIFF-047 のとおり） |
  | 八丈町 の 八丈 | 黄八丈・八丈絹（物産・織物の名） | **当たらない**：物産は親の地名に合わせて替わる。ただ 八丈絹 は「長さ八丈の絹」の意味もある言葉なので、イ の説（絹から島名）を取るなら ②（一つの言葉）の側で見る |
  | 平安町（もしあれば） | 平安時代 とのつながりではなく、ただの地名 | 当たらない（名ごとに） |

## 2. DIFF-026・DIFF-028・単語の表 と重ならない書き方か
- **① が DIFF-028 とぶつかる**：DIFF-028 は「同じ意味に替える言葉が見つからないときは、読みを残して字だけ替える（朝日→朝暉）」。なので「同じ意味の字がない」だけでは ① にならない（字だけ替える道が残る）。**① は「字だけ替える道も取れない」ときに限る** と書くのを推す。取れないのは、替えると当て字になるとき（Gin「同音異義語はNG」「山→耶麻 ✗」2026-10-07）か、字を替えると意味が別のものになるとき（京→都 の書き分け）。
- **DIFF-026（替えない字）は別の層**：方角・位置・数・町・極・暦の名・左右 は、もう DIFF-026 で残る。DIFF-060 は「DIFF-026 に入らない名」のための決まり、と頭に一行。重ねて ① と書かない（京都市の区の 東・西・上・中・下 は DIFF-026、京 だけが ①）。
- **② は単語の表の理由そのもの**：単語の表に入る行は、② を理由に持つ、と書く（決まりが二つあるように見せない）。単語の表には 日の出→陽の出・夕日→夕暉 のように **替える行** も入っているので、「単語の表の言葉はすべて ② で残る」とは書かない。残す行（高原→高原 のような同じ字の行）だけが ②。
- 川の名の終わりの 川（7afc576、Gin「〇〇口や〇〇高原と同じ、川の名称を表す字なので変えられない」）は ② に入る。M4 の §3 の ② に足すのを推す。

## 3. 今までの名で、当たらないもの・当たりすぎるもの
- **足すもの**：川の名の終わりの 川（伍百川・閼伽川・長巡川 ほか、②）。黒潮町（② の 黒潮 を名に持つ地名、§8 の確かめ）。
- **外すもの（DIFF-026 の側）**：南極・北極・赤道（せきどう）・子午線・甲子園の 甲子（干支の年）・九十九里町（数＋単位）・東区 ほか 58 区。これらは DIFF-026 で残るので、DIFF-060 の例には入れない。
- **見直すもの**：§3 の ③ の「東昭和」は、元号（昭和）＋方角で、DIFF-026（暦の名・方角）で残る。③ でもよいが、DIFF-026 で足りる。「室町」は元号ではなく時代の名なので、③ の説明を「元号・時代の名」にする。
- **当たりすぎの恐れ**：② の 北斗・金山 は一つの言葉だが、北斗 は星の名（25f0d69 で単語の表）、金山 は鉱山のふつうの言葉。どちらも「字を替えると言葉でなくなる」で ② に入る。当たりすぎではない、と G5 は見る。

## 4. 書き方の足し
- 残した名の行に、理由の欄を一つ決める（例 `keep: "DIFF-060①"`）。そうすれば lookup と rule-check で数えられる（rule-check の例外の数にも入れられる）。今の「verdict: 採用(そのまま)」の行と同じ形で足せる。
- 「名ごとに Gin の答えをもらう」は、決まりだけで機械的に残さない、という点でよい。rule-check に「DIFF-060 の理由が書いてない そのまま の行」を数える項目を足せる（G5 が作れる）。

## 5. 見立て
- 下書きの三つの柱は筋が通る。直すなら、① を DIFF-028 の「字だけ替える」と分けること、③ を「時代・元号・歴史の出来事」とのつながりに限ること、頭に「DIFF-026 に入らない名のための決まり」と書くこと。
