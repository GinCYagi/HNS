## 1. 北陸道

### K1 雪路

| 検査 | NG の結果 |
|---|---|
| C-01・C-02 | 国土地理院の住所検索で「雪路」「ゆきじ」とも0件 |
| 組み立て | 越路の「〇路（〜じ）」の形を残して「越→雪」。典拠は雪国の雁木（G-07）。越路が今ある地名で否寄りになった理由（長岡市の越路〇〇）は、雪路にはない |
| C-04（記録） | 「雪路」は「雪の道」の意の語（ふつうは雪道）。文の中では一般の語と取れる場面がある。女性の名前（ゆきじ）にも使われる字。どちらも害はない |
| C-08 | 七道の名は「〇〇道（〜のみち）」が多いが、越路と同じく「〜じ」で終わる形は、上ノ道（かみのみち）と声でもまぎれない。上ノ道・中ノ道・下ノ道の親として、層がはっきりする（よい点） |
| C-08（記録） | 雪は北陸だけでなく、陸奥（東北）・北加伊（北海道）にも強い。北陸道だけの名として足りるかは、典拠（雁木）で支える |
| C-07 | 字のとおり読める |

## 2. 上越市

### J1 上ノ道市

- 住所検索で「上ノ道」0件。
- 地方名（上ノ道）と市名（上ノ道市）が同じ字になるのは、現実の「上越地方」と「上越市」と同じ形。実態に即す（RUL-013）。合。
- 記録：台詞では「上ノ道」が地方か市かが前後で決まる。現実の上越も同じなので、問題ではない。

### J2 雁木市

| 検査 | NG の結果 |
|---|---|
| 典拠 | 高田の雁木の「共助の考え方」（上越市公文書センター本文、一次チェックで確認済み）。「手を、繋ぎましょう」と重なる、とてもよい典拠 |
| C-02 | 住所検索で「雁木」を含む地名2件（字雁木田〈7521〉、畑屋敷雁木丁〈30201〉）。記録：日本酒の銘柄「雁木」（山口県）があり、将棋の「雁木囲い」もある（NG の知識） |
| **C-04（否寄り）** | **一般名詞「雁木」と完全に同じ**。凍結版と今日までの前例：日ノ中（火の中）、遍路道、什陽（重要）は、一般語との完全同音で否・否寄り。雁木は字まで同じ（同音より強い）。「市」を付けても、名前の芯が一般名詞のままなので、前例と同じ側に入る。りゅうと市の例（雅称にひらがな）とは違い、雁木は今も使う一般の語 |

- 典拠のよさ（共助）は、市の名前ではなく、由来メモや、街並み・地名の小さい単位（通りの名など）で生かす道がある。

## 3. 頼みごと

- HNS-Rev-local：J2 を否寄りに。雁木の「共助」は、上ノ道市の由来メモか、高田にあたる地区の名前で生かす案に。
- Gin：北陸道を雪路にするか。上越市を上ノ道市にするか。

## 4. 追加：上越市＝軒結市（のきゆいし）の査読（0b7bd58）

経緯：Gin「推奨で行きましょう」で雪路・上ノ道市・上ノ道に決まったあと、Gin「かみのみち市／かみのやまから連想」で上越市だけ考え直し。Gin「軒いいですね」。

| 検査 | NG の結果 |
|---|---|
| 上ノ道市と上山市 | 上山市（かみのやまし、山形県。隣の県、城下町。かみのやま温泉駅）と「かみの〜し」の形が同じで、6モーラ中2モーラ違い。**C-03 の条件付き程度**で、否とまでは言わない。ただ Gin 自身が連想したので、読者も連想しうる。考え直す判断は妥当 |
| C-01・C-02 | 国土地理院の住所検索で「軒結」「のきゆい」とも0件 |
| 典拠（G-07） | 雁木の軒（共助、上越市公文書センター）と結（家々の労働の交換、コトバンク）。雁木市の否寄りの理由（一般名詞と完全一致）を避けつつ、共助の典拠を市の名前に生かせた。よい |
| C-04 | 「軒結」という語はない。「結（ゆい）」は一般名詞だが、二字を組んだ新しい語なので、雁木のような完全一致ではない |
| C-07 | 「軒＝のき」は素直。「結＝ゆい」は、結い・結の制度を知る人には読めるが、多くは「むすび」「けつ」と読む。**初出にルビ**（必須とまでは言わない） |
| **C-08（新しく見つけたこと、よい連想）** | ALM の SETTINGS に、バンド「**The YUI（結）**」がある（エンディングは The YUI のライブ）。軒結市の「結」と、作品のバンドの名が重なる。手をつなぐ・結ぶの筋で、よい重なり。ただ、同じ字が街の名とバンドの名に出るので、台本で「結」が出たとき、どちらかが前後で分かるようにする。M4 に知らせる |
| 層 | 地方名「上ノ道」と市名「軒結市」が別になる。現実の中越地方と長岡市のように、地方名と中心の市の名が違うのはふつう。つながりの地図に「上ノ道の中心の市は軒結市」と一行 |

判定（案）：**軒結市は受け入れ可**（条件：初出にルビ）。
