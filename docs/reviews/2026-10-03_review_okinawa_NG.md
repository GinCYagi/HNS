## 1. 事実の確認（元のページ）

- Wikipedia「沖縄島」本文（歴史）：「753年 - 鑑真が『阿児奈波』（あこなは、現在の沖縄本島とされる）に到着」。
- Wikipedia「沖縄県」本文（名称）：「淡海三船が著した779年成立の鑑真の伝記『唐大和上東征伝』では、天平勝宝5年（753年）11月21日に遣唐使一行が**阿児奈波嶋（あこなはしま／あこなわじま）**に到着したと記述されており、この島は沖縄本島のことを指していたという」。
- 同じく「沖縄県」の注：「なお『漂着』とする説が見られるが、文献、研究書で漂着と解しているものは見られず、**原文も単に『同到阿児奈波』としているだけである**」。
- 同じく「沖縄県」本文：「後に中国側により『流求』と呼ばれる、これは中華思想に基づく『溺れ助けを求む』と言う意味の蔑称であり、現在の『琉球』に落ち着いたのは明の時代以降である」。
- → **一次チェック §事実 の「鑑真らが島の人に『ここは何処か』と問い、そう答えたのが文献の初め」は、確かめた範囲の本文には書かれていない**。原文は「同到阿児奈波（ともに阿児奈波に到る）」とだけあり、誰が名を告げたかは書かれていない。**未確認**として扱う。
- 読みも「あこなは」と「あこなわ」の二つが記事にある。

## 2. 阿児奈波

| 検査 | NG の結果 |
|---|---|
| C-01・C-02 | 住所検索・OpenPOI で「阿児奈波」「あこなは」とも0件 |
| C-02（記録） | 字の頭「阿児」は、三重県志摩市**阿児町**（あごちょう、24215）。阿児の松原海水浴場・阿児アリーナなど施設11件。字の並び（阿児奈波）は一致しない。記録 |
| DIFF-021 | 今は地名として使われていない古い名。線の上 |
| **C-05（大事）** | HNS-Rev の前提「外から付けた名ではなく、土地の人の自称に寄せる」は、とても大事でよい。ただ、阿児奈波を「島の人が名乗った名」とする根拠は、§1 のとおり確かめられていない。記録として確かなのは「**文献に残る、この島のいちばん古い名（日本の文献）**」まで。由来メモは、確かめた事実だけで書く（PRE-007 の着想と断定の区別）。そのうえで、「おきなわ（うちなー）」の古い形を写した字だという見方があるなら、元のページで確かめて足す |
| C-03（記録） | 阿児奈波は、現実の「おきなわ」という名の、いちばん古い書き方とされる。読み「あこなは」は「おきなわ」と音が離れているが、字の歴史では同じ名の祖先。RUL-017（実名のまま）には当たらないが、「現実の名の古い書き方そのもの」である点は、光面道（山陽道の古い名）と同じ型。DIFF-021 で通る |
| C-07 | 4字・難読。**ルビ必須**。読みを「あこなは」に決める |

判定（案）：**条件付き**。条件：①由来から「島の人が答えた」を外し、確かめた事実（『唐大和上東征伝』に「阿児奈波嶋」、原文は「同到阿児奈波」）だけで書く、②読みを一つに決め、ルビ必須、③阿児町（志摩市）の記録。

## 3. 名付けの重さについて（Gin へ）

- 沖縄は、琉球王国、薩摩の侵攻、琉球処分、沖縄戦、戦後の統治と、外から名前や暮らしを決められてきた土地（一次チェックの前提どおり）。HNS が本土の側から沖縄の名を決めることにも、同じ重さがある。
- NG の提案：由来は控えめに、確かめた事実だけで書く。「本世界では、文献に残るいちばん古い呼び名が残った」という筋は、伊夜日子・相津・光面道と同じで、作品の世界観に合う。

## 5. 訂正（NG の見落とし）

- §1 で NG は「『島の人が答えた』は確かめた範囲の本文に書かれていない」と書いたが、**一次チェックの出典に挙がっていた Wikipedia「琉球王国」を、NG は見ていなかった**。
- Wikipedia「琉球王国」本文（「沖縄」の節）：「沖縄本島の人々は古くから自国を『うちなー』に近い音で呼称していたとされる。779年（宝亀10年）の淡海三船による鑑真の伝記『唐大和上東征伝』の中で、**鑑真らが島民にここは何処かとの問いに『阿児奈波（あこなは）』と答えたのが文献初出**であり、少なくとも鑑真らが到着した753年（天平勝宝5年）には住民らが自国を『うちなー』のように呼んでいたことが分かる」。
- 同じ節に、江戸時代の近藤守重『阿媽港紀略稿』は「阿鬼奈波」と書き、吉田東伍『大日本地名辞書続編』も阿鬼奈波の誤写とする、との記述。また石井望の、「阿」を「お」と読む説の紹介もある（読みの一本化〈あこなは／あこなわ／おこなは〉の材料）。
- つまり、Wikipedia の記事どうしで書き方が食い違っている（「沖縄県」の注は「原文は『同到阿児奈波』だけ」、「琉球王国」は「島民が答えた」）。HNS-Rev の扱い（確かな所＝日本の文献に残るいちばん古い名、753年、で書き、「答えた」は一つの記事の見方として記録にとどめる）が正しい。NG の §2 の条件①は、この扱いで満たされる。
- **NG は、一次チェックが挙げた出典をすべて開いてから「確かめられない」と書くべきだった**。手引き（REVIEW_GUIDE）にも、この一行を足すとよい。
