## 6. 追加：科柳本線の読み「しなぎほんせん」の照らし直し

経緯：国の層は歴史の呼び名のまま（Gin「そうだね」「元にしてる地図地形が同じなんだからそのくらいはリンクしてもバチはあたらんか」、09952d7）。柳越線の「越」も使える。科柳本線に Gin の読みの案「しなぎ」（しな＋やなぎを「な」でつなぐ縮め読み、DIFF-018）。

| 検査 | NG の結果 |
|---|---|
| C-04 | 「かりゅう（花柳）」と読まれる心配は、読みを「しなぎ」に決めれば消える |
| C-01・C-02 | 住所検索で「しなぎ」完全一致なし |
| **C-03（新しく見つけたこと）** | 「**品木**」の地名6件：品木（群馬県、10421）・品木ダム（しなき）、品木島（42209）、**品木沢（新潟県＝柳都県の中、15225）**。品木ダムは「しなき」で清濁違い。品木沢の読みは NG では未確認。柳都県の中に同じ音の頭を持つ地名がある。記録・条件付き |
| C-07（条件） | 「柳」を「ぎ」と読むのは、やなぎの最後の一音だけを取る縮め読み。字面からはまったく推せない。**ルビ必須**。わけ（しな＋やなぎを「な」でつなぐ）を記録 |
| **C-08（記録、新しく見つけたこと）** | 正本の路線名で「柳」は、東柳新幹線（とうりゅう）・磐柳西線・東線（ばんりゅう）と、どれも「りゅう」と読む。科柳本線だけ「ぎ」になると、同じ字の読みが路線名の中で分かれる。RUL-015（柳都は路線名では「柳」）の読みは決まっていないので違反ではないが、読者には「科柳＝かりゅう／しなりゅう」と読まれやすい。ルビで補う |
| よい連想 | 「しなぎ」は「しなの（信濃）」と音が近く、長野へ向かう線だと分かる |

判定（案）：**科柳本線（しなぎほんせん）は条件付き**（ルビ必須、わけの記録、品木沢・品木ダムの記録）。柳越線は §3 のまま受け入れ可の見込み。

## 7. 追加：越後線＝やますそ線の受け入れ判定

経緯：Gin「(ほくほく線)ルートは？」「地名由来ではなく全く新しい語呂の良い言葉にしてしまうルートです」「やますそでいきましょう」。越後線は伊夜日子山（弥彦山脈）の東の麓を走る（Wikipedia「越後線」）。柳越線・標柳線は候補に下げ、坂柳本線は Gin「丸かぶりはNGだね」で不採用。

| 検査 | NG の結果 |
|---|---|
| C-01 | 現役の路線名・列車名に「やますそ」は、NG の知る範囲ではない |
| C-02 | 住所検索で「やますそ」「山すそ」完全一致なし。「山裾」の地名は1件（鹿児島県、46221）。OpenPOI で「山裾」「やますそ」で始まる施設なし |
| C-04（記録） | 「山すそ（山裾）」は一般名詞。ただし高頻度の語ではない（凍結版の線「高頻度語と同音＝否、低頻度語＝記録」では記録の側）。Gin のひらがなルート（ほくほく線の型）は、一般の語を語呂のよい路線名にする道で、狙いどおり |
| C-07 | 6モーラ（やますそせん）。ひらがななので読める |
| **C-08（よい連想、新しく見つけたこと）** | 正本の思兼山は「伊夜日子山の**山裾**から張り出した、標高約50mの小高い山」（Gin「50にしましょう」）。おもいかねデータセンターのある山の裾を走る線が「やますそ線」になる。物語の場所とつながる |
| C-08（記録） | 現実のほくほく線（北越急行）も柳都県の中を走る。その線にも HNS の名が要る。ひらがなルートの線が二本になると、並び（やますそ線と〇〇線）を考える必要がある。記録 |
| 層 | 地方名「上ノ道・中ノ道・下ノ道」とも、七道とも重ならない |

判定：**やますそ線は受け入れ可**（条件なし。記録2つ）。
