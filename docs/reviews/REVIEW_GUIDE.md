### 3.3 層（どの段の名前か）

七道（〇〇道。雪路は道の別名）＞ 国（旧国名。歴史の呼び名として残す）＞ 都道府県 ＞ 県の中の地方名（上ノ道・中ノ道・下ノ道、左禄・正禄・右禄）＞ 市町村 ＞ 地区・通り・施設。声に出すと「〜のみち」が七道と県内の地方名で同じ形になるので、書き分け（「ノ」）と初出の言い方で見分ける。

## 4. 事実の確かめ方

- **検索ツールの自動要約を、事実として書かない。**元のページを開き、本文の該当文を引用させて確かめる。
- 確かめられないものは「**未確認**」と書く（「私の知識」「検索要約だけ」の別も書く）。
- 出典欄には、実際に開いて確かめたページだけを載せる。
- 読みの確認には、日本郵便の郵便番号検索（`https://www.post.japanpost.jp/cgi-zip/zipcode.php?zip=〒番号`）が使える（町域名のカナが出る）。

## 5. 地名の照合（国土地理院の住所検索）

- 問い合わせ先：`https://msearch.gsi.go.jp/address-search/AddressSearch?q=検索語`
- **「total（ヒット総数）」ではなく、検索語を「そのまま含む」件数を数える。**
- **Windows の注意**：コマンド行で日本語を Python に引数として渡すと文字コードが崩れ、「そのまま含む」がいつも0件になる。2026-10-03 にこの不具合で、三坊・楢崎・重原を誤って0件と記録した。**「total が多いのに 0件」は道具を疑う合図。**検索語は UTF-8 のファイルで渡す。
- 住所検索は町名を取りこぼすことがある。0件でも「未確認」とし、駅名は別に確かめる。

照合スクリプトの例（`queries.txt` に1行1語、UTF-8）：

```python
import json, sys, urllib.parse, urllib.request
sys.stdout.reconfigure(encoding="utf-8")
with open(sys.argv[1], encoding="utf-8") as f:
    queries = [l.strip() for l in f if l.strip()]
for q in queries:
    url = "https://msearch.gsi.go.jp/address-search/AddressSearch?q=" + urllib.parse.quote(q)
    with urllib.request.urlopen(url, timeout=20) as r:
        data = json.loads(r.read().decode("utf-8"))
    hits = [d["properties"]["title"] for d in data if q in d["properties"]["title"]]
    print(f"== {q}: total {len(data)} / containing {len(hits)}")
    for t in hits[:8]:
        print("   ", t)
```
