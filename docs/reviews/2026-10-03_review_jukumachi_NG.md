## 1. 什旭町

### 1.1 根拠

- Gin「什旭町(じゅうくまち)」「十日町 の対だからじゅうくまちで提案しました」「あってます」。町までが名前で、市としては「什旭町市（じゅうくまちし）」。P-04 足りる。
- 組み立て：十→什（同じ十）、日→旭。**旭は「九」と「日」でできた字**（日が九の音を持つ形声文字。NG の知識）。その「九」の音「く」を読みに取った当て字（DIFF-018、Gin「ルールは承認、のこします」）。十日町の「日」を字の中に残しつつ、読みは「とおか」から離れる。よく考えられた組み立て。

### 1.2 C 系

| 検査 | NG の結果 |
|---|---|
| C-01・C-02 | 国土地理院の住所検索で「什旭」0件。三字の「什旭町」の実在なし |
| C-02（記録を足す） | **滋賀県長浜市に「十九町」**（住所検索、自治体コード 25203）。ほかに四十九町（24216）、三十九町（7204）。読みは NG では確かめていない（「じゅうくちょう」なら「〜まち」と違う）。字も違う（十九／什旭）ので記録だけ |
| C-02 旭町 | 一次チェックどおり、全国に多い。三字で分かれる。記録 |
| C-04 十九 | 数の「十九」と同じ音。一次チェックどおり、害なし |
| C-04（記録を足す） | 「**重苦（じゅうく）**」と同じ音（三重苦・四重苦の「重苦」）。重い苦しみの意で、やや暗い語。ただ単独ではあまり使わない語なので、什陽の「重要」ほどの重さはない。記録 |
