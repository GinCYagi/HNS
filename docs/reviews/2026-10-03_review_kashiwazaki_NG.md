## 2. K1・K2 の「楢」（記録・新しく見つけたもの）

- 「なら」から奈良を思わせる、という一次チェックの見立ては妥当。奈良（大和）は本世界の畿内（五国府）の国。
- **もう一つ、重い連想がある**：福島県双葉郡の**楢葉町（ならはまち）**。福島第二原子力発電所の立地町で、東日本大震災のあと全町避難になった町。現実の柏崎は柏崎刈羽原子力発電所の町で、作品にはその発電所にあたる発電所と廃炉の筋がある（ALM city_plan、Gin の福島への思い）。「楢」の字が、原発の町どうしを結ぶ連想になりうる。害とまでは言わないが、Gin の思いに触れる所なので、知らせる。

## 3. K3 標崎

| 検査 | NG の結果 |
|---|---|
| 典拠（G-07） | 伝承「沖を通る船が、河口部のモチカシワ樹の群生する丘を目印にした」（コトバンク「柏崎市」、一次チェックで確認済み）。柏の木の丘＝船の目印＝しるべ。名前の筋が通っていて、よい |

| C-01・C-02 | 住所検索0件 |
| C-03 | 「しるべ」を含む駅・地名は、NG の知識では思い当たらない。機械照合は HNS-Rev の手元で |

## 4. 「柏」を残さない判断

- 妥当。柏は千葉県柏市（中核市、駅も多い）の名として強い。柏を残すと「柏〇」の形がほぼどれも柏市・柏原・柏木などに当たる。

## 5. 頼みごと

- HNS-Rev-local：K1 に住所検索の10件を足して否寄りに。K1・K2 に楢葉町の記録。K3 に「しべざき」と読まれる余地を足す。
- Gin：K3 標崎（しるべざき）を、ルビ必須を承知で採るか。K2 楢岬を残すなら、楢葉町の連想を承知で採るか。

## 6. 追加：標先（しるべさき）の査読（Gin の案、e262055）

Gin の言葉（原文）：「標先(しるべさき)はどうでしょう」

| 検査 | NG の結果 |
|---|---|
| C-01・C-02 | 国土地理院の住所検索で「標先」「しるべさき」とも0件 |
| C-03 | 「しるべさき」に近い音の駅・地名は、NG の知識では思い当たらない（全国駅名の機械照合は HNS-Rev の手元で） |
| 規則の扱い | **「標」は G-07（典拠：船の目印の柏の丘）、「崎→先」は DIFF-016（近い字。崎も先も、もとは同じ「さき」＝突き出た端）**。什旭町（DIFF-016・DIFF-018）と同じく、rule に二つ並べて書けばよい。G-07 の一部に含めると、典拠の範囲がぼやける |
| G-05 | 「先」は地形の字ではないので、地形どうしの置き換え（G-05）の問いは起きない。合 |
| C-08（記録を足す） | 「崎」をやめたので、名前から「海に突き出た所＝海沿いの町」という手がかりが消える。標崎で NG が良い点に挙げた所が薄れる。由来メモ（船の目印の丘）と絵で、海沿いだと補えば足りる |
| C-04 | 「これから先」「道しるべの先」と読め、Gin の願い（廃炉先行実証実験・常温核融合実証実験の町）と重なる。よい連想 |
| **C-07** | 清音の「しるべさき」で、「しべざき」と紛れにくくなったのは一次チェックの見立てどおり。ただし「標先」は音読みで「ひょうせん」とも読まれうる。「標＝しるべ」が字面から読めないのは標崎と同じ。**ルビ必須の条件はそのまま引き継ぐ** |

判定（案）：**標先は条件付き**（ルビ必須）。標崎と比べると、願いとの重なりが強く、読みの紛れも減る。海沿いの手がかりが消える点だけ、由来メモと絵で補う。
