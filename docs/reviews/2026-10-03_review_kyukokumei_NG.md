## 0. 結論

- HNS-Rev の照合（前例 §1、ぶつかり A〜E、まとめの線引き案）は、正本と合っている。NG も「旧国名を使うこと自体は既存の世界観とぶつからない」と見る（G-02、陸奥、二名島、尾張府）。
- 見落としとして、次の4つを足す（§1〜§4）。どれも「使ってはいけない」ではなく、線引きのときに一緒に決めておくと、あとで迷わないもの。

## 1. 層ごとの扱いがそろっていない（A の広げ）

- A は「畿内の国だけ替えている」とした。正本を層ごとに見ると、もう一段ある：
  - **道（七道）の層は替えている**：北陸道→越路（裁定待ち）、西海道→火守道、東海道→海つ道（案）、東山道→権現道（案）、南海道→補陀落道（案）、畿内→五国府。
  - **国の層は、畿内だけ替え、ほかは実名（旧国名）のまま**、という案になる。
  - **県の層は替えている**（柳都県、尾張府）。
- つまり「道は替える・国は残す・県は替える」の三層になる。おかしくはないが、読者には「なぜ越路の中に越後がそのままあるのか」に見える。**「国の層だけは、歴史の呼び名として実名のまま残す（畿内は都の国なので五国府の中で別名）」**と、層の理由を一行で記録しておくとよい。
- 越路（越の国）→越後（越の国の後ろ）は、字の上でもつながる（越）。越路が採られれば、越後は越路の子として自然に読める。記録。

## 2. 県の名前の付け方が二通りある（新しく見つけたもの）

- **尾張府（愛知）は、旧国名＋府**で県の名前にしている。**柳都県（新潟）は、雅称＋県**で、旧国名（越後）を使っていない。
- RUL-022（りゅうとの命名規則は埼玉県さいたま市の応用）と、pending の解消「府の字は県ごと（尾張府）」で、それぞれの県の作り方は決まっている。ただ、旧国名を使うと決めたあと、ほかの県を「旧国名＋府（尾張府型）」で作るか「雅称など＋県（柳都県型）」で作るかの物差しが、まだない。
- 例：正本の open に「東都は武蔵府東都市か?」がある（旧国名「武蔵」を県に使う尾張府型）。
- **旧国名の線引きと一緒に、「県の名前に旧国名を使うのはどんなときか」を Gin に一言決めてもらう**と、47都道府県（RUL-011）を進めるときに迷わない。

## 3. 現役の駅名の「旧国名＋地名」（D の広げ）

- D は路線名（越後線ほか）を挙げた。**駅名にも同じ形が多い**：現実の JR は、同名の駅を区別するために旧国名を頭に付けている（越後石山・越後湯沢・越後川口、信濃大町、羽前〇〇・羽後〇〇、陸奥〇〇 など。NG の知識）。
- 旧国名を「部品」として使ってよいとすると、「越後〇〇駅」の形がそのまま現役の駅名と一致しやすい（C-01）。pending にある越後石山駅がその例。
- 線引き案の「現役の路線名にはそのまま当てない」に、**「旧国名＋現実の地名」の駅名も同じ扱い**と足すとよい。部品にするなら、後ろの地名の側を HNS 名にする（例：越後＋（石山）→ 越後＋HNS 名）形なら、C-01 は避けられる。

## 4. 東北の中の旧国名（B の広げ）

- B は陸奥の二重を挙げた。足すこと：
  - 正本の秋田新幹線は「出羽・羽後方面の古称」で再設計待ち（L223）、陸羽新幹線は「陸奥採用済みとの意味重複」で棄却（L232）。**旧国名を使うと、出羽・羽後・羽前・磐城・岩代などが、地方の「陸奥」の中の国名として並ぶ**。陸奥（地方）の中に出羽（国）がある形は、現実の律令（陸奥国と出羽国は別の国）とは食い違う。
  - 本世界では「陸奥＝東北地方の名前」なので、律令の陸奥国を指したいときは「陸奥国（むつのくに）」と読みを分けるか、別の呼び方にする。HNS-Rev の B の指摘と同じ結論で、**読み（みちのく／むつ）で分ける**のが一案。
  - 相津（会津）は、現実では陸奥国（のちの岩代国）の中。相津はすでに名前を替えているので、ぶつからない（記録）。

## 5. HNS-Rev の線引き案について

- 「旧国名は、国・地方の呼び名と、名前の部品に使う。今ある市町の名前と現役の路線名には、そのまま当てない。畿内は五国府の国として別の名前」に、NG は賛成。
- 足すとよいもの：
  1. 層の理由（§1）
  2. 県の名前に旧国名を使う物差し（§2、尾張府型と柳都県型）
  3. 「旧国名＋現実の地名」の駅名も、路線名と同じ扱い（§3）
  4. 陸奥は読みで地方と国を分ける（§4）
- 佐渡（C）は、線引き案のとおり、島・国の呼び名としては佐渡、市の名前は別に。三瀬川の棄却（同じ柳都県の佐渡市に同名の大字）のように、すでに佐渡市を実在の照合先として扱っている前例とも合う。

## 6. 頼みごと

- HNS-Rev：§5 の4つを線引き案に足して、Gin に上奏。
- Gin：旧国名の線引き（HNS-Rev 案＋§5）と、県の名前に旧国名を使う物差し。

## 7. 追記：そのあとの Gin の答え（kyukokumei_check §6〜§8）

- 線引き：Gin「1 okです」。NG の §5 の1（層の理由）は、§6 の「国の層は歴史の呼び名として残す」に入った。§5 の3（駅名）は「現役の路線名と駅名」として入った。
- 県の名前の物差し（NG §2）：Gin「元の名前を使わないでどれだけその場所を想像できるか、が一つの根拠になっていると思います」「旧国名が現在と被っている場所もあるはずなんです(磐城→いわき市)」。尾張府型と柳都県型は、同じ物差しの上にあると読める。DIFF-019 の案に NG も同意。
- 陸奥の読み分け（NG §4）：HNS-Rev の §7 のとおり、「むつ」は**青森県むつ市**と同じ音になるので、NG の「国は『むつ』と読む」案は弱い。読みで分けるなら、別の読みか書き方が要る。Gin の答え待ち。
