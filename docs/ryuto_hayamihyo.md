## 2. りゅうと市（りゅうとし）＝新潟市

りゅうと市の中の名前と決めごとは **Gin の裁量**（RUL-019）。HNS は記録と照合。

### 2.1 地理の骨組み

- 北は日ノ本海。柳都大川が南から北へ流れ、河口に **りゅうと漁港**。
- 川の**西が「島」**（旧市街＝**古湊**、SOLAPH、ALP'n-Z、商店街）、**東が「本土」**（**りゅうと駅**、商業地、Octagonuth）。
- 島と本土を **よろずよ橋（よろずよばし）** が結ぶ。6連の石張りのアーチ橋。昔の表記は「夜来津代橋」（音から取った当て字）。
- 島は、二本目の放水路（関屋分水にあたる。**名前は裁定前**：候補「堰戸分水」）でできた。
- 日は**東の山から昇り、西の日ノ本海に沈む**。

## 3. 呼び方の決まり（読者が迷わないために）

（1・5・6 は HNS-Rev の読みで、Gin の言葉ではない。Gin に確認中。2・3・4 は RUL-015・021・018）

1. **毎日呼ぶ名前はひらがな、いわれを背負う名前は漢字**（りゅうと市・よろずよ橋／柳都県・閼伽川・相津）。
2. **路線名の「都」は東都**。柳都は路線名では「柳」（東柳新幹線）。地名どうしの「都」の重なりはかまわない（東都と柳都）。
3. **一般の語を付けた派生名は、親のいまの表記に合わせる**（よろずよ通り・よろずよ口。RUL-021）。
4. **動物の字を含む地名は残す**（RUL-018）。
5. **古い名前が残っている**のが日ノ本（よろずよ橋、伊夜日子、相津）。
6. 名前がない所は**カッコ**。台詞や字幕では、カッコのまま出さず、名前を言わない言い回しにする（例：「川向こうの町」）。
