## Retry Contract

参照コピー：

`retry-contract-current.md`

正本は ProC の `Standards/retry-contract-v0_1.md`（v0.1、発効 2026-07-18）。ProC の配布スクリプトはヘッダ規則だけを配るので、この参照コピーは 2026-10-09 に HNS-M4 が正本から写した（Gin「HNS内のProC最新情報に更新」）。

## 運用の更新（ProC 正本にはまだ入っていないもの）

- 伝達文の書式（2026-10-08、Gin の指示、ALM・E5 経由）：ヘッダは種類だけ（Notice・Question・Report・Request など）、本文の最初の一言で名乗る（例「HNS-M4 です。」）、確認や承認が要るときだけ「Ginへ：」を足す。【プロジェクト】や「〇〇 より Gin への文」は付けない。ヘッダ規則 v1.6 の書式を、コンテキストを減らすために短くした運用。
- セッションどうしの知らせは郵便受け（~/HANDSHAKE_mail/to_<プロジェクト>/）。直接の手紙は急ぎのときだけ。

## 更新規則

- 配布コピーを直接編集しない。
- 改訂はProC正本で行う。
- ProC配布スクリプトによって同期する。
- 現在の適用版は、参照コピー本文の文書名・状態欄・版管理欄を確認する。
